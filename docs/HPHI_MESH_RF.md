# P03：軸を含まない一般断面と複数PEC境界のHφ FEM

専用[Hφ Project/Job](HPHI_JOBS.md)の入力・実worker・保存/取込・中止/再起動を後続工程で接続・限定受入した。GUIは[別計画](HPHI_GUI_PLAN.md)。
2026-09-12、基準f4b8cc3。[一般断面計画](COAXIAL_GENERAL_MESH_PLAN.md)を実装・限定受入した。
追加12unit・独立細分・標準回帰と専用native/CLIまで確認し、以下の範囲で限定受入した。

## 入力と対象

専用 `HphiMeshCase` は `MeridionalMesh` を持つ。自動生成された長方形に限定する
[CoaxialCase版1](COAXIAL_RF.md)とは別の入力/native形式で、両方を保持する。
座標はSIの(r,z)、全三角形はr>0、連結真空、m=0 Hφ族、全輪郭は閉じた実PEC。
単一外周と0個以上の穴を明示でき、斜めの直線境界、凹外周、環状の内導体も対象にする。
軸接続領域、曲線、材料、ポート、混在した位相領域、他の場族、自動メッシュ生成は未対応。

外周は反時計回り、穴は時計回り。閉点を重複させない。
入力のbinary64座標に対する向き・交差判定を、既存自作の有理数fallbackで行う。
全輪郭の非交差・厳密包含・穴の非入れ子、正の要素Jacobian、辺連結、各頂点のlink、
境界cycle数と `V-E+F=1-h` を検査する。T字・接触・重なり・飛び地・未使用点は拒否する。
全境界辺は、元の輪郭の各線分を指定順に厳密に覆う必要がある。
丸めで曲がった節点を直線へ投影しない。その折れを輪郭点として明示するよう案内する。
既存 `PlanarMesh` の単一disk契約は変更しない。

全3D体積は `2π∫r dr dz`。各実表面積は `2π∫r ds` で、穴の体積を引き、穴の表面積は加える。
全表面を「外周、指定順の穴、各輪郭の指定順の線分」の順序で保存する。
三角形数は既存円筒版と同じ250000以下。これは一般大規模計算の性能保証ではない。

## FEM・場・RF

未知数はq=rHφ。閉同軸円筒と同じ
`K=∫∇q·∇v/r dr dz`、`M=∫qv/r dr dz`、自然PEC条件 `∂n q=0` を用いる。
P1/P2の共有中辺基底、積分、正スペクトル検査、元セルでの成分評価を自作円筒実装と共有する。
新しい一般断面の行列を組み立てて実際に解く。固有値を解析値へ置き換えない。
積分次数qとq+4の相対行列差5e-10という既存ゲートも保持する。

連結な正半径のHφ空間には、定数qの静的循環零空間が一つある。
穴の数をそのままこの場族の零空間次元にしない。全Maxwellの静的場族を網羅したとは扱わない。
零空間へのM直交と残差、規格化、正の低位スペクトルを検査し、静的成分をRFから除く。

場はpeak `exp(+iωt)`、**real+i*quadrature**。
Hφ_real=q/r、Er_quadrature=q_z/(ωε0r)、Ez_quadrature=-q_r/(ωε0r)、他のE/H成分は0。
全3Dの平均全エネルギーU[J]で規格化し、E/H両積分で再検査する。
各PEC線分の `∫Hφ² dS` と境界成分ごとの和を保存し、全損失P[W]、Q0、Gを計算する。
R/Qの二規約・Vacc/Eaccは、真空の加速経路が宣言されていないため理由付きN/A。
表面ピークの収束保証と、損失による複素周波数は対象外。

## 保存と操作

`superfish_ng_hphi_mesh_case/result/manifest/probe` の専用schema1を用いる。
case/mesh/fields/resultsを保存し、最後にcompletion manifestを公開する。
元三角形、P1/P2自由度、境界の所属・線分番号と実面積を再構成し、正スペクトルと全RFを再検証する。
hashを再作成した境界改変・静的混入・低位モード欠落も拒否する。
途中失敗は完了扱いにせず、既存出力を置換しない。native内部へのプローブ出力も拒否する。

```sh
python -m superfish_ng solve-hphi-mesh examples/hphi_mesh/holes1.json --out new-hphi-run
python -m superfish_ng replay-hphi-mesh new-hphi-run
python -m superfish_ng probe-hphi-mesh new-hphi-run --points examples/hphi_mesh/probe_points.json --mode 6 --out new-hphi-probe.json
```

modeはCLIが1始まり、APIが0始まりの周波数順位で、追跡IDや解析ラベルではない。
プローブは元要素の片側場を評価し、穴の内部と外部を厳密な向き判定で拒否する。
E/H/Bの全real/quadrature成分と元hashを保存する。斜め例題には、その真空内の座標を別途指定する。
専用Project/Job、GUI、Study・追跡への統合は後続工程。

## 先行不変量と固定した独立ゲート

[計画](COAXIAL_GENERAL_MESH_PLAN.md)の矩形外周から、z∈[L/3,2L/3]の矩形穴を1個または2個引く。
`q=A cos(3πz/L)` はすべてのPEC境界を満たし、f=3c0/(2L)、Ez=0。
規格化積分は `I=L/2 log(b/a)-Σ L/6 log(d_j/c_j)`、A²=U/(μ0πI)。
各穴を含む全8面/12面の壁積分を、独立の線積分で比較する。

検証器は `scripts/validate_hphi_mesh.py`。穴数1/2、二尺度、P1/P2、二水準の16実FEM/nativeを保存再生する。
P1は各基本帯の16→32分割、P2は6→12分割。全9モードを解き、解析対象の上下guardと相対間隔3%以上を要求する。
今回の対象を常に同じモード番号と仮定しない。E/Hは一つのH符号だけで揃え、振幅をfitしない。

| 最終相対ゲート | P1 | P2 |
|---|---:|---:|
| f | 1e-3 | 1e-4 |
| Eの体積L2 | 0.035 | 0.01 |
| Hの体積L2 | 0.003 | 0.001 |
| 全線分壁積分・G/Q/P | 0.01 | 0.005 |
| U | 1e-8 | 1e-8 |

U以外の各誤差が実細分で減少し、二尺度のf/G/Q/P/U則は相対1e-8以内であることも必須。
穴なしで既存円筒版の点・自由度・K/M配列と固有値が一致することを別検査にする。
幾何の多項式双線形積分は、外矩形の64×64 Gauss積分から各穴を引いた独立積分と照合する。
