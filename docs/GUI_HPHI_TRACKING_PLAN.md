# Hφ部分空間対応のGUI

所有保存・worker・CLIに続く操作工程。未実装・未受入。
既存Hφページに、保存済み単発結果二つの選択、完全な追跡要求の編集/保存、実行/取消と再生を接続する。

受入条件：

- 候補はこのworkspaceのcompleteなhphi_solveジョブだけとする。前後の元場を選び、明示比較メッシュを含むstrict要求を開く/保存する。入力のない比較メッシュ・形状写像・IDを自動生成しない。
- 個別IDとID集合、前後の順位、E/H両方の主内積、係数位相、有限比較区間、guard/射影未達の理由を表示する。completeと数値PASSを区別し、UNVERIFIEDでは個別IDを確定しない。
- 多次元群は部分空間のID集合として表示し、基底ごとの周波数や係数位相を割り当てない。前後の元場を通常Hφジョブへ取り込み、Project・元係数・native5ファイル・PNG・全18成分CSVを保持する。
- 要求と結果のダウンロード、URLからの復元、所有した前後の場での再比較を接続する。元の出所パスがなくても保存結果を使える。
- 実Chromeで個別対応、縮退/順位逆転のID集合、厳しい条件/guardの未検証、原場の取込・保存・取消・再起動を確認する。旧Hφ細分差・Study・TM/TE/平面の操作を回帰し、CLIと数値/保存内容を照合する。
- 細分差表の「差の減少」を、既存の微小増加許容を含む検査だと明確に表示する。数値しきい値や判定式は変えない。
- 標準/旧f/RF、固定候補/統合後のsourceを照合する。一般の形状変更・連続問題の誤差上界・表面ピーク精度保証は宣言しない。

新規外部資料・依存・旧版参照・外部サービスなし。履歴連鎖と形状写像は後続工程。
