StaticFieldStudyは専用format/version、基底StaticFieldProject、parameter、valuesを持つ。11種類のCaseと対応次数を保持する。最初の共通パラメータはuniform_scale（正の有限値）とexcitation_scale（符号付き有限値、零を含む）。未知のパラメータ・型・重複キー・RF入力を拒否し、全派生Caseを出力予約前に厳密検証する。表示m/mmとSIを混同しない。

uniform_scaleは原点を中心に全メッシュ節点・外周・穴の座標を同じ係数で変更し、領域・材料・境界edge ID・源密度・境界値を保つ。単一の境界座標だけを変更したり、磁束/電流の総量を暗黙保存するために源を補正したりしない。excitation_scaleは電荷/電流の体積源密度、明示の電位/磁気ポテンシャル/Neumann・Ht境界値、反跳材料の残留Bを同じ係数で変更する。epsilon/mu、反跳主値/方向、B-H構成表と来歴は変更しない。対応する全source/boundaryフィールドを列挙し、新しい型を黙って無視しない。

初期係数と非線形反復条件は基底Projectに明示された値を各条件へそのまま渡す。前の条件の解を次の初期値へ流用しない。条件変更による実非線形失敗は元の専用FEMで再現・保存する。初期値の有効性やB-H表範囲を満たさない条件を、成功へ近付けるために変更しない。sweepの順序は入力値の順序であり、RFモード追跡・解枝追跡・メッシュ収束を表さない。

API・CLI・実Study workerと専用GUIを接続し、全条件Projectと成功5/失敗3の元native、全量/停止履歴と実装来歴を保存する。全条件の実行完了と、全条件の求解成功を別項目で保持する。完了した失敗点には場や成功量を作らず、CLIは全点成功0、実行完了かつ実非線形失敗点あり1、不正/未完/保存エラー2を返す。中止/強制終了後の部分出力を完了Studyと扱わず、既存出力を上書きしない。再起動後も同じCase/元FEM・失敗履歴を検証して表示する。
