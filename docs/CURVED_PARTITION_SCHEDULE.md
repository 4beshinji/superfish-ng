# 設計変数で選ぶ曲線の分割候補

2026-09-15 JST、開始HEAD `f8b0638`。D02の境界分割変更のための計算基盤。
**この段階ではtuneの要求・実行・保存・GUIへ未接続であり、D02の境界分割変更を受入済みとはしない。**

`build_partition_schedule(project, schedule)` は、同じ解析曲線と物理設定を持つ
複数の初期メッシュ・明示細分履歴を検証し、各候補のportable Projectを返す。
自動対応推定は行わず、既存の曲線比較版5と同じ明示参照座標を使う。
初期接続・境界節点数・履歴を変更できる。各試行の形状法則への適用と実追跡は次の接続課題。

scheduleは厳密な次の4キーを持つ。

- schema_version: 整数1。
- breakpoints: 設計変数の単位で指定する有限実数の厳密増加配列。
- partitions: breakpointsより一つ多い、1〜32個の分割候補。
- max_pair_tests: 各参照被覆検証で使う正整数の組合せ予算。

`partition_index(schedule, value)` はbreakpointと等しい点で右側を選ぶ。
例：breakpoints=[0.5]なら、x<0.5は候補0、x>=0.5は候補1。
降順・追加中点・過去の参照試行でも値だけで選ぶ。試行順や以前の選択を状態として保持しない。

各partitionは次を明示する。

- source_mesh: 既存schema_version=1の完全なタグ付き弦メッシュ。
- reference_vertices: 初期source_mesh各頂点の無次元共通参照座標。
- curved_refinement_levels または curved_refinement_steps: どちらか一方の新しい履歴。
- minimum_corner_angle_deg: 有限で0より大きく60未満の品質下限。
- segments_per_curve: 必要な場合に指定する初期弦分割数。省略時は元Caseの指定を継承。

Projectの解析曲線・タグ・RF・solver・物理モデルは元入力から保持する。
分割候補からの物理設定上書きは未知キーとして拒否する。
元の局所要素番号は引き継がず、新履歴のmarked選択を新メッシュ上で凍結する。
全P2段階で幾何と角度下限を検査し、各候補を最初の候補と比較して
曲線ごとの共通参照折線・全親被覆・非交差・正向き・計算予算を検査する。
`partition_comparison_mesh` は実Project、参照座標、履歴から比較版5の文書を作る。

同じ解析曲線でも、境界節点を追加して二次写像を作り直すと、表現される領域は変わり得る。
既存の `remesh_curved_project` が要求する「二次境界が全て同一」という契約は変更しない。
新経路は各側の実二次領域をそれぞれ参照領域へ写す。場の補間やFEMによる周波数評価はまだ行わない。
参照座標は対応の宣言であり、物理モードの同定や区間全体の連続性の証明にはならない。

新4unittestは、初期対角線・軸境界分割・uniform履歴が違う矩形について、
独立な解析面積0.02 m²、回転体積pi*0.1²*0.2 m³と共通分割からの積分を照合する。
未知設定・不正単位値型・breakpoint・参照折線・予算の拒否、原入力の不変性と
新候補への元marked履歴の非継承も検査する。
さらに曲線PEC辺を分割し、同一解析曲線でもP2体積が変わる候補を新経路が検証し、
従来の同一二次領域経路が引き続き拒否することを確認した。
証拠は `out/curved-partition-schedule-20260915/`。

次は、この候補群をtuneの各実値から選び、式による形状変形・実FEM・比較版5へ接続する。
最終細分の親とID回復の参照元はそれぞれ実値の候補を使い、元履歴と取り違えない。
全候補と式を保存要求へ含め、再構築と変更拒否、途中の分割切替、CLI/worker/GUIを検証する。
外部から宣言する分割候補の方式であり、設計値から新しい接続を自動推定するメッシャーではない。
全計画・D02親・他物理とD03の残件は保持する。
