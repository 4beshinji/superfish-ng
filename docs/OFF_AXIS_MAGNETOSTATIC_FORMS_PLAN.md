# S02: 軸を含まない磁静領域の縮約磁束ポテンシャル・弱形式

2026-09-13 JST。軸非接続のgauge/参照と場の残件を解く最初の限定課題。未実装・未受入。

直線MeridionalMesh（全点r>0、明示穴を含む）に、psi=r*Aphi[Wb]をP1/P2で表現する。Br=−∂z psi/r、Bz=∂r psi/r、dV=2πr drdz。磁気エネルギーはπ∫nu/r |grad psi|²drdz[J]となる。

- 正値実数mu_r、全セルの領域所有と全領域の符号付きJphi[A/m²]を明示する。軸接続・曲線・非線形/異方性/永久磁石はこのAPIで拒否する。
- K=2π∫nu/r gradNi·gradNj drdz[1/H]、f=2π∫Jphi Ni drdz[A]を組み立てる。源電流はsum(f)/(2π)[A]で、軸接続aの荷重[A m²]とは異なる。
- 定数psiはBr=Bz=0、Aphi=C/rのcurl-free成分であり、全DOFと定数核を保持する。軸接続aの定数（一様B）と混同しない。軸を除いた領域だけでは、その穴を貫く絶対的な磁束の参照は決定できない。境界/参照の拘束は次段階で明示する。
- Kの対称性・一つの定数核・残りの正値スペクトル、一様軸方向Bのpsi=Bz*r²/2による全Jエネルギーを独立に照合する。
- 1/r重みは一般に有理関数なので求積次数比較を行う。既定16対20、4〜32の明示指定に+4を比較し、K/荷重/総電流差5e-12以内を要求する。未解決なら細分/求積次数増加を促し、許容差は緩めない。
- 独立高次数Gauss/Vandermonde積分、矩形から穴を引く解析モーメント（1/rはlog）でpsi=1/r/z/r²/rz/z²のエネルギーと源仕事を照合する。
- mu倍率mでK∝1/m、一定psi係数で幾何尺度sに対しK∝1/s、f∝s²を検査する。z移動、材料/領域順序、源反転、厳密JSON往復を確認する。
- 新規unitと独立72例（穴0/1/2、P1/P2、材料3パターン、尺度0.5/2、z移動2通り）、216多項式、既存標準周波数/RFを受入条件とする。独立比較は相対差1e-11以内。

固定psi/Ht境界付き実FEM、元psi/Aphi/B/H・磁束出力、参照を保持する保存/CLIは後続工程。軸が領域外のとき、その軸を含む磁束積分を捏造しない。新規依存・外部資料・旧版実行なし。S02と全計画は未完。
