# S04: 平面P1の境界付き非線形磁静場

2026-09-13 JST。後続の限定課題。[実装記録](PLANAR_BH_SOLVE.md)の専用API範囲で限定受入。

平面P1の単調等方H(B)弱形式へ、全Jz、固定Azと接線Htを明示した専用Caseを接続する。少なくとも一つの固定Azを要求し、基準と相対/絶対係数を保持する。自然荷重は−∫HtNi ds[A]。自由DOFでg(A)−fJ−fHt=0を、実接線K=d g/d Aと減衰Newton法で解く。一定muへ固定した解を最終解と扱わない。

初期値・反復上限・残差許容値・減衰条件を厳密入力とする。初期値は固定境界に一致する線形初期接線の境界延長を基本とし、源を含むNewton試行を表の範囲とエネルギー目的関数で棄却/減衰する。必要な場合は境界に合う明示的な初期係数を受け取る。表の外挿、無効初期場の切り詰め、収束失敗を成功に読み替える処理は追加しない。反復履歴には残差・目的関数/エネルギー・採用減衰率と棄却理由を保持する。

成功解だけから元Az/Bx/By/Hx/Hyを返し、片側材料・表区間・来歴を明示する。U/U*[J/m]と元B·H、元H周回/固定境界反力[A]、元B磁束[Wb/m]を別々に確認する。離散仕事はU+U*=電流/自然境界/固定境界仕事で、2Uではない。原場のAmpere収支と離散反力保存を分ける。小さなNewton残差を場の離散化精度と扱わない。

受入は一様な非線形B/H、二層の共通Htと連続Az、一定電流でHが一次・B(H)が区分一次となる独立対照、線形極限、零場・符号反転・幾何/材料尺度・基準変更、表上限/反復上限/無効入力を含む。失敗は理由・Case/設定・履歴・最後の有効な係数を持つ機械可読の例外情報として保持し、保存/CLIは後続工程で接続する。

場・U/U*・元H周回/反力・磁束をP1の8/16/32から独立に細分比較する。表現可能な場は1e-10以内、細分最細のAzは1e-3、B/Hは2e-2、U/U*は1e-3、周回/反力は2e-2を開始条件とし、未達なら元結果を保持して細分する。一定電流の1次元対照では解析積分に加え、別の1次元境界値解法との比較を設計する。この比較の範囲を一般2次元・軸対称の独立ソルバー検証と呼ばない。

P2の非線形積分・軸対称・履歴型材料・RF・力/トルクは別工程。物理仕様を明示的に拡張した専用入力とし、既存線形/反跳/RF入力を暗黙に拡張しない。標準検証と旧周波数/RFを含めて受け入れる。

独立1次元比較には既存SciPyの[solve_bvp公式仕様](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_bvp.html)を確認した。一次ODEの二点境界値問題と残差制御の接口だけを参照し、源問題A'=B(H)、H'=−Jを独立に構成する予定。文書の例題コードはコピーしない。これは新しい依存ではなく、既存のSciPyを検証専用で使う設計である。

独立検証は96条件を予定する（一様32、二層16、電流細分24、旧線形FEM極限8、厳密零場8、期待される収束/材料範囲失敗8）。電流の8系列には独立1次元境界値比較を加える。細分では元場3量の単調改善と各量の最細許容値を別に判定し、元磁束は最細2e-3以内を開始条件とする。凸エネルギー汎関数の解析最小値との差も評価し、入れ子メッシュでの減少を丸め誤差と区別する。
