## 他の検査

- Bessel場との重み付きL2比較で、周波数だけを再現する誤実装を検出。
- 質量内積のモード直交性、固有値残差、電気/磁気エネルギーを確認。
- 任意形状の一様拡大でf∝1/s、R/Q一定、常伝導Q∝sqrt(s)を確認。
- Uを9倍、σを4倍とした場合の場振幅、壁損失、Qのスケーリングを確認。
- 軸上区分線形場の通過位相積分を独立した数値積分と比較。
- 未対応入力・重複キー・既存出力への上書きを拒否することを確認。
