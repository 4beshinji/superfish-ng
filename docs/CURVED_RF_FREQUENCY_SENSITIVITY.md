# 曲線RFの角周波数偏微分

2026-09-09。N04の随伴重み付き細分選択に向けて、
`curved_rf_frequency_sensitivity.r_over_q_frequency_derivative(solution, mode=0)`を追加した。
周波数と場の変化を分離し、実係数u・K/M行列・幾何・beta・積分区間・位相原点を固定した
角周波数ω [rad/s]に対する偏微分を返す。Hzに対する微分には2πを掛ける。
固有値・固有場の再計算や、暗黙のエネルギー再正規化は行わない。

## 独立導出

軸上のP2場をu(z)、位相原点をz0、v=beta*cとすると、

```
V(ω) = 2/(ω ε0) ∫ u(z) exp(i ω (z-z0)/v) dz
V'(ω) = -V/ω + 2i/(ω ε0 v) ∫ (z-z0) u(z) exp(i ω (z-z0)/v) dz
```

後者の積分は三次多項式と複素指数の積。
元の軸P2辺を指定RF区間で切り詰め、中心座標へ移して球Bessel関数の厳密モーメントを使う。
`x³ = (3 P1 + 2 P3)/5` と `∫ Pn(x) exp(i t x) dx = 2 i^n jn(t)` より、
三次モーメントは `2i (3 j1 - 2 j3)/5`。負向きの辺も同じ物理積分に直す。
既存の電圧共変ベクトル経由で直線軸・連続区間・modeの厳密条件を検査する。

`E = Em + Ee`、固定係数・行列で `Ee ∝ ω^-2` より `E' = -2 Ee/ω`。
加速器規約 `q = |V|²/(ω E)` の微分は、

```
q' = 2 Re(conj(V) V')/(ω E) - q/ω + 2 q Ee/(ω E)
```

となる。固有ベクトルから外れた係数にも使えるよう、電気・磁気の両エネルギーを保持する。
回路規約の偏微分は加速器規約の1/2。V=0でも対数微分による0除算を使わず評価する。
戻り値の単位は電圧がV/(rad/s)、R/QがΩ/(rad/s)。

## 随伴との結合と限界

[固定周波数の随伴](CURVED_RF_ADJOINT.md)をzとする。
Kに対称摂動Bを与えた固有対の一次変化は `λ' = u.T B u/(u.T M u)`。
RF関数自体のK/Mと幾何を元のまま評価する場合、

```
dq/dt = -z.T B u + (∂q/∂ω) c/(2 sqrt(λ)) λ'
```

で場方向と周波数方向の寄与を結合できる。実際の形状/行列を変える目的関数では、
さらにRF関数への直接寄与が必要になる。このAPIだけを形状全微分・細分誤差上界とは呼ばない。
既存のFEM/RF/選択/停止条件は変更しない。
次は親子空間の残差をこの結合感度で重み付けし、局所選択・独立精度/効率比較へ接続する。

## 検証

追加3検査はPASS（0.175秒）。

- 定数軸場の複素指数の閉形式を直接微分したV'に相対差2e-13未満で一致。
- 軸上電圧0の非ゼロ場でq'=0。不正mode拒否。
- 固有ベクトルから外れた係数の中心差分で両R/Q偏微分が相対差2e-7未満。
  振幅倍率・位相原点の変更でもR/Q偏微分は不変。
- 対称な行列摂動の密固有値再計算による差分と、上式の随伴・周波数項の和を相対差2e-6未満で照合。
  周波数項が全微分の1%以上となる試験を使い、省略した実装を検出する。
