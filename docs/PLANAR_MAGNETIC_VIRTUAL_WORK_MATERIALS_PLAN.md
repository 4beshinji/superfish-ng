# S05: B-H・反跳材料の平面仮想仕事

2026-09-13 JST。後続限定課題。未実装・未受入。

[材料Maxwell応力](PLANAR_MAGNETIC_FORCE_MATERIALS_PLAN.md)に続き、同じ真空P1重み・剛体対象・固定外周・固定した対象外源/材料で、実際の±変位FEMを独立に再求解する。B-HはP1、反跳はP1/P2に限る。元の線形スカラー仮想仕事version 1と保存報告を完全再現する。

B-Hの停留ポテンシャルは真の表積分エネルギーUとAzによるJ/Ht仕事からΠ=U−Az·(J荷重+Ht荷重)。反跳はB=0を基準とするU0=∫(B·nu·B/2−B·nu·Brem)dAを用い、同じJ/Ht仕事を引く。U0には残留磁化結合を既に含むため、remanent_loadによる仕事を二重に差し引かない。H=0基準ポテンシャルとの差は材料体積で定まる定数で、剛体対象の微分が一致することを別経路で確かめる。

反跳の対象回転では、対象領域のorientation_radへ実際の回転角を加え、透磁率主軸と残留Bを同時に回す。元の節点移動と同じP1補間を使い、真空セルだけが変形する。全領域の積分電流、境界値・基準Azを維持する。重み付きトルクと節点回転応力トルクは両方保存し、仮想仕事との比較は後者に限る。

材料の変位Caseが非線形求解に失敗したときは、成功側から差分を推定しない。材料用結果version 2に完了/失敗状態を明示し、元要求、全完了記録、失敗した符号/種類/刻み/変位Case、既存MagneticNonlinearFailureの履歴・最後の有効係数を保持する。失敗を含む差分値はnullで、失敗を示す明示的な例外にこの保存可能な結果を結び付ける。刻みの暗黙縮小・外挿・部分成功の合格扱いは行わない。入力不正と求解失敗を区別する。nativeへの保存とCLI終了1は後続の保存工程で設計する。

最初の独立不変量は対称mu_rec=1永久磁石の非零磁気モーメントトルク。材料方向を回さない場合の差を保存し、方向を回した実変位ポテンシャルで解析トルクと節点応力の一致を確認する。線形極限の電流力/偶力、非線形B-H内部と異方性/残留磁化内部、回転/反転/尺度、原点変更、電流/材料体積不変、δとδ/2、複数重みを別系列で検証する。応力/実差分の尺度付き差1e-5を実装前の開始条件とし、解析厳密対照1e-9とメッシュ細分の判定を混同しない。

意図的な非線形失敗を元Case・変位先の両方で確認し、最後の有効係数/反復と失敗原因の完全保存を検証する。標準回帰と既存周波数/RF差、旧線形56応力/40仮想仕事と24native報告の不変を確認して専用APIのみ限定受入する。材料保存CLI・GUI・軸対称・S05全体・全計画は未完。

新規外部資料・依存・旧版実行は導入せず、[元平面力計画](PLANAR_MAGNETIC_FORCE_PLAN.md)の公開エネルギー変分と既存のB-H/反跳構成則から自前に導出する。

材料用の入口は別の専用API `material_planar_magnetic_virtual_work` とし、既存 `planar_magnetic_virtual_work` の線形限定契約と拒否試験を維持する。両方を同じ名前へ暗黙拡張しない。材料失敗例外は `PlanarMagneticVirtualWorkFailure`、保存可能な完全報告はその `report` 属性とする。
