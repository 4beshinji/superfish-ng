# G02 一般輪郭の独立RF照合

## 方式と受入条件

`scripts/compare_contour_ngsolve.py` は自前の品質判定付きメッシュ生成とP2 u=Hphi/rを、
Netgenメッシュ・NGSolve P3 Hphiの独立参照へ照合する。参照の弱形式と積分は
[既存の独立照合](INDEPENDENT_COMPARISON.md)と同じ。全PECの単一輪郭を参照側へ渡し、
NGの三角形・行列・係数・RF積分は渡さない。SciPy/ARPACKと定数/物理契約は共通。
一般輪郭の向きだけを座標順に合わせ、境界の形状・タグを変更しない。

SI・peak phasor・U=1 J・beta=1・基本m=0 TMで比較する。内部磁場の内積から全体符号を
一つ選び、同じ符号で電場を照合する。振幅フィット・点ごとの符号合わせはしない。
参照電場は `Er=-Hphi_z/(omega epsilon)`、`Ez=(Hphi_r+Hphi/r)/(omega epsilon)`。
円筒Besselの電磁場・RFをoptional unittestで検証し、電場だけ2倍にした判定試験も行う。

両ソルバーを独立に3段階以上細分し、最終差と最後の細分変化をそれぞれ判定する。
周波数相対1e-4、R/QとG相対0.005は既存参照の閾値を継続する。
内部Hphi点群の最終相対L2差は0.005、内部電場ベクトルの最終差と双方の最終細分変化は0.01。
点群の一致を領域全体の誤差保証とは扱わない。鋭い角の表面ピークは未検証。
Gは表面H²の積分を検査するが、局所ピークの検査を代替しない。

## 合成形状

- 円錐台: 長さ0.12 m、入口半径0.08 m、出口0.10 m。12個の内部点。
- 折返し: (z,r)頂点 `(0,0),(3,0),(3,2),(1,2),(1,1),(2,1),(2,.5),(0,.5)` を
  各座標0.03 m倍した単一輪郭。独立矩形分解から選んだ内部11点。

いずれも実測構造ではない。参照プローブは軸・壁・角を避け、形状から明示指定する。

## 再現

[検証専用環境](DEPENDENCIES.md)で実行し、未使用の出力先を指定する。

```bash
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src /tmp/superfish-g02-reference/bin/python scripts/compare_contour_ngsolve.py --out out/g02-independent-new
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src /tmp/superfish-g02-reference/bin/python scripts/compare_contour_ngsolve.py --cases folded --sizes .0015 .00075 .000375 --out out/g02-folded-fine-new
```

NGSolveは検証専用であり、一般輪郭の製品メッシュ生成に追加する依存ではない。
G02全体の製品入力/保存/CLI/GUI、自動生成公開はまだ未完了。
