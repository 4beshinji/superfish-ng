# S02: 軸接続磁静の境界付き実FEM・元場/磁束

2026-09-13 JST。正則a=Aphi/rの弱形式を実電流源問題へ接続する限定課題。[実装記録](AXIS_MAGNETOSTATIC_SOLVE.md)の専用API範囲で限定受入。

- 全境界へaxis_regularity（r=0のみ）、固定Aphi/r[T]、向き付き接線Ht[A/m]を明示する。r,z面の接線は領域を左に置く向き、法線は右側。穴境界は時計回り。
- Br=−r∂z a、Bz=2a+r∂r aより、自然境界荷重は**+2π∫r²Ht Ni ds[A m²]**。平面Azとは符号が異なる。固定aは基準gaugeに変換せず、実係数として解く。
- 軸上aの自由度を残す。軸接続の正則空間はAphi=C/rを含まず、全非軸境界Htでも一意に解ける。軸非接続と純スカラーgaugeの問題とは区別する。
- 元Aphi/r[T]・Aphi[Wb/m]・Br/Bz[T]・Hr/Hz[A/m]、片側mu_r/材料情報を保持し、軸のAphi=Br=0と有限Bzを検査する。混在bool/領域外を拒否する。
- 全回転体の∫B²/(2mu)dV[J]、境界磁束2π∫r B·n ds[Wb]を評価する。反力は固定aに共役な[A m²]、元場の対応積分は+2π∫r²Ht dsであり、通常の電流[A]と混同しない。
- 離散仕事と定数試験関数の恒等式を検査する。元HのAmpere診断は∮Ht ds+∫Jphi drdz=0（r,z向きとJphiのcurl符号による）。軸境界もHt積分へ含める。
- 一様軸方向磁場を固定aと指定Htの双方で照合する。半径R内に一定Jphi、外周Ht=0の解析場Hz=Jphi(R−r)、a=mu*Jphi(R/2−r/3)で、P1/P2・源反転・mu/幾何尺度・エネルギーを検査する。
- 半径方向二層mu/JphiのH連続と、aに含まれる1/r²成分を独立積分で参照し、a/Aphi/B/H・エネルギー・H周回積分を別々に細分判定する。軸を除いた領域のgauge実装を兼ねたとは扱わない。
- 既存標準周波数/RFと静電/平面磁静を保持する。解析式によるFEM置換・補正は行わない。

有限に宣言した軸接続領域。保存/CLI、一般外部境界診断、軸非接続、曲線、非線形/異方性/永久磁石、巻線インダクタンスは後続工程。新規依存・外部資料・旧版実行なし。S02と全計画は未完。

独立系列は一様B32例・円筒電流32例（穴0/2を含む）・二層電流24例の88例。一様B/円筒製造解は相対差1e-10、尺度/mu則1e-10。二層ではP1のn16/32/64、P2のn8/16/32を用い、独立4×4求積でa/Aphi/B/H/U/元H周回誤差を分離する。最細許容差はP1 [1e-3, 1e-3, 2e-2, 2e-2, 1e-3, 2e-2]、P2 [1e-5, 1e-5, 1e-3, 1e-3, 1e-5, 2e-3]、各量の単調改善を要求する。二層の境界磁束はP1 2e-3/P2 2e-5以内。値を緩める代わりに必要な場合は細分を増やす。
