# RF合格・表面未達時の明示的な一様細分方針

2026-09-09。RFA-6改善の決定と実装。[詳細と検証](CURVED_RF_SURFACE_POLICY.md)。既存の合成回転楕円体では、RF三量が合格しても
Epk/Eacc差が約2.4%で停滞し、R/Q指標による局所選択を続ける費用が大きい。
形状や五量許容差を易しい条件へ変えるのではなく、表面未達時の進め方を明示して比較する。

版5の既存request・保存済み判断は維持する。任意の`surface_refinement_policy`で
従来の`rf_goal`と新方針`uniform_when_rf_passes`を区別し、未指定は従来挙動とする。未知の選択値は拒否する。
Caseの物理や規格化は変えない。

新方針は次のとおり。

1. 一様確認の個別追跡・積分・五量が検証済みであることを先に確認する。
2. RF三量が合格し表面量だけ未達なら、確認解を次の細分の親として採用する。
   これは停止判定の合格ではない。連続一様確認の合格回数は0に戻す。
3. その親から一様細分を続ける。RF三量も未達なら従来の元親からのRF局所選択を使う。
4. TARGETS_METは従来どおり、連続2回の一様細分で五量全てが合格した場合だけ。
   親への採用と、五量停止の合格を混同しない。

受入には、未指定の旧文書完全一致、未知指定拒否、E/B各々の未達で合格回数0、
RF未達時の元親分岐維持、追跡/積分未確認拒否、全solve予算、保存再開とnative replayを要する。
元の非球形両尺度・初期写像・五量許容差を維持し、同じ追加一様対照との差、
親子Ritz、Maxwell、体積、全workflow費用を実計算で比較する。
GUIでは方針と採用/未達を明示する。確認未達を成功へ読み替える実装にはしない。

単体検査・実CLI・非球形両尺度6イベント・実Chrome19項目・標準689件を確認した。
限定した実装と例題を部分受入。一般精度/効率と親N04は未完了。
従来方針の長時間実行の完走を、新方針の結果から推測しない。
