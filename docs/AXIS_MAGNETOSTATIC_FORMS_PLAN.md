# S02: 軸に接続した磁静場の正則な材料・電流・弱形式

2026-09-13 JST。平面磁静nativeの検証と独立に進める次の限定課題。[実装記録](AXIS_MAGNETOSTATIC_FORMS.md)の正則弱形式API範囲で限定受入。主5unit/独立72例と標準1181件もPASS。

直線のAxisConnectedMesh（明示穴を含む）で、Aphi=r*a、a[T]をP1/P2の未知数とする。B_r=−r∂z a、B_z=2a+r∂r aを用い、r=0でも有限な場を構成する。定数aは一様B_zであり、平面Azの定数gauge核を移植してはならない。

- 正値実数mu_rと全セルの材料所有、全領域の符号付きJphi[A/m²]を明示する。軸非接続・曲線・非線形/異方性/永久磁石はこの段階で拒否する。
- K=2π∫ν r[(r∂z Ni)(r∂z Nj)+(2Ni+r∂r Ni)(2Nj+r∂r Nj)]drdz [m⁴/H]、f=2π∫Jphi r² Ni drdz [A m²]を組み立てる。体積は2πr drdz、U=∫B²/(2mu)dV [J]。
- 軸aの自由度を保持する。aの定数を零モードとは扱わず、行列の正値と一様Bのエネルギーを独立に照合する。軸非接続のAphi=C/r gaugeをこの空間で解決したとは主張しない。
- Jphiの断面積分[A]と、aの源仕事に対応する2π∫Jphi r²drdz[A m²]を区別する。符号相殺、源反転、材料/領域順序・厳密JSON往復を検査する。
- 一定a係数で幾何をs倍するとK∝s³、f∝s⁴。muをm倍するとK∝1/m。z移動、穴0/1/2、材料パターン、P1/P2で確認する。
- 独立18×18 Gauss/Vandermonde積分、長方形から穴を引いた解析モーメントで、定数/r/z/r²/rz/z²の磁気エネルギーと源仕事を照合する。比較誤差1e-11以内、求積次数差/仕事和5e-12以内を要求する。
- 標準周波数/RF、平面磁静・静電の既存機能を保持する。

境界付き軸対称磁静解・元場/磁束の出力・保存/CLI、外部境界診断、軸非接続は後続工程。解析式は検証専用。新規依存・外部資料・旧版実行なし。S02と全計画は未完。
