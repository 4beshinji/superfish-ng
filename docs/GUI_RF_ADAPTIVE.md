# RF適応版5のGUI

2026-09-09。[版5の実行・保存再開](CURVED_RF_ADAPTIVE_REFINEMENT.md)をGUIから扱えるようにした。
確認方式で版5を選び、現在の二次曲線Caseからstrict requestを作成して実ジョブを開始する。
高次積分・曲線の最小角・五量の条件を保持し、通常の追跡/停止閾値は変更しない。

## 入力と予算

版5では「RF寄与の選択割合」と表示する。
全計算回数と今回追加する回数は、初期・未採用の一様確認・局所solveを全て含むと明記した。
版4/5は曲線頂点接線の角度と高次積分の入力を有効にし、版1の標本次数は無効にする。
版3以下の既存入力と版4の設定値を保持する。

## 分岐・確認・対象場

計算表に版5だけの「親計算」「採用状態」を追加した。画面の計算番号・親番号は1始まり。
initial / uniform_probe / rf_localを「初期」「RF確認」「RF局所細分」と表示する。
採用列、確認の総数、局所solve数、採用列の最終連続確認数、次に細分する親を表示する。
未採用の確認を最終採用解と混同しない。

五量ゲートは確認イベント自身の親比較から作る。版5のdecisionは最後の比較だけを持つが、
最終一様確認の親も採用済みの確認なら、その比較を前の区間として表示する。
直前の局所分岐を別の確認区間に読み替えない。比較元/先を画面に明記し、
確認が1回だけなら前区間は未評価のままにする。全イベントの高次積分表も表示する。

対象場の選択を追加した。版5は最後の採用解、従来版は最後の水準を初期選択する。
未採用の確認場も明示的に選べる。場を開く直前にcheckpointを再検証し、
選択したイベントのnative出力と追跡モード順位で開く。
版5の曲線結果に直線用表面評価を適用するボタンは無効にする。

保存文書を開くと、版・入力・分岐・選択候補・ゲートを復元する。
中止操作は既存のジョブ一覧を使う。中止後は完了済みcheckpointを開き、
その保存条件・元親から続きを計算できる。入力欄の後編集を再開へ暗黙に適用しない。
