# S04: 軸接続P1の非線形B-H弱形式

2026-09-13 JST。後続限定課題。[実装記録](AXIS_BH_FORMS.md)の軸接続P1弱形式API範囲で限定受入。

正則なa=Aphi/r[T]を持つ直線の軸接続メッシュと等方単調H(B)表を接続する。領域/来歴と全Jphi[A/m²]、Bphi=Hphi=0の軸対称モデルを明示する。全軸DOFを保持し、Br=−r a_z、Bz=2a+r a_r、H=h(|B|)B/|B|を元場とする。一定aは一様Bz=2aであり、gauge核として除去しない。軸上Aphi=Br=Hr=0を構成則と形状関数で満たす。

測度dV=2pi*r dr dzでg_i=∫B_i·H dV[A m²]、K_ij=∫B_iᵀ(dH/dB)B_j dV[m⁴/H]、fJ_i=∫Jphi*r*Ni dV[A m²]を分離する。U/U*[J]、元B·H、a·gと一定a試験∫2Hz dVを別に検査する。断面電流∫Jphi dr dz[A]と源仕事の径方向モーメントを区別する。

P1でもBはセル内一次で、非線形H/接線/エネルギーは一般に多項式でない。明示した固定正値求積を使い、同一求積でU、g、Kの微分関係を保つ。次数qとq+4の差をK/g/U/U*ごとに報告し、差を場の誤差上界や単なるNewton残差へ読み替えない。求積点だけでなくセル頂点のBを確認し、元P1場の最大|B|が表範囲内であることを保証する。表折点の接線は材料APIの片側規約に従う。

受入は一様軸場の解析U/U*と非零一定aエネルギー、零場、旧線形軸P1とのK/f一致、元H/実接線の独立Vandermonde/Decimal対照、U→g→Kの独立変分、軸DOF/材料所有/穴付き領域、幾何尺度・z移動・H表倍率・符号反転を含む。場が同じなら幾何s倍でK/g/U/U*はs³、固定JphiのfJはs⁴。非線形求積の次数差を一様場の厳密積分と分離して記録する。境界付きNewton/保存/CLIは後続。標準と旧周波数/RF差を含めて限定受入する。
