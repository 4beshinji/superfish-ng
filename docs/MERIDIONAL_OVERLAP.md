# 同一真空領域の元要素共通分割

[計画](HPHI_OVERLAP_PLAN.md)の幾何工程。固定候補608sourceを主ツリーへ統合し、以下の範囲で限定受入。

`meridional_overlay(previous, current)` は検査済み `MeridionalMesh` または `AxisConnectedMesh` を受け取り、
各共通小三角形の元要素ID、両側の元局所順による重心座標、物理(r,z)座標と正の面積ヤコビアンを返す。
配列の測度はdr dzである。2πrや場の位相・単位は後続の物理積分で明示する。

入力座標のbinary64値を厳密な有理数として扱う。外周の同一直線上の分割点と開始点を正規化し、
全穴の集合が一致することを確認する。境界分割・穴の順序・節点/要素番号・内部三角形分割は独立。
凹形や傾斜辺、全z幅より短い真空軸も扱う。穴や軸区間の欠落、微小な形状差を許容差で吸収しない。
各元三角形の被覆を有理数で検査し、全体の面積一致だけでは合格にしない。

候補探索の木/葉比較を `max_candidate_tests`、入力要素数と生成小三角形数を `max_overlay_triangles` で制限する。
既定はそれぞれ2,000,000と250,000。予算超過や有限の正面積で表現できない分割は明示拒否する。
戻り値の配列はread-only。このAPIは物理Caseの同一性、FEMの精度やモードの対応を判定しない。
