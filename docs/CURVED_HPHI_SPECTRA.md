# 曲線Hφの有限比較スペクトル（H13-bの途中段階）

`curved_hphi_spectral_resolution`は元の曲線固有場を明示比較空間へ質量射影し、比較演算子の近傍固有値の周波数区間を返す。元の周波数や場は変更せず、比較固有値を元の解へ代入しない。E/H部分空間追跡・永続ID・調整への接続は未完了で、H13-bを完了扱いしない。

## 条件と意味

元solutionを宣言caseから再検証し、全native幾何・空間・最低正固有スペクトルとの整合を確認する。比較は明示`same_vacuum`二次領域だけで行い、形状変換を受け入れない。両native分割は完全な有理数chartで同じ参照領域を覆い、丸めた細分は版2の明示契約を満たす必要がある。

比較空間は元以上のP1/P2次数、より多い要素数、より小さい最大セル径を要求する。セル径は頂点だけでなくP2 Bernstein制御値全体を包むbounding boxの対角長。元と同じ幾何でも同じメッシュを「より細かい」と扱わない。

[scalar質量射影](CURVED_HPHI_PROJECTION.md)で得たvと、比較nativeのK/Mから`T=(K+sM)^-1 M`、`s=1/area`を構成する。`λ=(2πf/c)²`、`μ=1/(λ+s)`として`δ=||Tv−μv||_M/||v||_M`を直接求める。有限自己共役演算子について、厳密算術ではμから有限スペクトルまでの距離はδ以下。実装はδに`1e-10 μ`を加え、逆変換して周波数区間を報告する。

これは浮動小数点残差とpaddingを用いる診断であり、認証された包含区間、固有値順位の分離、連続問題の離散化誤差上界、モードIDではない。比較固有値の直接計算を本API内では行わない。独立試験だけが密行列固有値を使う。

qの定数静的零空間は比較演算子内に残す。区間がその零値に到達する場合、上端が有限でない場合、元scalar場の射影損失が宣言上限を超えた場合は`UNVERIFIED`。uでは軸DOFを保持する。正の射影ノルム・線形残差1e-10・全中間量の有限性を検査し、未分解ならエラーで停止する。射影側の幾何・DOF・共通分割・求積点予算も適用する。
