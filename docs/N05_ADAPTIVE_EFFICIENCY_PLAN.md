## 精度の共通条件

全ケースでSI/peak phasor、U=1 J、beta=1、sigma=5.8e7 S/mを固定する。
f=1e-4、両R/QとG=0.005、Epk/Eacc・Bpk/Eacc=0.01。
ピークは元離散上下界の両端/最悪変化を評価し、推定値だけの一致に置き換えない。
加速器/回路R/Qのfactor2、全PEC壁積分・Ue/Umと求積差を個別に保存する。
物理参照の場目標はE/Hφの全領域相対L2=0.005、物理軸Ez=0.01。
丸め参照は全五モードを保持して実TM sector/HφでIDを識別する。
単一符号をE/Hに共通適用し、振幅のfit・領域縮小・標本の削除をしない。

両方式とも最後の二つの全域細分区間で量別条件を確認する。
適応は既存のuniform_two_stepsへ移った後も未達なら全域確認を続ける。
一様はすべて全域細分なので最低三水準を必要とする。
到達した最初の物理参照精度水準と、二区間/全域確認まで完了した水準を分ける。
同一幾何・面積/回転体積、完全P2親子境界、個別ID、Ritz単調性、積分比較を別ゲートにする。
場/RF/peakは周波数や代数残差の合格で代用しない。
幾何近似のN03証拠をFEM差へ混ぜず、physical_error_boundはnullを維持する。

既存追跡設定は各元対照内で両方式同じものを用いる。
新丸めはoverlap=0.98、margin=0.05、cluster gap=1e-6、最小相対特異値=1e-8。
円筒はnested_affine、曲線はnested_curved。細分種別を保存し、未解決ID/guardなら非成功停止。
元球のhistorical overlap=0.95を新丸めの0.98成功へ昇格しない。

## 回数・資源・測定境界

各ケース各方式の独立実行は**2回**。同時に動かさず、反復1は一様→適応、
反復2は適応→一様。全3ケース×2方式×2反復=12実行。
新プロセス、同一uv環境・commit・CPU、OPENBLAS_NUM_THREADS=1。
N03の全検証など他の重い計算が終端してから開始する。
Python/NumPy/SciPy、CPU、実visible memory、OS、時刻・実行順・ソースhashを保存する。
GPUは使わない。import/mesh生成・全規格化/保存/再構築を両側で同じ計測境界に入れる。

| 上限/設定 | 両方式で実行前に固定する値 |
| --- | --- |
| 初回を含むmax_levels | 8 |
| 全要素上限 | 250000、Case側が小さければその小さい値 |
| 壁時計上限 | 各独立実行3600秒、途中停止も元成果物を保全 |
| メモリ上限 | 各プロセス32 GiB、RSSの実測超過を非成功として記録 |
| 適応bulk_fraction | 0.5、元二乗残差指標を使用 |
| 元最小角/曲線corner angle | 5度。Case/元mesh側の厳しい条件を保持 |
| 曲線基底求積/高次比較 | 元次数12 / 24、relative tolerance=1e-6 |

一様側でも局所指標の選択費用を架空に加えず、実施した処理を記録する。
計測はmesh生成、組立、固有値solve、規格化/RF/peak、残差指標・mark/適合化、
個別ID追跡、求積増次数、保存/再構築、全域確認を分け、重なる区間を二重加算しない。
内側のsolve秒とプロセス全体秒・最大RSSを別報告する。
過去のJob metadataに時刻がないときはUNKNOWNを維持し、推定秒で埋めない。
独立参照の準備/lookup費用は共有費用として別欄に保持し、片側だけを無償にしない。
「FEM経路の時間」「同じ最終参照検査を含むend-to-end時間」を両方出す。

最初の反復の成功済み結果を二回目のnative計算として再利用しない。
品質・ID・予算・solver失敗、LEVEL_LIMIT/REFINEMENT_LIMIT/QUADRATURE_UNVERIFIED等は
実状態・到達DOF・費用・欠測量を残し、範囲を後から広げて初回失敗を消さない。
独立中止を正常完了や精度達成として集計しない。

## 出力と判断

N06の新 `scripts/validate_adaptive_efficiency.py` は各ケース/方式/反復の元要求・全native、
全水準/個別ID/量別誤差・離散区間・停止理由・環境・hash・段階費用を新outへ保存する。
誤差対DOFと誤差対時間の曲線を分け、五量と元場を一つの指標に潰さない。
二回の測定値と範囲を併記する。過少な反復から統計的な一般優位を主張しない。
同じ物理精度と全域確認を達成した点どうしだけでDOF/時間/メモリを比較する。
達成点が存在しなければ効率比較は未確認であり、最終値だけを並べて勝者を作らない。
検証手順/物理精度のPASSと、効率改善の有無を別条件にする。

旧球では初期85 DOFで既に解析五量の目標内、一様は1201 DOF/33.298秒、
適応は2661 DOF/118.974秒だった。全体時間には検証回数の違いがある。
この [旧非優位の実測](CURVED_REFINEMENT_EFFICIENCY.md) を維持し、新条件で上書きしない。
N05は比較仕様のみの受入。N06の実精度/費用、N07の測定後の修正採否、N08/N04の監査は後続。
