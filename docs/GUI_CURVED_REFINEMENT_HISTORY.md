# 曲線細分履歴のGUI編集

2026-09-09。N04の限定したGUI接続。二次曲線要素のCaseを開くと、
`mesh.curved_refinement_steps`を順序付き表へ復元する。以前は読込後の
`collect()`が一様段数しか出力せず、保存/計算時に局所履歴を落としていた。
独立した受入不変量は、入力履歴・保存文書・実FEMのCaseとメッシュの一致である。

「順序付き細分履歴」で一様/選択段階を追加し、上下移動・削除できる。
選択段階の要素番号は、その段階の直前メッシュでの0始まり番号をカンマで指定する。
重複・負数・非整数・安全整数範囲外・空欄を拒否し、最小頂点接線角は
0度より大きく60度より小さくする。実メッシュにおける番号範囲・品質・予算は
既存のstrictな計算経路で検証する。形状や初期メッシュを変更した場合、番号の意味を再確認する。

「一様細分の段数」と履歴は排他で出力する。明示履歴が空なら保存/計算を拒否する。
履歴を選んだまま幾何次数を1へ変更しても黙って削除しない。
一様段数だけの旧Caseを開くと、前の表を消去して旧方式へ戻る。
要素の図上選択、履歴対応Study、一般形状の精度/効率は今回の対象外であり未受入。
