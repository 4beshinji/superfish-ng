## 受入軸と対象の決め方

Fは要求された物理・機能、Iは入力変換・拒否、Oは規約を保つ保存・出力、
Nは独立参照・収束、WはCLI/Python/GUI等で操作が完結すること。
F/I/O/N/Wを別々にPASS、FAIL、UNVERIFIEDで記録する。
N/Aには適用しない理由が必要。未知の仕様・参照不在はUNVERIFIEDでありN/Aにしない。

優先度Aは初期RFの開発必須、Bは追加物理の開発対象、Cは対象版で採否調査、Xは別計画。
A/Bの製品実装を進めることと、旧版で同機能を確認したことを区別する。

## C02へ渡す限定TM入力辞書

最初の受入は単一REG、軸接続真空、閉PEC、z非減少壁、直線/短円弧。
幾何はNGのCaseへ変換し、NGのFEMで解く。旧の入力制御を黙って捨てない。
下表の「記録」は変換レポートへ原値・意味・適用差を残す意味であり、現時点で実装済みではない。

| 入力 | 仕様根拠と限定変換方針 |
|---|---|
| REG/PO、$または&の区切り | R25 VI冒頭。行/列位置を保つ字句解析。未知namelist、重複変数、配列・式は初期版で拒否 |
| KPROB / ICYLIN | 表VI-1。最初は明示1/1のみ。静的場・平面RFへ誤配しない |
| CONV | VIの座標単位節。cm/入力単位。省略はcm、長さをCONV×0.01でSIへ。一方、場単位はCONVで変わらない |
| X / Y | 表VI-4。RFではz/r。初期版は両方明示、X0/Y0、極座標は未対応として拒否 |
| NT / RADIUS | 表VI-4。NT省略は1。4/5は端点と半径、ccw/cw。2/3はG03の受入まで拒否。Rを4/5の半径別名と解釈しない |
| NBSLO / NBSUP / NBSLF / NBSRT | 最初は保存AFで確認した0/1/1/1を明示要求。軸Hphi=0をu=0に変換しない。半領域は別受入 |
| MAT / MT / POA / 複数REG | MAT省略または1だけ。その他は材料・領域・源物理の実装まで拒否 |
| DX / DY | 長さ単位を換算。旧と同じ節点配置を約束しない。NGのメッシュ指定へどう写すかC02.Sで確定し、元指定を保持 |
| FREQ / EPSIK / XDRI / YDRI | MHzの探索初期値・旧反復条件・駆動点。NGの固有値探索と同じではない。無適用なら明示的な変換診断が必要 |
| BETA / KMETHOD / ZCTR | 初期版はBETA=1、KMETHOD=1、ZCTR=全長中央を明示要求。一般化はR01の区間・位相契約へ接続 |
| SEG FieldSegments | 実金属面全体の損失が必要。AFだけからSEGの一部選択を推定しない。読込対応までは全壁評価の差を記録 |

DXのNGへの写像、探索条件のユーザー指定方法、AF単体で未指定の導電率・正規化はC02.Sの残件。
旧の暗黙値を新しい数値精度の保証にしない。旧初期値FREQを解くべき固有周波数と解釈しない。

## 合成受入ケースと判定

1. TM円筒: SIとcm、CONV付き寸法の等価性、面積RLと体積πR²L、Bessel周波数/場/RQ/G。
2. 段差: 輪郭面積・体積の区分積分、垂直PEC面を含む壁損失、canonical JSONと同一離散解。
3. 短円弧: 半径・接線・向き、NT=4/5、円弧原形と弦近似を区別し幾何細分を別評価。
4. 入力拒否: 複数REG、未知変数、重複、材料、異なる境界、未対応曲線、非有限数、未閉鎖輪郭。
5. 出力: SFOの軸Ez絶対値を高次モードの符号付き場と混同しない。SF7のcm/MV/m/A/mをSIへ変換。
6. 操作: 旧入力→変換診断→NG計算→保存再読込。失敗時に成功出力を作らず元入力を保持。

数値ゲートは既存比較のf 0.1%、Q0/G/TTF 0.5%、RQ/軸Ez L2 1%を初期参照とする。
各側の収束も同じ量で評価。高精度・ピークの課題では計画の別基準を使う。
近零量の絶対尺度やケースごとの例外は各.Sで先に固定する。今回これらの新ケースは未実行。

ログは `/tmp/superfish-compatibility-baseline-20260907.log`。skipはNGSolve参照環境専用。
物理・製品コード変更なし。既存の数値検証結果を今回の新規実行と呼ばない。
