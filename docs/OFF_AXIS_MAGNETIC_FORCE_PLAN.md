# S05: 軸を含まない軸対称磁場の軸方向力

2026-09-13 JST。後続限定課題。[実装記録](OFF_AXIS_MAGNETIC_FORCE.md)の専用API範囲で限定受入。

最初の軸対称力はr>0の閉じた直線断面、線形スカラーOffAxisMagnetostaticSolution P1/P2、m=0のpoloidal磁場に限る。元ψ=r Aphi[Wb]の実FEM再求解と基準/係数の一致を確認する。対象は断面を一周回転させた実際の軸対称物体で、出力Fzは全周の[N]。平面の[N/m]を流用しない。

対象全セルw=1、外部境界w=0、他の源/非真空材料w=0、変化する全セルはmu_r=1/Jphi=0の真空。元のBr/Bzから真空Maxwellテンソルを作り、Fz=−∫2πr*(Tzr*dw/dr+Tzz*dw/dz)dr dzを評価する。全周で横方向ベクトル力と軸まわりトルクは軸対称性により零であり、半径方向の応力/圧力を物体全体の横方向力と表示しない。今回のAPIはFzだけを受け入れる。

独立仮想仕事は同じP1重みの±z並進で、r座標、外周、他の源/材料を固定する。対象は全周の剛体軸移動であり、meridional断面の回転を三次元剛体回転と扱わない。各領域の∫Jphi dr dz[A]と全周体積を保持し、元のψ荷重を用いた全周停留ポテンシャル[J]の−dΠ/dzを実FEM再求解で評価する。基準ψの定数による源仕事も保持し、真の固定電流から外れない。

独立解析対照はr>0矩形箱の中央高さにある有限電流領域と外部Br=C/r、Bz=0。ψext=−CzはP1/P2で表現でき、上下の固定ψ、両径方向側のHt=0で与えられる。電流・箱・重みをz鏡映対称にすると自己Brは奇、自己Fzは零。外部力はFz=−2π C∫body Jphi dr dz。解析係数をソルバーへ代入せず、外部境界値と有限電流から実FEMで求める。

応力の交差項は弱形式の∫(1/r)gradψself·gradwに一致するため、同じ元FEMの有限電流積分との独立不変量になる。自己/外部場の対称性、電流反転、C反転、長さ尺度、基準ψ変更、対象mu_rの変更と仮想仕事を別条件として検証する。1/rを含むため既存off-axis FEMの求積契約4..32/既定16と+4比較を継承し、求積差・メッシュ差・重み差・変位刻み差を分ける。

実装前の開始条件は解析電流力1e-9、実±z変位差分/応力1e-5、16/+4求積差1e-10。最初の物理不変量の失敗を保持し、必要なら実際の細分/求積改善を行い、許容差を緩めない。零電流、反転、基準ψ、厳密真空判定、不正対象/重み、改変した元係数と軸r=0の拒否を検査する。

標準回帰と既存周波数/RF差の後、専用APIのみ限定受入する。軸接続ケース、B-H/反跳材料、保存/CLI、GUIへの軸対称力受渡しは後続工程。Br=C/r対照はr=0で使えず、軸接続の受入へ流用しない。既存の公開Maxwell式と自作ψ弱形式から導出し、新規外部資料・旧版コード/データ・依存は導入しない。

先行設計試作ではI=10 A、C=.0625 T mで解析Fz=−3.926990816987 N。元実FEMのP1/P2について16/20次数応力と、1e-5/5e-6 mの実±変位ポテンシャルが既定の1e-9/1e-5条件を満たした。試作はout/off-axis-magnetic-force-design-probe-20260913にCase/重み/結果と自作スクリプトを保持する。製品API・全体回帰・軸接続の受入ではない。

独立検証の最初のP2/q4/n8は、元FEMの1/r行列比較5e-12条件で拒否された。n16細分で求解と軸力1e-9を満たすため、求積4/8/16/32比較は全て同じn16メッシュへ変更し、n8/16/32のメッシュ系列とは分ける。元FEM・応力/仮想仕事コードと許容差は変更しない。n8の拒否とn16の成功を試験に追加し、最初の出力と改訂出力を別ディレクトリへ保存する。
