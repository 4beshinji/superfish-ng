2026-09-14 JST、N04残件4の限定拡張。
[曲線寸法の法則](CURVED_HARMONIC_STUDY.md)と
[初期メッシュ置換計画](CURVED_PROJECT_REMESH.md)をStudy版4で結ぶ。
受入条件は値の区間規則・元形状対応の保持・全宣言の事前検査、
通常/保存追跡/逐次・適応再開、独立幾何/周波数/RF/場形とGUIの一致。

## 入力と値の区間

`study_version: 4` は `kind: "curved_remesh_sweep"` 専用。
版3の `project`, `parameter`, `parameter_unit`, `values`, `geometry_coefficients`,
`rf_coordinates`, `minimum_corner_angle_deg` に、必須の `mesh_schedule` を追加する。
版1/2/3へ新フィールドを混在させると拒否する。
合成例 [curved_remesh_study.json](../examples/curved_remesh_study.json) は二つの半楕円を変形し、
元26初期/146最終要素から、28初期/188最終要素の別メッシュへ切り替える。
KEK/LANLの実測構造を表さない。

区間定義は次の形。`plan` には省略のない既存の置換計画版1を入れる。

```json
{
  "schema_version": 1,
  "breakpoints": [0.75],
  "plans": [
    {"kind": "original"},
    {"kind": "replace", "plan": {}}
  ]
}
```

上の空 `plan` は形式説明のための記号であり、実行可能な入力ではない。
実行には携帯可能な合成例、または [remesh-plan.json](../examples/curved_project_remesh/remesh-plan.json) の完全な内容を使う。

- 境界値は変数と同じ単位（`1` またはSIの `m`）の有限数で、厳密昇順。
- 計画数は境界値数+1。境界と等しい値は右側の計画を選ぶ。
- 例では x<0.75 が元、x>=0.75 が置換。逆順・再訪・適応二分でも同じ規則。
- 境界値の空配列は全値に一つの計画を適用する。少なくとも一つの置換計画が必要。
- 全計画を元形状上で検査する。指定値が使わない計画も無効なら拒否する。

全ての置換メッシュは**元Projectの形状上**で与える。変形済みのメッシュを計画へ入れない。
計画ごとに新しい細分履歴を明示し、新marked選択を元形状上で固定する。
元marked番号/履歴を別接続へ読み替えない。
未知キー、重複JSONキー、未知kind、bool/非有限数、順序/個数不整合、
不正なメッシュ/履歴・予算・品質・二次境界差は拒否する。

## 実FEMメッシュと形状の対応

各点は前の点からの累積変形ではなく、元入力から独立に作る。
区間の計画から選んだ元または置換Projectを、版3と同じ曲線法則・調和変位で変形する。
比較用Projectは常に元Study Projectをその実際の値へ変形して作る。
これにより比較用の接続/固定履歴は共通で、実FEMは独立の接続/履歴を使える。

置換の元形状だけでなく、指定された各変形点で実FEMと比較用Projectの二次境界全体を照合する。
共通の曲線パラメータ区間でBernstein係数を比較し、既存の丸め誤差条件を維持する。
解析曲線の一致だけでは二次有限要素領域の一致としない。
元/置換の正Jacobian・角度・品質/細分予算は各構築段階で検査する。
出力ディレクトリは全計画と指定点の検査後に作る。

通常結果は独立スペクトル、`comparisons: []`, `numerical_status: "UNVERIFIED"`。
同じ周波数順位に同じモードIDを付けるものでも、固定領域の収束判定でもない。
保存追跡/逐次/適応は既存の `piecewise_remesh` 閾値を受け取り、
手動 `comparison_meshes` を拒否して実比較点から元形状の対応を導出する。
元要求には全区間計画を保持し、履歴には実際に導出した比較メッシュを保存する。

適応実行は厳密単調の値、最大深さ/試行数/最小幅を要求する。
0→1が拒否されて0.5を挿入すれば、0.5の区間を改めて選ぶ。
保存再開も全宣言と実計算点・native場を再構築して検証し、計画/境界値/元場の改変を拒否する。
離散的なメッシュ切替で追跡閾値を満たせない場合は、拒否履歴と未達点を保持しUNVERIFIEDで停止する。
切替を消すための閾値緩和や物理枝の自動確定は行わない。

## 操作

```sh
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m superfish_ng study \
  examples/curved_remesh_study.json --out out/new-curved-remesh-study
```

保存追跡/逐次/適応の外側要求・checkpoint形式は変更せず、内側Studyを版4とする。
GUIは「曲線形状と初期メッシュの掃引」を選ぶ。
版3と共通の寸法法則・単位・RF座標・角度欄と、区間計画のJSON欄を使う。
置換計画ファイルの読込では、指定した切替値の前を元メッシュ、以後を置換とする定義を作る。
複数の区間はJSONで明示できる。ファイル読込時点では入力準備だけを行い、保存/実行で全計画を検査する。
法則・区間・読込計画は文字列のまま厳密readerへ渡し、重複キーを保持して拒否する。
非同期検査/読込中に入力が変われば、その旧応答で現在の定義を置き換えない。
