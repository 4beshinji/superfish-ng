候補の `coincident_circle_arcs` は、既存の円オフセットモデルで中心と非零支持半径が一致し、相対回転が厳密な四分の一回転となる場合を分類する。正規化した回転ベクトルへ符号付き半径の符号を掛け、内積/外積が厳密な正負置換に一致することを有理数で検査する。二進回転のノルムを1へ丸めない。

両有限区間を元の角度へ戻し、相対回転を qπ/2 とすると、共有点は `θ1 = θ2 + (q + 4k)π/2` を満たす。角度差の有限範囲とπの区間から、可能な整数kの全範囲を囲む。各周期の移動区間について、離隔、正の長さの重なり、厳密な共有端点、未確認を記録する。周期をまたぐ二つの重なり成分も保存する。

πの囲い込みは `π = 16 atan(1/5) − 4 atan(1/239)` を有理数の交代級数と次項の剰余で評価する。加法関係で `tan(4 atan(1/5)) = 120/119`、さらに `atan(1/239)` を引いた角の正接は厳密に1で、その角は第一象限にある。この関係から式を導出した。有限二進数の `math.pi` を真の周期や端点等号へ置き換えない。

全周期の判定が済んだ場合だけ `finite_domain_complete=true` とする。正の長さの重なりではパラメータ対/中心点とも無限、共有端点だけなら中心点1、離隔なら0を返す。πを含む非零の位相差を有理数端点の等号へ丸めない。幅/項数の予算不足では既存の共有パラメータ証拠または支持円一致だけを保持し、有限領域の完全性は未確認とする。潰れた円は既存の別分類を継続する。
