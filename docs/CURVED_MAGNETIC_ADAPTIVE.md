# 磁気対称半球の適応停止と追加対照

2026-09-09。前段の[対称半領域対応](CURVED_ADAPTIVE_SYMMETRY.md)で未検証だった
磁気対称の最終停止を確認する。数値コアはbfa48f4から変更しない。
電気対称で検証した合成半球の要求を使い、境界タグを磁気対称へ変更する。
実測空洞ではない。元半領域のR/Q・Eacc・位相/積分区間を保持する。

`scripts/validate_curved_magnetic_adaptive.py --out 新規ディレクトリ --electric-evidence out/curved-adaptive-symmetry-initial-20260909`
で実行する。入力は尺度1/2の指定半球・単一対象モードに限定し、
f=1e-4、RQ/G=.005、E/Bピーク比=.01の閾値を変更した要求も拒否する。
適応の予算は元要求の8水準・20000要素、Caseの生成上限は250000要素。
後者は追加対照にも適用される。許容差や予算を自動的に緩めない。

実適応の最終checkpointは固有値再計算を禁止して全保存文書と照合する。
TARGETS_METの場合、その固定二次領域に一様細分を1回追加して実FEM/native保存する。
同じモードの追跡・高次積分と五量差を確認する。この追加対照との差は絶対RF誤差ではない。
両尺度の全水準でfの1/2則と、R/Q・G・ピーク比の不変を確認する。

初回 `out/curved-magnetic-adaptive-initial-20260909` は両尺度PASS。
その後、検証スクリプトの形状・対象モード・許容差の入力条件を明示的に検査するようにし、
`out/curved-magnetic-verifier-rejections-20260909` の不正入力3種類を計算前に拒否した。
これらは検証スクリプトの改良で、数値コアや初回計算の条件の変更ではない。
最終 `out/curved-magnetic-adaptive-accepted-20260909` も両尺度PASS、終了0。
両尺度とも10→28→53→98→392→1568要素の6水準でTARGETS_METとなり、
追加一様対照は6272要素/12673自由度。全保存文書の再検証、追加対照の追跡・高次積分が合格。

| 追加対照との差（両尺度最大） | 値 | 条件 |
|---|---:|---:|
| 周波数 | 1.425e-8 | 1e-4 |
| R/Q（加速器規約） | 8.929e-5 | .005 |
| G | 8.703e-8 | .005 |
| Eピーク比 | 2.608e-4 | .01 |
| Bピーク比 | 5.050e-5 | .01 |

全適応水準の五量相似差は最大1.710e-14（基準2e-8）、要素系列も一致した。
初回と最終の数値報告は完全一致。最終ソースhashも照合した。
既存661件の標準検査対象ファイルは全て前回のhashと一致し、新規ファイルは本検証スクリプトだけ。
同一数値コアの全標準検査は重複実行せず、既存の659合格/2 skipを基準とした。
`baseline-source-comparison.json`にその範囲を記録する。

これで磁気対称の限定した最終停止・追加対照項目を完了した。
磁気対称モードの絶対RF解析誤差を検証したとは主張しない。
一般曲線/幾何誤差・一般精度/効率と親N04全体は残る。新しい物理式・外部参照・依存は追加していない。
