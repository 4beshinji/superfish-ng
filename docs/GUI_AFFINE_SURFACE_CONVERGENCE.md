# 直線表面収束評価のGUI

「直線要素の表面ピークの細分差を評価する」から、[直線表面収束評価](AFFINE_SURFACE_CONVERGENCE.md)を操作する。
評価は既存APIと同じ全native再検証・角診断・上下界比較を使用し、GUI専用の判定値を作らない。

## 操作

1. 適応細分の計算一覧から3水準以上の結果を開くか、そのチェックポイントを開いて再検証する。
2. 表面評価の対象IDを指定する。元の細分対象とは別のIDも、全水準で個別確認されていれば使える。
3. 「上の適応結果から表面評価する」を押す。
4. 結果・五量の個別判定・全水準のピーク上下界・元多角形の角診断を確認する。
5. 必要なら評価文書を保存し、再読込または「表示中の評価を再検証」を使う。

3水準に満たない場合は評価ボタンを無効にする。実際のID・native場・追跡・幾何はサーバーで再検証する。
改変文書、重複JSONキー、未確認IDや元場変更は拒否し、最後に再検証できた表示を保持する。
入力IDや上の適応結果を変更しても、表示中の評価は自動では変えない。新しい対象は評価を実行して確認する。

## 表示と判定

各水準の細分方式、対象順位、要素数、f、加速器規約R/Q=V²/(ωU)、Gと、
Epk/Eacc・Bpk/Eaccの上下界を表示する。内部の0始まり順位/水準は画面では1始まりに変換する。
全区間について五量の相対変化上限・基準・合否を表示し、最後の2区間を「対象」、それ以前を「履歴」と区別する。

| 評価状態 | 画面での意味 |
|---|---|
| TARGETS_MET | 基準達成（細分差） |
| CONFIRMATION_PENDING | 全域確認待ち。版2で最後の全域確認2水準が不足 |
| NOT_CONVERGED | 未収束。必要な細分差が基準外 |
| UNVERIFIED | 必要な量/区間が未確認 |
| SINGULAR_GEOMETRY | 再入角があり、有限ピークは未認定 |
| UNVERIFIED_GEOMETRY | 形状未確認でピークは未認定 |

版1は「局所差のみ・全域確認なし」、版2は全域確認2水準の有無を表示する。
元の適応判定も併記し、確認待ちを再開可能と解釈しない。上限停止済みの元計算はそのまま保持する。
角診断は元の輪郭を使い、再入角/凸角の数と解析曲線の弦近似の未確認も表示する。
差の達成を物理誤差上界や正則性の証明に読み替えない。
元適応のsurface_status=UNASSESSEDや停止判定を、この画面で書き換えることはない。

## 保存と場表示

保存ボタンはサーバーが返した検証済みJSON文字列をそのままダウンロードする。
再読込は元の全native保存先を必要とする。JSON単独で元の場を移送する機能ではない。
ページを再読込し、適応結果をまだ開いていない状態でも、保存した表面評価を再検証して表示できる。

「評価した最終水準の対象場・RFを開く」は表面評価を再検証してから、
その最終水準のmode_indexを使ってnative結果を取り込む。元の細分対象や順位1を暗黙に選ばない。
再入角・未収束でも確認済みの離散場は観察できるが、場表示は精度認定を意味しない。

```bash
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -p test_gui_affine_surface.py -v
superfish-ng gui --workspace out/gui-affine-surface-new --no-browser

```

厳密なフィールド・重複キー・改変評価/元ファイルの拒否を確認する。
実ブラウザーでは新規計算、全域確認待ち/達成、別IDの場表示、保存/再読込、
再入角/形状未確認/未収束の表示と、失敗時に直前の評価を保持することを検証する。
