# Hφの明示比較空間によるスペクトル診断

同領域の質量射影に続く、部分空間追跡のための有限行列診断。[有限比較空間の実装](HPHI_SPECTRAL_RESOLUTION.md)の範囲で限定受入。
元の専用Hφ解を完全再検証し、ユーザーが明示した同じ真空領域のより細かいP1/P2空間へ射影する。
比較先は三角形数増加・最大辺長減少・次数非減少を要求するが、入れ子空間は仮定しない。

正のs=1/断面積に対してT=(K+sM)^(-1)MはM自己共役。
元のlambdaに対するmu=1/(lambda+s)と非零の射影vを使うと、厳密算術で
dist(mu,spectrum(T)) <= ||Tv-mu*v||_M/||v||_M。
この残差から比較空間の近傍固有値の区間を計算する。元の固有周波数・係数・RFは置き換えない。

受入条件：

- 元解の最低正スペクトル・空間と同領域を再検証する。比較メッシュ・次数・予算・射影誤差の上限をstrictに検査し、宣言のない変形や自動メッシュ生成を行わない。
- 質量射影の直接誤差とノルムを保持し、比較先のシフト逆行列を実際に解く。線形残差・M残差、明示した丸め余裕から有限周波数区間を出す。
- 射影損失が上限を超えた列や、正半径で静的零モードへ区間が及ぶ場合はUNVERIFIED。区間が一つの固有値を捉えても順位の同定・縮退分離・連続問題の誤差上界とは呼ばない。
- 比較空間の独立な全一般化固有分解で、各区間が少なくとも一つの固有値を含み、スペクトル展開から求めたM残差が一致することを確認する。
- 軸あり/なし・0/1/2穴・P1/P2・二尺度、独立再メッシュと故意の射影未達、定数循環/正スペクトル、元native不変、標準と旧f/RFを検査する。

追跡の帯域guard・縮退のID集合・保存/CLI/GUIは後続工程。新規外部資料・依存・旧版参照なし。
