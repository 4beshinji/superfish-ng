# 明示曲線HφのProject・表示・独立掃引

[専用native・CLI](CURVED_HPHI_NATIVE_PLAN.md)に続く操作工程。未受入。

受入条件：

- 専用二次幾何をHphiProjectへ接続し、元頂点・全中点・全穴・軸経路・規約を編集、保存、復元する。表示単位をSIの物理入力に混同しない。
- 共通native入口・実worker・元結果の取込・取消・再起動で専用完全再生を維持する。元ファイルの移動後も所有コピーを再生でき、再hashしたProject/状態の不一致を拒否する。
- 元要素の参照座標で場を評価し、描画する各小領域の境界を二次曲線で保持する。全穴を除き、P1でも二次の物理幾何を描く。色は元場の片側サンプルで、表面ピーク精度や積分値には使わない。
- GUI/CLIで符号付きHφ・Er・Ezを描き、全18成分E/H/BをSI CSVへ出す。保存結果・PNG/CSV・規格化・位相と軸R/Qを照合する。
- 独立掃引は一様尺度、全蓄積エネルギー、壁導電率だけを接続する。一様尺度では全二次点と明示軸の区間・位相原点を同じ倍率で変換し、解析尺度則を検証する。順位を追跡IDとはしない。
- 曲線の共通分割・細分差診断・スペクトル比較・追跡は未対応として入力段階で拒否する。直線用の比較へ暗黙に渡さない。
- 軸あり/なし、P1/P2、複数穴、半径も非線形な曲線、実GUI・CLI・worker・標準周波数/RFを検証する。

一般曲線の自動生成・正確な円錐曲線・形状写像の追跡・表面ピーク精度・旧版照合は別工程。新規依存、外部サービス、旧版ソース参照は追加しない。
