# Hφの明示した同形状メッシュ列・細分差診断

P03/N03/O02の後続。[API・保存・CLI実装](HPHI_CONVERGENCE.md)の範囲で限定受入。共通領域の元電場/磁場内積を使い、明示した3水準以上のHphiProjectを比較する。

対象は閉同軸・正半径一般断面・軸接続の直線PEC穴付き断面。全水準は同じ宣言外周/全穴（同じ区間順序）、P1またはP2と積分の固定次数、同じモード数、全3D U・壁導電率・加速区間/位相原点/betaを持つ。各水準の三角形数が増え、最大要素辺長が減ることを確認する。ユーザーが明示した独立メッシュ列であり、入れ子空間やRitzの単調性は仮定しない。任意の自動形状生成・自動細分はこの版に含めない。

受入条件：

- 完全定義のstrict要求・元Project/Caseとの一致、同じ真空と物理条件、細分水準・候補/分割/モード予算を検査する。粗いまま同じmeshを並べた入力を拒否する。
- 各水準を実FEMで解き、元E/H両方の全体積内積で同順位の一意な対応を検査する。上下近傍・上端guard・近傍周波数の細分移動を確認し、縮退/順位入替/弱い対応はUNVERIFIED。
- 同じ係数符号をE/Hと複素Vaccへ用いる。L2差は元要素で直接積分し、Gram行列の近い数の差引きによる桁落ちを避ける。
- 最後の2組についてf、E、H、各RF量・全壁線分、宣言済みの複素Vacc・両R/Qを個別に比較する。各差が増えておらず、要求した有限差しきい値内であることを判定する。ゼロ面積軸は損失ゼロ、加速未宣言はN/A。
- 全量を保存し、全水準の所有nativeから再計算して改変を拒否する。CLIの実行/再生を確認する。ジョブ/GUIへの接続は別工程。
- 円筒の独立解析f/E/H/RFと相似則、穴付き複数水準の実FEM、意図した粗さ未達・guard不足・厳しいしきい値、係数符号反転、元native不変、標準/旧f/RFを確認する。

PASSは最後の3水準の差の診断で、連続問題の誤差上界・一般の精度・表面ピーク証明・永続的mode IDを意味しない。順位入替や縮退の部分空間追跡は後続。
入力は明示Project列とし、暗黙の形状写像・フィット・穴の補完を行わない。新規外部資料・依存・旧版参照なし。

候補はAPI/専用保存/完全再生/CLIまで接続。24系列/72FEMと二尺度がPASS。一般の穴付きメッシュではUNVERIFIEDも保持する。長い円筒のn=2/4/8で一線分の差だけが増える反例を得た。合計RFで隠さず、未検証判定を維持し、しきい値を変えずに細かい列を別途確認した。

細かいn=4/8/16の解析4系列/12FEMは元の全条件でPASS（348.806秒）。縮退TM011/TM020の3FEMは個別対応UNVERIFIEDを保つ（15.584秒）。固定617sourceの標準1055件と主5unit/4CLIも合格し、主623sourceへ統合済み。操作拡張はHPHI_CONVERGENCE_WORKSPACE_PLAN.mdの別候補で進める。
