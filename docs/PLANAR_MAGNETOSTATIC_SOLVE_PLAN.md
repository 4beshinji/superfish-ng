# S02: 平面線形磁静場の解・元B/H・磁束/エネルギー

2026-09-13 JST。Azのreluctivity弱形式へ明示境界と実FEMを接続する限定課題。実装中・未受入。

- 全辺へ固定Az[Wb/m]または向き付き接線H_t[A/m]を割り当てる。境界は反時計回り、外向き法線の右側規約、H_t=H·t=−(mu0 mu_r)^−1∂nAz。荷重は−∫H_t Ni ds [A]。
- 少なくとも一つの固定Azを要求し、基準Azからの差でgaugeの定数成分を分離する。純Neumann・暗黙の外部境界は拒否する。
- 元Az、B=(∂yAz,−∂xAz)[T]、H=B/(mu0 mu_r)[A/m]を保持し、片側界面プローブで平均化しない。混在bool等の座標/セル入力を拒否する。
- ∫B²/(2mu) dxdy [J/m]と領域エネルギーを評価し、離散仕事恒等式を検査する。反力と元Hの境界線積分を分ける。
- 元Hの全周線積分と全Jz電流[A]でAmpere則を評価する。元Bの外向き磁束[Wb/m]と全周のdivB=0を検査する。離散反力保存だけで元場精度を保証しない。
- 二層の固定Az問題で接線H連続、Bのmu依存、磁束とエネルギーを解析照合する。
- Az=A x²/A y²の凹形/回転製造解と符号付きJz/非0H_t、全周Az=0の一様Jz矩形を独立に解析照合する。
- mu/幾何尺度、電流反転、定数gauge移動を確認し、Az/B/H/エネルギー/元H境界積分を別々に細分判定する。
- 標準周波数/RFを保つ。軸対称、非線形/異方性/永久磁石、巻線のインダクタンス、厳密開放境界、native/CLI/GUIは別工程。
