# 曲線寸法の法則と調和変位による形状Study

2026-09-14 JST、N04残件4の履歴付き形状掃引を、
[調和変位による非アフィン変形](CURVED_HARMONIC_DEFORMATION.md)へ接続した。
各条件の元Project、曲線上の対応と固定分割を保持し、
通常Study・完了結果の追跡・逐次/適応の保存再開とGUIから使う。

## 入力契約

`study_version: 3` は `kind: "curved_harmonic_sweep"` 専用。
旧Study版1とアフィンStudy版2の保存フィールド/受理条件は保持する。
[携帯可能な合成例](../examples/curved_harmonic_study.json)は、二つの半楕円の中心/長さ/半径を変える。
元メッシュとmarked→uniform→markedの固定履歴を含み、測定構造を表さない。

| 項目 | 契約 |
|---|---|
| `project` | 未組立・直接構築のnative曲線P2、閉PEC/軸のTM。全marked分割を固定済み |
| `parameter` | 空白だけでない変数名 |
| `parameter_unit` | `1` または `m`。値はその単位で与える |
| `values` | 二つ以上の有限数。通常掃引では順序の入替え/同じ値への帰還も可能 |
| `geometry_coefficients` | geometry内の連続な曲線数値項目から、次数昇順の有限係数配列への対応 |
| `rf_coordinates` | `fixed` または `axis_fraction` を必須指定 |
| `minimum_corner_angle_deg` | 全変形段階で必要な角度。有限、0より大きく60未満 |

例えば `"/curves/1/semiaxes_m/1": [0.08, 0.01]` は
その半軸長を `0.08 + 0.01*x` mとする。二次以上の係数も指定できる。
配列は空にできず、少なくとも一つの法則に非零の高次項が必要。
個々の法則を定数にして、関係する複数の寸法を同時に変更することもできる。
法則は元geometryのコピーへ全て設定してからCaseを検査する。

許されるパスは `/curves/<番号>/` の後に次の数値葉を指定するもの。
元のプリミティブに存在する項目だけを受理する。

- `start_zr_m` / `end_zr_m` / `center_zr_m` / `semiaxes_m` の要素0または1。
- `rotation_rad` / `start_rad` / `sweep_rad` / `start_parameter` / `end_parameter`。

番号は0からの正規の整数表記。負数や先頭ゼロの別名は拒否する。
曲線数/順序/種類、離散的な双曲線branch、タグ、弦分割/誤差/品質予算、
物理モデルやsolverなどを、この連続法則のパスで変更することはできない。
未知パス、空配列、bool、NaN/無限大、浮動小数で扱えない巨大整数、評価時のoverflowも拒否する。

寸法の出力単位は元の項目どおりm、角度はrad、双曲線パラメータは無次元。
k次の係数は、その出力単位を `(parameter_unit)^k` で割った単位で与える。
GUIの長さ表示がmmでも、この法則と変数のm指定はSIのmである。
TE・反射・対称半領域、未固定のmarked履歴は元の変形APIと同様に拒否する。

## 各条件の作成と追跡

各xで元Projectから独立に変形する。前の試行結果を次の元形状にしない。
曲線番号/増加分率から先の弦境界を作り、元弦メッシュの平面P1調和変位で内部を動かす。
先のP2曲線境界を構築してから、元の固定参照分割を制限する。
物理座標での写像はP2参照写像F₀/F₁による `F₁ ∘ inverse(F₀)` であり、全体のアフィン変換を要求しない。

通常Studyは全指定点の幾何/品質/予算を出力作成前に検査する。
結果は独立スペクトルで、comparisonsは空、numerical_statusはUNVERIFIEDを保持する。
同じ周波数順位が同じ物理モードであるとは解釈しない。
固定領域の細分収束や、未評価の区間内の形状妥当性・連続物理枝を保証しない。

完了Studyの `track-study-modes` と逐次/適応のstep_controlsは
`mapping: "piecewise_remesh"` と既存閾値を指定する。
`comparison_meshes` を手動で混在させることは禁止する。
実比較点のProjectから元メッシュと全固定履歴を取り出し、
[曲線比較メッシュ版2](CURVED_PIECEWISE_REMESH_TRACKING.md)を毎回構成する。
元要求は比較メッシュなしのまま保存し、実際の比較要求/履歴には導出した両メッシュを保存する。

適応実行では値を厳密単調とし、既存の最大深さ/試行数/最小幅条件を保持する。
例えば0→1の比較が二分された場合、0→0.5には0.5から作ったメッシュを使う。
元区間の閾値は継承するが、1のメッシュを0.5へ流用しない。
逐次/適応の内部では、既に検査して求解に使ったProjectを比較宣言にも使用する。
保存replayは宣言法則・実際の条件値・元Project・全native場から再構築し、
変更された要求・メッシュ・祖先ファイルを拒否する。
拒否比較、未達の終端、計算済み点、PAUSED/UNVERIFIEDの区別を維持する。

## CLIとGUI

```sh
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m superfish_ng study \
  examples/curved_harmonic_study.json --out out/new-harmonic-study
```

保存追跡・逐次・適応のCLIは既存の要求形式を使い、内側Studyだけを版3とする。
外側の追跡/保存文書の版は変更しない。
通常StudyのCLI終了0は指定点の計算完了を意味し、数値収束の認定ではない。

GUIは「曲線寸法を変える掃引（調和変位）」を選ぶ。
現在の曲線から定数項だけのひな形を作成し、必要な項目へ変化する係数を追加する。
共有端点や接線条件を持つ寸法は、関係する法則を同時に指定する必要がある。
変数の単位/RF座標/最小角度も明示する。
定義の保存/読込で元メッシュ・固定履歴と全法則を保持する。
法則欄のJSONは文字列のまま厳密なserver readerへ渡すため、重複したパスも拒否する。

保存/実行前に全指定点を検査し、その非同期検査中に形状・法則・単位・品質等が変われば旧応答を破棄する。
完了Studyの追跡と逐次/適応要求の準備も、導出用のpiecewise_remesh controlsを生成する。
ここで追加したのはStudyの操作であり、単独Project変形の目標形状プレビュー/適用/Undoとは区別する。
