# P04: 材料重み付きHφ固有解・元場・RF

2026-09-13 JST。材料領域/行列基盤の次の限定課題。[実装記録](MATERIAL_HPHI_RF.md)の専用API範囲で限定受入。
専用Case版1として直線適合メッシュ、正値実数・等方・線形・非分散・無損失の区分一定epsilon_r/mu_rを扱う。
固有解・元場・全3D RFのAPIを対象とし、native/CLI/GUIは後続で個別に受け入れる。

受入条件：

- 材料/領域/元セルを完全に保持したstrict Case。曲線・複素/分散/非線形材料・体積損失を拒否する。
- 実K/Mの低い正スペクトルを解く。正半径qの定数静的核だけを除き、軸接続uは全軸DOFを保持する。
- peak exp(+iωt)、Hφ real、Er/Ez quadrature。Eにセルのepsilon_r、Bにmu_rを反映する。プローブは元セルと材料を明示し、界面を平均化しない。
- U=∫(epsilon0 epsilon_r |E|²+mu0 mu_r |H|²)/4 dV。領域ごとのエネルギーと全U、電磁分配、質量直交性を別々に確認する。
- 全PEC壁のHφから摂動損失を積分する。非磁性の壁金属のmu=mu0と明示し、隣接媒質のmuを壁Rsへ代入しない。体積損失はない。
- 加速量は明示した真空軸区間だけ。区間に材料が接する場合は拒否し、経路なしは両R/Qを理由付きN/Aにする。
- 一様材料の周波数・規格化場・RF尺度則と、層状同軸の解析共振モードを独立対照とする。周波数、場L2、領域エネルギー、壁損失を別判定し、実細分も行う。
- 元場/係数の再構成検証と不正配列・高順位への差替え拒否を確認する。標準回帰・既存f/RFを保つ。

層状同軸の独立対照はq=Z(z)、d/dz[(1/epsilon_r)Z']+k0² mu_r Z=0、両端Z'=0から導出する。
長さLの2/3を真空、残りをepsilon_r=4,mu_r=1とすると両層の光学長が等しく、k0=3nπ/(4L)。
Zは左でA cos(k0 z)、右でB cos(2k0(L-z))。偶数nでB=A、奇数nでB=-2A。
Hφの連続とZ'/epsilon_rの連続を満たす。適切な細い環状断面で低いTEM帯域を比較し、径方向モードの混入も確認する。
解析式は検証専用で、FEMの代替にしない。製造解の界面条件テストとPEC共振器の精度検証を区別する。
