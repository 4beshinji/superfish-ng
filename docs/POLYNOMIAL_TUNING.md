# 多項式による設計変数と座標の連動

2026-09-09、D02の非線形設計変数。真空・閉PEC・正半径の連続profile、
既存の個別モード追跡と二分法・最終細分ゲートを使用する。
受入条件は、二乗で半径を変える円筒の解析周波数、単位表現・Maxwell相似則、
保存再開・旧版文書一致、範囲内部の不正形状の停止、GUI生成/復元と標準回帰である。

## 入力と単位

tune requestの `schema_version: 3` は版2と同じ項目を持ち、
各bindingを `path, coefficients` に置き換える。
`coefficients` は定数項から昇順に並ぶ有限数の非空配列で、式は
`coordinate_m = c0 + c1*x + c2*x² + ...`。
Horner法で評価し、全指定座標を同時に更新してProjectを検証する。
設計変数xの単位は引き続きmまたは無次元。cₖの単位はm/(xの単位)ᵏ。
単位ラベルによる自動換算はなく、bounds・探索幅・係数を整合させる。

例題 `examples/tuning/pillbox_radius_squared.json` は両端半径に
`coefficients: [0, 0, 0.1]` を指定し、無次元xの二乗で半径を変える。
半径93 mmの解析目標に対しx=√0.93が独立参照となる。
FEMの代わりにこの式から周波数を返す実装ではない。

定数項だけのbindingは他に変化するbindingがあれば使用できる。
全bindingが定数、非有限値/bool、未知項目、空係数、重複/不正path、
計算後の非有限座標や不正形状は拒否する。
版1単一座標と版2一次式の入力/計算/保存形式は保持する。
チェックポイント自体の版は1のままで、内包requestの版を保持する。

## 範囲と失敗の意味

開始前に両端の粗/細形状と円筒写像条件を検査し、両端で形状が全く変わらない
連動を拒否する。多項式が範囲全体で有効・単調であるとは証明しない。
各試行で実形状を再検証し、範囲内部で不正形状になれば失敗記録を残して停止する。
その試行を周波数評価や成功checkpointにせず、先行checkpointを保持する。
有効な全区間やすべての根を探索する機能ではない。
非単調な周波数でも二分法は実評価の符号が異なる区間だけを継続する。
連続分枝・大域根・物理誤差上界を認証したとは扱わない。

GUIの連動設定で「一次式/多項式」を選び、対応するJSON係数を入力する。
保存結果を開くと式の種類・係数・変数単位が復元される。
再開は保存条件を使い、編集中の別の式を混入しない。
通常tune/resume-tune/replay-tune CLIとJobManagerでも同じ入力を使える。
