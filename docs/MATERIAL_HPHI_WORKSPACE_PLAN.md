# P04/O02: 材料HφのProject・表示・独立掃引

2026-09-13 JST。専用材料native/CLIの次の限定課題。[実装記録](MATERIAL_HPHI_WORKSPACE.md)の操作範囲で限定受入。
材料Caseを既存Hφ Project・所有worker・GUIへ接続し、全材料・界面・場の片側情報を保持する。
材料Case/Project JSONの読込から計算・保存・表示・再起動までを対象とする。

受入条件：

- 完全な材料分割をProject版1で往復し、実worker・所有取込・取消・再起動・保存再生を確認する。
- 元セルのE/H/Bを表示/CSVへ渡す。Bを真空のmu0 Hで上書きしない。片側セル・領域/材料・epsilon_r/mu_rをCSVと付随情報に保持する。
- GUIで材料/領域一覧と領域別エネルギー・壁損失、非磁性壁の規約、真空軸経路の制約を確認できる。
- m/mmの切替とProject保存で材料係数・全メッシュ・明示軸経路を変えない。材料中の軸区間を加速経路に指定すると計算開始前に拒否する。
- 独立Studyは一様幾何尺度・総U・壁導電率に限定する。材料係数とセル割当は保持し、順位を追跡IDにしない。
- 材料の比較・収束診断・追跡は入口で明示拒否し、既存真空の比較へ暗黙変換しない。
- 実ブラウザー、全native/Projectの不変、GUI/CLIのPNG・CSV・復元一致を確認する。旧真空Hφ・TM/TE・平面操作を保つ。
- 全標準回帰と旧周波数/RFを保つ。材料係数のGUI編集・材料掃引、材料の形状比較/追跡・損失/分散、P04全体は後続。

新規依存・外部サービス・旧版参照なし。
