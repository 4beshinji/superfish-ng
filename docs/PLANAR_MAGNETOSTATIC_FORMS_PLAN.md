# S02: 平面線形磁静場の材料・電流・弱形式

2026-09-13 JST。既存の静電と区別した、Azによる平面磁静場の弱形式を追加する限定課題。実装中・未受入。

受入条件：

- 単純多角形の直線適合P1/P2、全セルの正値実数等方mu_r、全領域の符号付きJz[A/m²]を明示する。非線形BH、異方性、永久磁石、RF、曲線/穴を黙って通さない。
- Az[Wb/m]、B=(∂yAz,−∂xAz)[T]、H=B/(mu0 mu_r)[A/m]。K=∫(mu0 mu_r)^−1 gradNi·gradNj dxdy [m/H]、f=∫Jz Ni dxdy [A]。
- 全DOFと定数Azのgauge核を保持する。境界条件/解法や厚さは仮定しない。半径軸の扱いを平面へ持ち込まない。
- mu倍率に対してKは逆比例することを先に独立不変量とする。静電のepsilon倍率をmuへ読み替えない。
- 独立Gauss/Vandermonde積分、矩形/凹形の多項式モーメント、定数核の全スペクトル、全領域電流を確認する。
- 一様Bの解析磁気エネルギー∫B²/(2mu) dxdy [J/m]、尺度/剛体不変性、Jz符号反転、mu倍率、材料/領域順序変更を照合する。
- strict JSONと読み取り専用配列、未割当/重複/不正材料/不正電流の拒否、標準周波数/RFを保つ。

固定境界付き解法・元B/H・磁気エネルギー/保存・CLIは後続工程。新規依存・外部資料・旧版実行なし。S02と全計画は未完。
