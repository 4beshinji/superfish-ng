# S05: 反跳/B-Hモデルの線形無源領域での多極抽出

2026-09-13 JST。後続限定課題。[実装記録](PLANAR_MAGNETIC_MULTIPOLE_MATERIALS.md)の専用API範囲で限定受入。

平面の反跳P1/P2とB-H P1の実FEM解も抽出元として明示的に受理する。円板全体のJz=0、正スカラーで一様な線形構成則を要求する。反跳材料は宣言した二つの主mu_rが同一で残留Bが厳密ゼロ、B-H材料は全表でH=nu Bの比が厳密同一であることを確認する。表の一点や現在の場の区間だけを根拠に非線形材料を線形と扱わない。円板外には異方性/残留磁束/非線形材料を許可し、元の全領域FEMで解く。

従来の線形スカラー抽出版1は全JSONを維持する。追加2種類は抽出版2として元物理と円板の構成則を明示し、係数と全4標本系列/求積診断を保持する。保存/CLIの対象拡張は後続とし、この段階で未対応のnativeを暗黙に読む処理は加えない。

最初に既知の線形極限のB-H解から一様/四極場を抽出する不変量が既存APIで拒否されることを記録する。受入は一様双極、線形極限のP2反跳四極、P1のB-H四極8/16/32細分、円板外の非線形/永久磁石・異方性層、回転/尺度/基準Az、円板内の非線形/異方性/残留/電流・近似線形表・改変元係数の拒否を含む。厳密場/係数と座標則は1e-9、P1最細は係数/元場とも0.02、細分による改善を要求する。従来版1の独立72抽出と24例72保存報告の全JSON/元ファイル不変も確認する。

新規依存なし。解析係数を求解へ代入しない。標準検証と既存周波数/RF差を確認して限定受入する。GUI、保存対象拡張、力/トルクは後続工程。
