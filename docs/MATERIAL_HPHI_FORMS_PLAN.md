# P04: 線形RF材料の領域・界面・Hφ形式

2026-09-13 JST。C00台帳K12のRF EPSILON/MUに対応する独立数値基盤。[実装記録](MATERIAL_HPHI_FORMS.md)の行列API範囲で限定受入。
既存canonical Model・専用真空Caseの受理範囲は保ち、材料は新しい明示データ/APIに限定する。
旧版との材料入力互換や数値一致はこの基盤の受入に含めない。

最初の対象は実数・正値・等方・線形・非分散・無損失の区分一定epsilon_r/mu_r。
全ての直線三角形を明示した材料領域へ一度だけ割り当て、界面は共有要素辺へ適合させる。
正半径のq=rHφと軸接続の正則u=Hφ/rを区別し、全軸DOFを保持する。
複素係数、分散、体積導電損失、異方性、非線形材料、曲線界面は拒否する。

受入条件：

- 材料/領域IDの一意性、全セルの重複なし被覆、材料参照、正値係数、全穴/軸をstrict JSON往復で保持する。未割当セルを暗黙の真空にしない。
- 領域別面積・全3D体積と界面両側のセル・領域/材料を元メッシュへ結び付ける。未知キー・非整数セル・非対応材料と幾何の拒否を確認する。
- q形式はK=∫grad(q)·grad(v)/(epsilon_r r)、M=∫mu_r qv/r。
  u形式はK=∫r[(2u+r u_r)(2v+r v_r)+r²u_z v_z]/epsilon_r、M=∫mu_r r³uv。
  共通2piは省略し、固有値を使う後続ではomega²/c0²に対応する。
- 一様材料でKが1/epsilon_r、Mがmu_r倍となる。qの定数静的核と軸接続uの正スペクトルを保持する。行列積分次数の比較を離散化誤差上界としない。
- 各セルの独立Gauss/Vandermonde組立、材料ID/セル番号の置換、正半径/軸・穴・P1/P2を検証する。
- 層状の製造解でHφの連続、epsilonを含む流束/接線Eの連続を確認する。FEMの一般解の界面微分を平均化しない。
- 全既存の周波数/RFと標準テストを保つ。固有解・材料重み付き場/エネルギー/RF・保存/CLI/GUIは後続で独立受入する。

Maxwell方程式から自作Hφ弱形式にepsilon/muを保持して導出する。材料物性表・旧ソルバーコード・新規依存は追加しない。
