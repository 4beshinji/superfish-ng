# S05: 平面磁場のMaxwell応力と仮想仕事

最初の範囲は直線P1/P2・線形スカラーのPlanarMagnetostaticSolution。元Caseの実FEM再求解と係数一致を確認し、明示した対象領域と連続P1重みwを用いる。対象全セルでw=1、外部境界でw=0、0≤w≤1を要求する。wが変化する全セルは厳密mu_r=1・Jz=0の真空とし、対象以外の電流/非真空材料はw=0を要求する。元の場を平滑化しない。暗黙の磁石長・RF phasor係数・軸対称への拡張を行わない。

真空のT=(B⊗B−|B|²I/2)/mu0を元Bから評価し、単位長さの力F/L=−∫T grad(w) dA[N/m]、明示原点cに関するトルクτz/L=−∫((x−c)×T grad(w))z dA[N m/m]を計算する。[David Meeker, Derivation of Weighted Stress Tensor (2022-08-27)](https://www.femm.info/doku/doku.php?id=weightedstresstensor)の公開数学を照合する。FEMMのコード・図・磁場データ・重みを丸める方法は再利用しない。任意の適切な重みとメッシュで得た差を別診断とし、小さい差を誤差上界と扱わない。

P1重みを用いた内部メッシュの仮想移動を別経路で実施する。対象は剛体並進/回転、外部境界と他の源/材料は固定し、変形域は真空のみ。全源電流と材料・境界規約を保持した別Caseを±δで実FEM求解する。元の停止/残差ではなく、停留ポテンシャルΠ=U−Az·(電流荷重+Ht荷重)の中心差分から−dΠ/dx、−dΠ/dθを求める。固定電流と固定境界条件、基準Azの扱いを明示する。[FEMM 4.2 User’s Manual、2015-10-25、§2.3.11 式2.13/2.14](https://www.femm.info/Archives/doc/manual.pdf)の固定電流での余エネルギー微分を照合し、自前Caseの混合境界には源/境界仕事を含む停留ポテンシャルを独立に導出する。力/トルクの積分実装を差分式へ流用しない。

受入の解析対照は、対称な真空箱の内部に置いた有限電流領域と一定の外部B。一つの中心電流では自己力が対称性で打ち消され、F/L=I ez×B。左右の±I対では力が打ち消され、非零の偶力トルクが得られる。実FEMの境界は上下固定Az・左右Htで外部一様Bを与える。反射対称な四分三角形メッシュを用い、解析係数を求解に代入しない。

許容差は実装前に、厳密一様場/単電流の力とP2偶力の解析対照1e-9、P1偶力の8/16/32細分最細0.02、仮想仕事のδ/2系列と応力差1e-5を開始条件に置く。原点変更τ(c')=τ(c)−(c'−c)×F、回転/電流反転/尺度、重み/メッシュ/差分刻みの別系列、領域/単位/不正重み・元係数改変の拒否を確認する。最初に失敗した物理不変量は証拠を保存し、許容差を緩めない。

元FEM場の離散誤差、重み依存、差分誤差と非零力/トルクの判定を区別する。標準検証と既存周波数/RF差の確認後、専用APIのみ限定受入する。保存/CLI/GUI、反跳/B-H・軸対称の力/トルクは後続工程。
