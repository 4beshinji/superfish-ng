# 平面多角形の宣言相似写像による追跡計画

保存履歴の受入後に扱う次の限定課題。現行の多角形追跡版2は原点まわりの正の一様尺度だけを受理する。この計画は回転・平行移動を製品へ接続したことを意味しない。

## 物理写像と反例

次の座標を `x_next = s R x_previous + t` と宣言する。`s > 0`、`R`は平面の向きを保つ回転、`t`はSIの平行移動。せん断・異方尺度・鏡映・任意の頂点移動は別仕様とする。同じ偏波、元三角形の番号・接続と既知四分割関係を要求する。

TEの横電場は、次の場を前の座標枠へ`R^T E_next`で戻してから物理内積を取る。TMの縦電場Ezはこの平面内回転で変わらない。尺度やU′が異なる振幅は、現在の正規化されたGram処理で区別する。FEMの場を修正・置換する操作ではなく、二つの保存場を比較する座標枠を明示する。

実装前に`out/planar-similarity-tracking-preflight-20260910`で、三角形/凹形状、TE/TM、P1/P2の8条件を確認した。既存の実FEM場に対し、90度回転・尺度2・平行移動(0.13, -0.08) m・U′3倍の形状を独立に解いた。各3固有値の1/s則、基本モードのG不変・Qの√s則・損失のU′/s^(3/2)則を確認した。TE基本モードを座標だけ対応させた内積は約0だが、ベクトルの回転も戻すと正規化重なりは1となる。TMのEzは回転操作なしで1となる。現行の原点尺度写像はこれらを拒否する。

この8 FEMは新写像の物理的前提の検査であり、写像の幾何・入力・保存・CLI/GUI・履歴の受入ではない。

## 実装前に決める契約

- 版付き要求で尺度・回転・SI平行移動・両側の既知細分回数を明示する。未知項目、非有限値、異Case/偏波、鏡映を黙って受理しない。旧矩形版1・原点尺度版2の保存と再生結果を保持する。
- 座標と全接続を検証する。大きな原点オフセットを理由に幾何許容差を緩めない。回転で零付近となる座標の演算誤差と、局所メッシュに対して有意な領域差を区別する。
- 宣言相似変換と四分割の演算順を明記する。別演算順を許す場合は具体的な再構築で照合し、座標へのfitで差を吸収しない。
- 共通積分域は前の元領域の面積とする。移動後の座標からの逆変換による差引きの精度低下を避け、元要素と親子barycentric写像から前の物理積分域を構成する。
- 回転後の元電場を同じ参照座標枠で積分し、3/5次積分・PSD・規格化・帯域guard・有限細分空間診断・縮退集合を完全再生する。
- 保存要求/結果・実worker・CLI/GUI・保存履歴へ同じ写像を渡す。履歴のnative同一性・帯域・ID集合連続性を弱めない。次の写像を履歴から推測しない。

## 受入条件

三角形と凹形状、TE/TM、P1/P2、両尺度、90度と非直角回転、平行移動、細分の正逆を含む幾何・場比較を実FEMで確認する。周波数/物理場/RFの相似則、変換の逆・合成、TEベクトル回転の反例、縮退部分空間の基底回転を別に評価する。大きなオフセット・零付近・異接続・頂点差・非有限値・誤った細分宣言を拒否する。

全保存再生と改変拒否、旧版保存、実worker・中止/再起動、CLI/GUI要求と結果のroundtrip、新写像を含む複数段階履歴、標準全体・旧TM/TE/平面の周波数/RF・source hashを確認してから限定受入する。一般多角形変形や連続経路のモード同一性を保証しない。

## 隔離した幾何と元電場の候補

`out/planar-similarity-geometry-direction-20260910`で三角形/凹形状、90度/0.371 rad、尺度0.37/2、細分0/1の16条件を正逆両方向で検証した（6.759秒）。前の物理面積を保持し、大きな原点で8ulpだけ領域を変えた反例を拒否した。逆向きを再計算した尺度・角度・平行移動へ展開する初期候補は、凹形状の座標照合で失敗した。許容差を緩めず、元の宣言変換を逆向きに使う明示フラグと、既知演算の逆照合を持つ候補で確認した。主製品の新formatにはまだ採用していない。
