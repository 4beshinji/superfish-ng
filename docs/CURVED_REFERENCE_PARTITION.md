# 曲線比較の版5：明示参照座標と異なる初期接続

2026-09-15 JST、開始HEAD `3b30e3b`。D01一般写像のうち、以下の版5契約を実装・限定受入した。
親D01の元要件全体の照合は別途継続する。

`mapping="piecewise_remesh"` の両 `comparison_meshes` を版5にする。
各側は `schema_version: 5`、完全な `source_mesh`、`reference_vertices`、
`boundary_pairing: "declared_reference_polylines"`、正整数 `max_pair_tests` を持つ。
細分は省略・`curved_refinement_levels`・`curved_refinement_steps` の既存契約を使う。
両側で版・境界方針・総組数予算を一致させる。

`reference_vertices` は各初期source_meshの頂点と同じ順序の、無次元2座標の配列。
実FEMの全P2節点や履歴後の節点に対する座標ではない。
参照領域は利用者が明示し、物理形状間の対応を座標の近さや周波数から推定しない。
旧新の頂点数・要素接続・境界分割数・履歴は異なってよい。

各側の参照辺は共有節点以外での交差/接触/重複を拒否し、全参照三角形を正向きとする。
各物理曲線の番号・増加分率方向に並べた参照折線と境界タグを両側で照合する。
追加の共線節点は許すが、折れ点・向き・曲線順が一致しない場合は拒否する。
物理曲線分率そのものは一致を要求しない。参照頂点座標が対応を宣言する。
各比較空間と元FEMの全二次境界の一致、正Jacobian、閉PEC/軸接続TMの検査は保持する。

両側の固定細分履歴を元P2空間から再構築し、親参照写像を合成して共通参照領域へ移す。
[有理数交差分割](REFERENCE_PARTITION.md)で、両側の全最終親要素を厳密に覆う。
各共通三角形は旧新それぞれの親番号と親内重心座標を持つ。
物理点は各側の実P2局所写像から求め、体積Jacobianには共通要素から親への
座標変換の行列式を乗じる。元の二次曲線を再投影したり、場係数を別メッシュへ置き換えたりしない。
既存の `Hphi * sqrt(r/max(r)) * sqrt(detJ/max(detJ))` と正の共通求積重みで比較する。

`max_pair_tests` は両側の参照辺検査、参照三角形の自己重複検査、旧新の交差検査の総予算。
標本数の既存上限262144も適用する。予算超過は未計算の積分を成功として返さない。
求積次数を変えた確認は必要で、被覆の厳密性は求積/物理誤差上界ではない。

完全な参照宣言・親内座標・被覆・境界対応は既存の保存pairと履歴へ保持する。
元場を再読込して再計算し、派生情報の改変を拒否する。旧版1〜4は各版の契約を保つ。
GUIは既存の比較メッシュJSON欄を使い、「明示した共通参照座標」と共通要素数を表示する。
