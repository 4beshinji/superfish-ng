# 曲線適応版4の単一対称半領域

2026-09-09。従来は全ての対称半領域を版4で拒否していた。
単一の平面上で連結し、電気または磁気対称タグが一貫する境界について、
既存の解析曲線鏡映で全領域を構成し、全PEC接続と軸端の滑らかさを検査する。
元の半領域のPEC角も、鏡映で生じるPEC接続も従来の角度条件を満たす必要がある。
混在タグ・切れた対称面・非平滑な軸端/接続は受理しない。
単一対称面の幾何検証は既存のCurvedContour.reflectedに委譲する。

幾何の判定に鏡映を使うが、FEM・残差・追跡・PECピーク探索は元の半領域で行う。
電気対称のu=Hphi/rは偶、磁気対称では奇となる既存の境界契約を保つ。
鏡映で電磁場の符号が変わってもPEC上の大きさの最大値は不変、
同じ振幅で体積を2倍にすると蓄積エネルギーも2倍になることを受入不変量とした。

R/Q、積分区間、active length、位相原点、Eaccは元Caseの半領域規約を保持する。
全領域RF値へ暗黙に換算しない。全領域の値が必要なら既存の明示鏡映操作を使う。
checkpointには幾何診断の領域と、ピーク/RFが元半領域であることを保存する。
既存の全PEC要求の診断文書は変更しない。版4の要求・保存形式を保つ追加受理範囲である。
一般曲線の幾何誤差や物理ピークの誤差上界を提供する変更ではない。
