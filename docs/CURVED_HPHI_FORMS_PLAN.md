# 穴付き二次幾何のHφ変分形式

P03の[二次幾何基盤](CURVED_MERIDIONAL_GEOMETRY_PLAN.md)に接続するK/M構築工程。[CURVED_HPHI_FORMSの実装記録](CURVED_HPHI_FORMS.md)の範囲で限定受入。
固有解・RF・保存/GUIへ進む前に、正半径のq=rHφと軸接続のu=Hφ/rを幾何の型で明確に分ける。

先行する物理不変量は、正半径qの定数場がKの静的核に属することと、軸接続uの定数場には正のcurlエネルギーがあること。
既存の軸接続u用曲線形式を正半径qへ流用するとこの区別が失われる。軸の自由度をゼロにしない。

受入条件：

- 検証済み二次幾何から参照P1/P2を物理座標へ写し、qには1/r、uには既存のr重みcurl/r³重み質量を使う。2πを含めない既存行列規約を明示する。
- 二つの積分次数でK/Mを別々に比較し、未解決の積分を拒否する。有限次数の一致を離散化誤差上界とはしない。
- 直線極限で既存の正半径/軸接続K/Mと一致する。全穴と軸自由度、共有DOF、対称性と質量正値を保つ。
- 定数qの唯一の静的核、軸uの正値、物理座標の線形場と定数uの解析エネルギーを独立に検証する。
- 軸あり/なし・0/1/2穴、P1/P2、曲線境界と複数尺度の相似則を検証する。
- 未対応型/次数/積分条件をstrictに拒否し、標準と既存周波数/RF回帰を維持する。

このAPIは行列を構築する。正のスペクトルの抽出、規格化、RF量、native/Project/GUIと追跡は後続工程で受入する。
自作の既存FEM式と二次写像を再利用し、新規外部資料・依存・旧版参照は予定しない。
