# 単位付きの非多項式スカラー式

2026-09-15 JST、開始HEAD `7061866`。D02の非多項式関数連動に使う式評価基盤。
式基盤の受入時点では未接続だった。現在は[要求版7](EXPRESSION_TUNING.md)でtuneへ接続し、実ブラウザー・曲線RF等の検証を継続中。

`validate_scalar_expression(expression, variable_units, expected_unit=...)` は全構文と次元を検査し、
使われる変数名とノード数を返す。`evaluate_scalar_expression` は同じ入力に変数値を与えて評価する。
値は有限実数、単位はSIの `m` または無次元の `1`。単位の自動変換はしない。

式は次の厳密なJSONオブジェクトの木で表現する。

- 定数：`{"constant": 0.1, "unit": "m"}`。
- 変数：`{"variable": "x"}`。宣言済みの変数だけを参照できる。
- 演算：`{"op": "exp", "args": [{"variable": "x"}]}`。

二項演算はadd/sub/mul/div/pow/atan2/hypot、単項演算はneg/abs/sqrtと
exp/log/sin/cos/tan/asin/acos/atan/sinh/cosh/tanh/floor/ceil。
min/maxは2〜16引数、比較lt/le/gt/geは2引数。
ifは比較条件・真の場合・偽の場合の3引数で、選ばれた枝だけを評価する。
両枝の構文と次元は選択にかかわらず検査する。比較値を数値や最終結果へ流用しない。
一般のPython構文、属性参照、import、外部呼出し、外部状態へのアクセスは含まない。
式を多項式へ近似・当てはめする処理も行わない。

長さ次元の指数を有理数で保持する。和/差/min/max/hypot/比較は同じ次元を要求し、
積/商は次元指数を加減する。sqrtは指数を半分にする。
powの指数は無次元で、次元を持つ底に対しては明示定数の指数を要求する。
atan2は同次元の2量から無次元角を返す。その他の数学関数は無次元引数を要求する。
全体の結果が指定した `m` または `1` と一致しなければ拒否する。
`sqrt(length)`のような中間の分数次元は保持され、二乗して長さへ戻す式を検査できる。

未知キー/演算/変数、不正引数数、booleanや非有限値、変数名集合の不一致、
256ノード・深さ32の上限超過は拒否する。循環したPython辞書も深さ上限で停止する。
各演算の定義域エラー・ゼロ除算・オーバーフロー・非有限結果はValueErrorにする。
数学関数は標準ライブラリの浮動小数演算であり、区間証明や厳密実数演算ではない。

新8unittestで、指数/対数の逆関係、三角恒等式、3-4-5の長さ関係、
複数変数の2倍長さ則、分数次元、次元不整合、遅延分岐、定義域/入力/予算拒否を確認した。
変更前のAPI不在は `out/scalar-expressions-20260915/baseline.log`、最終結果は同`final-tests.log`。
FEMや既存利用先への変更はなく、この基盤変更で全suite/数値/GUIは実行していない。
