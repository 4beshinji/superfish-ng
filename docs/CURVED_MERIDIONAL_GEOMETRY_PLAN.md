# 穴付き軸対称断面の明示二次幾何

P03の曲線内導体に必要な幾何基盤。未実装・未受入。
検証済みの直線MeridionalMeshまたはAxisConnectedMeshの頂点・接続・境界成分を保ち、全辺の二次中点を明示して曲線領域を定義する。
二次多項式が幾何の正本であり、円・楕円そのものの表現や解析曲線からの自動メッシュは別工程とする。

先行する不変量は、軸あり/なし・0/1/2穴の直線極限での全境界・面積・回転体積の一致。
現行の大域曲線検証はEuler標数1の領域に限定され、正常な穴付き直線極限でも拒否する。
穴数だけで条件を緩和せず、以下を受入条件とする。

- 頂点と全辺の対応をstrictに保存・復元する。暗黙の辺補完、頂点移動、未対応の物理指定を受け付けない。
- 各辺の共有・向き、連結性、境界の次数と全閉路、Euler標数1−穴数を検証する。既存の穴なし呼出しの契約を保つ。
- 全二次要素のJacobian正値と、境界・内部を含む全辺の大域交差を検証する。節点や少数の積分点だけの正値で代用しない。
- 入力binary64座標の厳密な有理数多項式で半径の最小値を検査する。正半径領域は全域r>0、軸接続領域はr≥0かつ宣言した直線軸以外に軸接触がないことを要求する。
- 多項式の面積・半径一次モーメントを全要素から積分し、向き付きの全境界積分と照合する。外周と穴の役割を保つ。
- 軸あり/なし・0/1/2穴・複数尺度、直線極限、既知の可逆多項式変形による曲線境界を独立に検証する。反転、辺交差、共有不整合、軸変更、節点間の負半径、型/予算違反を拒否する。
- 既存曲線の検証と標準回帰、旧seedの周波数・RF量を維持する。

この工程は幾何のみ。曲線HφのK/M・固有解・RF・native/Project/GUI・追跡への接続は別の受入を必要とする。
既存の自作二次要素・辺分離検証を再利用し、新規外部資料・依存・旧版参照は予定しない。
