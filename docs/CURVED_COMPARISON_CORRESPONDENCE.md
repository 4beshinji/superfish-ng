# 曲線比較メッシュの番号自動対応

2026-09-14 JST、N04残件4/D01の独立番号付けを扱う。
比較宣言の版3で、旧・新を独立に番号付けしても、境界と三角形の隣接関係から
全P2節点・要素を対応付ける。実FEMメッシュは従来どおり別接続でもよい。
[版2の曲線比較](CURVED_PIECEWISE_REMESH_TRACKING.md)と外側の追跡/履歴保存版は保持する。

## 入力と境界方針

`mapping="piecewise_remesh"` の `comparison_meshes` に旧・新の二宣言を入れる。
各宣言は次の項目を持つ。

| 項目 | 契約 |
|---|---|
| `schema_version` | 整数3。両側で一致 |
| `source_mesh` | 完全な版1弦メッシュ。SI/rz/0始まりの番号 |
| `boundary_pairing` | 下記の二方針の片方を両側で同じ値にする |
| `curved_refinement_levels` または `curved_refinement_steps` | 比較側の細分履歴。省略は0段、併記/空stepsは拒否 |

境界方針を省略して自動推測しない。

- `same_curve_fractions`：同じ曲線番号・同じ増加分率の節点を対応させる。
  分率の一致は既存境界照合と同じ `512 ε` の丸め幅で検査する。
- `ordered_curve_vertices`：各曲線内の増加分率順で節点を対応させる。
  分率の数値自体が変わる形状変更も明示的に許す。各曲線の辺数・タグは一致が必要。

両方とも曲線の個数・種類・順序を保持する。原点や近い座標だけから対応を推定しない。
曲線番号とこの境界方針は利用者の幾何対応宣言であり、物理モードIDの宣言ではない。

元の局所細分番号/patternは**各側の元メッシュとその段階**へ解釈してから対応を求める。
旧側のmarked番号を新側へ流用する機能ではない。
節点番号・要素行順・三角形の巡回頂点順・境界辺の行順/向きは異なってよい。
最終比較分割の向き付き隣接関係は同型でなければならない。
同じ節点数/要素数/境界でも、その境界対応の下で内部対角線が対応しない分割は拒否する。

## 対応の構築と求積

各比較空間の全履歴を通常のnative経路で再構築し、被覆、正Jacobian、全辺の交差/共有、
各実FEMの二次境界全体との一致を検査する。曲線の再投影で別の二次領域になる入力は受理しない。

境界辺を曲線番号と増加分率で整列して対応させる。
向き付き境界辺の内側には一つの三角形があり、その第三頂点は一意に定まる。
同じ手順を共有辺の向こうへ伝播する。連結な三角形分割では全要素に到達するので、
境界を固定した向き付き対応は一意である。全節点/全要素の単射・全射、巡回向きと
P2辺中点の一致を最後まで検査する。衝突・未到達・異なる接続を部分対応として返さない。

境界からの伝播順を番号に依存しない順序へ固定する。
各三角形の参照頂点順と要素の求積順もこの順序で正規化するため、
非対称な三角形求積則でも元の局所頂点番号によって標本位置が変わらない。
二つの元P2写像を同じ参照節点順で評価し、従来の
`Hφ(Fs(ξ)) sqrt(rs detJs)` に相当する体積重みを用いる。
場係数の補間/再求解、固有値による番号合わせ、RF補正は行わない。

対応表は `physical_mapping.numbering_correspondence` に保存する。
`current_node_for_previous` / `current_cell_for_previous` は旧IDを添字とする新ID配列。
`previous_reference_cell_nodes` は共通求積順の旧6節点配列。
境界方針、全境界辺数、分率差の最大値と丸め幅も記録する。
節点順方針の分率差を不一致判定や物理誤差として扱わない。
保存再生では元宣言・native場から表と全追跡結果を再計算し、保存表の改変を拒否する。

## 操作

既存CLI `track-modes REQUEST --out RESULT` と追跡履歴の継続を使う。
GUIの「比較用メッシュによる局所変形」のJSON欄へ版3の二宣言を入力できる。
完了表示に境界方針と自動対応した比較要素数を示す。
失敗時は直前の検証済み結果を保持し、逆向きの継続では二宣言の順序も交換する。

次の専用検証器が、合成した二半楕円の完全な比較JSON・CLI要求・元native場を新規出力する。
測定構造ではない。版2の既存検証は追加オプションなしで引き続き実行できる。

```sh
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src:tests .venv/bin/python \
  scripts/validate_curved_piecewise_remesh_tracking.py --automatic-numbering \
  --out out/new-curved-correspondence-validation

OPENBLAS_NUM_THREADS=1 PYTHONPATH=src:tests .venv/bin/python -m unittest \
  test_curved_comparison_correspondence

node scripts/verify_gui_curved_piecewise_remesh.mjs \
  --url '<ローカルGUI起動URL>' --out '<新規ブラウザー出力>' \
  --sources out/new-curved-correspondence-validation
```
