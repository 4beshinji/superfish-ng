# 固定周波数における曲線P2場のRF感度

2026-09-09。N04のRFを意識した細分選択に向けた係数感度の基盤。
`curved_rf_sensitivity.voltage_covector(solution, mode=0)`と
`r_over_q_gradient(solution, mode=0)`を追加する。
既存のFEM solve、RF出力、残差指標、適応選択/停止は変更しない。
今回のAPIだけで適応効率改善や誤差推定器が完成したとはしない。

周波数・幾何・beta・積分区間・位相原点を固定する。
実係数ベクトルuは既存のHphi/r [A/m²]、軸上のEzは2u/(ωε0)。
各軸辺のP2基底を既存の位相付き厳密多項式積分へ渡し、複素共変ベクトルcを作る。
`V = c.T @ u`であり、この積ではcを共役しない。軸外のc成分は0。
区間の切詰め・辺の向き・位相原点は通常のRF積分と同じ規約を使う。

ピークphasorの電磁エネルギーを `E = u.T A u` とし、
`A = μ0 τ M / 4 + τ K / (4 ω² ε0)`、`τ = 2π` と置く。
加速器規約のR/Qは `q = |V|² / (ω E)` なので、実係数に対する勾配は

```
g = 2 Re(conj(V) c) / (ω E) - 2 q A u / E
```

となる。回路規約のR/Qと勾配はそれぞれこの1/2。
勾配の単位はΩ/(A/m²)。磁気対称などの同次拘束自由度は0に射影し、
許容される係数変化に対する微分として返す。返す配列は読み取り専用。
周波数を変化させる固有対感度や、境界/メッシュの形状微分ではない。

固有ベクトルから離れた係数でも微分を評価できるよう、電気/磁気の両エネルギーを保持する。
微分の途中で等分配や再正規化を仮定しない。これは係数空間上のRF関数の評価であり、
任意に摂動した係数を収束した固有モードと呼ぶものではない。
