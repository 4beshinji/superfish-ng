# 非球形の曲線適応・一様細分対照

2026-09-09、直前基準465e09f。N04の一般形状対照を、滑らかな回転楕円体へ広げる。
軸方向半長0.16 m・最大半径0.08 mの合成形状であり、実測空洞ではない。
閉PEC/axis・真空・m=0 TM・P2場/二次曲線領域の既存契約を使う。
球形の場合の独立RF解析誤差と、この非球形の細メッシュ比較を区別する。

入力例は examples/adaptive_refinement/curved_prolate_confirmed.json。
検証入口は scripts/validate_curved_nonsphere.py --out 新規ディレクトリ。
長さ尺度1と2を実FEMで計算し、正規化エネルギーを尺度の二乗倍にする。
初期メッシュ・二次写像・積分・規格化は、適応と一様細分で揃える。

適応側は版4の残差選択・全個別ID追跡・五量停止と全域確認2回をそのまま実行する。
一様側も保存場・親子質量内積追跡・高次積分・品質・五量の直近2区間を確認する。
一様側の確認完了後、少なくとも一回追加細分し、適応側の最終自由度を超える一様対照を作る。
追加対照自身も五量の二区間条件を満たす必要がある。
対照用の予算は --reference-max-triangles（既定100000）で明示し、足りない場合は未確認とする。

適応の最終水準と、一様側の最初の確認完了水準を追加対照と比較する。
f/RQ/Gは単一値、E/Bピーク比は連続離散上下界の最悪相対差で評価する。
比較基準はf 1e-4、RQ/G 0.5%、E/Bピーク比1%。ただし、これは同じ二次近似領域内の差であり、
独立した厳密RF解との絶対誤差でも、幾何近似誤差や物理誤差の上界でもない。

独立物理検査として、尺度2でfが1/2、加速器規約のR/Q・Gとピーク比が不変となる
Maxwell相似則を用いる。今回の五量表は加速器規約のR/Qを採用する。
全水準のf/RQ/G/E比/B比を比較し、許容相対差2e-8で検査する。
二次写像を保持する系列のRitz単調性も確認するが、RFやピークに単調性は仮定しない。

回転楕円体の独立解析体積4πab²/3とnative解析曲線の体積を照合する。
二次FEM領域の体積は2π∫r dAを別に積分し、元解析体積との差を記録する。
この体積は局所/一様細分中に不変である必要がある。体積差からRF誤差を推定しない。

JSONに各尺度の全水準・自由度・solve時間・停止位置・追加対照との差・幾何診断を保存する。
CSVには水準ごとの対照との差を出力する。時間は単発のローカル観測であり、検証負荷も方法で異なる。
基準未達・追加対照の予算不足を成功とせず、一般的な適応優位や精度受入をこの一例から主張しない。

初回予算8水準・適応20000要素・追加対照32000要素では、尺度1がLEVEL_LIMIT / REFERENCE_BUDGET。
一様側は20480要素・41281自由度で最初の確認を完了したが、追加対照を作れなかった。
尺度2は、加算順序を保持する組立高速化へ移るため所有プロセスを明示終了した。
初回 out/curved-nonsphere-initial-20260909 は部分結果として保持し、両尺度合格とは扱わない。
再計算の予算を12水準・適応100000要素・追加対照100000要素へ増やす。誤差閾値は変更しない。
