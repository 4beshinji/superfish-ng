二進回転行列をR、L²=c²+s²とする。Rは直交回転のL倍なので、元の半軸a,bと有効距離δ/Lを使って軸方向の議論へ戻せる。Lを1へ丸めず、平方根を含む条件はL²の有理式として扱う。

非円楕円p(θ)=(a cosθ,b sinθ)の、同じ距離を持つ異なる法線接点をθ=α±βと書く。K=a²−b²≠0とし、二点の距離二乗の差と両接線への直交条件を消去すると、K sinα cosα sin²β=0を得る。異なる接点なのでsinβ≠0となり、二点はどちらかの主軸に関して対称である。周期で同じパラメータ点になる対は別に分類する。

第1軸での反射対θ,−θではδ>0かつ
`q=sin²θ=(δ²a²/(L²b²)−b²)/(a²−b²)`、0<q≤1を必要とする。共有中心の回転前座標は `((a²−b²)cosθ/a,0)`。
第2軸での反射対θ,π−θではδ>0かつ
`q=(δ²b²/(L²a²)−b²)/(a²−b²)`、0≤q<1を必要とし、共有中心は `(0,−(a²−b²)sinθ/b)`。
除いた端の等号は二つの接点が同じになる場合であり、内点へ丸めない。残す端の等号は反対側の接点が中心で一致する場合で、別の共有端点との重複を数えない必要がある。

双曲線の同じ枝p(u)=(σa cosh u,b sinh u)では、u=α±βと同じ距離/直交条件を消去して `(a²+b²)sinhα coshα sinh²β=0` を得る。異なる二点はα=0、すなわちu,−uに限る。`−σδ>0`、`q=sinh²u=(δ²a²/(L²b²)−b²)/(a²+b²)>0` が必要で、中心は `(σ(a²+b²)cosh u/a,0)`。q=0は同じ接点に戻るため自己交差へ追加しない。

実装では、同じ元パラメータの有限共通区間（楕円は真の2π周期も含む）と、上記で全てに絞った有限の反射対を別に検査する。平方根の有理数区間と元の有限弧所属を使い、各反射対が両弧に属することを確認する。共有パラメータ端点と自己交差中心が一致する場合の重複も証明して除く。全候補の所属・除外・重複が確認できたときだけ全域分類とし、予算不足では既知の証拠を保持する。
