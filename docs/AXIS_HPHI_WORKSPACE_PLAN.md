# 軸接続HφをローカルProject・表示・独立Studyへ接続する計画

`AXIS_HPHI_RF.md`の専用Case/nativeを既存Hφ操作へ接続する後続工程。[実装・受入証拠](AXIS_HPHI_WORKSPACE.md)の範囲で限定受入。
RF候補の標準・独立検証を変更しないよう、別候補を使う。

受入条件は以下とする。

- HphiProjectの明示Case選択へAxisHphiCaseを追加し、旧二形式の意味を維持する。canonical TM/TEやCartesian Projectと誤読しない。
- 実worker・native/管理済み取込・取消・再起動を通し、元係数と全ファイルを保持する。kind変更、入力/保存の改変、未完保存は拒否する。
- 元のP1/P2・軸上場・全E/H/B・符号・位相・SIと穴を除いた表示を使う。軸は壁のゼロ面積区間として示す。
- GUIは軸の有無と加速経路の宣言を区別する。nullならN/A、宣言した場合は複素Vaccと二定義のR/Qを表示する。表示単位変更でも元SIを保持する。
- 明示軸経路をGUIで有効化/無効化し、開始/終了/phase origin/betaを保存・復元する。固定多項式積分のCaseへ不要な積分次数を追加しない。
- 一様尺度Studyは全輪郭/節点に加えて明示した軸区間とphase originも同倍率で写す。betaを変えず、規格化・導電率の掃引と両R/Q/複素Vaccの尺度則を個別に確認する。
- 全点の所有native・完全再生とGUIの点取込を検証する。独立順位を追跡IDや収束精度と表示しない。
- 実ChromeでProject/Studyの開く・保存・計算・取消・再起動・図・SIプローブを操作し、元nativeとCLI結果へ照合する。既存Hφ二形式とTM/TE/平面RFの操作も確認する。
- 標準回帰と既存seedの周波数/RF、不変候補と統合ソースを確認する。新しい依存・外部サービス・旧版参照は追加しない。

正半径・軸接続をまたぐ追跡、一般の形状変形、曲線PEC穴、複数材料、旧版照合はこの工程では完了にしない。
