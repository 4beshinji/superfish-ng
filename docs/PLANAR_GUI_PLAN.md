# 平面RFの表示・GUI接続計画

[平面Project/Job](PLANAR_JOBS.md)に続き、xy断面の編集・保存・計算・結果表示をローカルGUIへ接続する。軸対称画面のr/z入力や全長エネルギーへ平面値を流用しない。矩形Case版1と明示単純多角形版2の既存科学契約を維持する。

## 表示基盤の受入条件

保存nativeを完全再検証してから、実FEM係数から場を評価する。TMは実Ezとquadrature Hx/Hy、TEは実Hzとquadrature Ex/Ey。ゼロ成分を含めたE/Hの全成分を保持し、B=μ0Hを明示する。xyはm、表示だけmm等へ換算し、プローブCSVはSIと位相を保存する。P1の要素間勾配不連続を平滑化して精度が高く見えるようにしない。P2の表示細分でも元要素と重心座標から評価し、表示の三角形で別の解を作らない。

矩形と多角形、P1/P2、TE/TM、二尺度・回転で保存成分/API/表示配列/プローブを照合する。正負の色範囲、xy座標・PEC境界・モード順序、実部とquadratureの区別を図へ記す。独立矩形/三角形の解析場を共通位相で比較する。単位長エネルギーJ/m、壁損失W/m、Q0/G、加速量N/A理由を保持する。外部点・未知キー・無効モードを厳密に拒否し、図作成後に元nativeのhash不変を確認する。

## GUI接続の受入条件

平面専用の明示した操作領域を設け、専用PlanarProjectの読込・保存・正規化・入力編集・実ジョブ投入へ接続する。矩形は寸法とメッシュを編集でき、多角形は元Caseと明示メッシュを欠落なく保持する。未対応の曲線・材料・穴・伝搬・Study/追跡/調整を黙認しない。

履歴の平面kindを正しく開き、軸対称追跡の候補へ混入させない。直接native/管理済み取込、保存Projectの復元と新しいジョブへの再実行、実中止とサーバー再起動を確認する。ジョブ完了をメッシュ精度合格と表示しない。xyプローブ、画像とnativeのダウンロードを用意し、表示と保存量の単位を明示する。

既存ローカルHost/Origin/tokenとstrict actionキー検査を共有する。描画cacheは全native/実装hash・モード・表示設定を含み、別偏波や別Caseの画像を返さない。ブラウザーによる実操作、CLI/API/nativeとダウンロードの一致、領域外エラー、元hash、旧TM/TE操作、全体回帰と数値回帰を受入根拠にする。単なるHTTP応答や画像生成だけでブラウザー操作を合格としない。

この文書は後続工程の条件であり、GUI実装済みという意味ではない。親P02と全計画の受入は別途継続する。
