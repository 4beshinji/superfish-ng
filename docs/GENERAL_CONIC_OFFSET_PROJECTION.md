## 円錐曲線と円の接触からの消去式

相手の中心をO、半軸をa,b、二進回転成分をc,s、n=c²+s²とする。
εは楕円で+1、双曲線で−1。候補中心Pに対してw=P−O、相手の局所座標(u,v)=Rᵀw/nを使う。
相手曲線の同次行列Qと、中心P・半径|e|の円の同次行列Cは

```text
Q = diag(1/a², ε/b², -1)
C = ((n, 0, -nu),
     (0, n, -nv),
     (-nu, -nv, n(u²+v²)-e²))
```

である。実接点ではQxとCxが平行なので、あるλについて(Q+λC)x=0。
両曲線上の点だからxᵀCx=0でもあり、行列の階数が2なら随伴行列はxxᵀに比例するため、
det(Q+λC)のλ微分も零になる。階数が1以下なら随伴行列自体が零となる。
e≠0ではCは非特異なので、このλは有限である。従って行列式の三次式は重根を持つ。
逆に、重根だけでは相手の実接点・符号・有限枝を証明できない。

T=b²+εa²、Bを次の二次形式の対称双線形形式とする。

```text
q(w) = b²(c wz+s wr)² + εa²(-s wz+c wr)²
a²b² det(Q+λC) = c0+c1 λ+c2 λ²+c3 λ³
c0 = -ε
c1 = ε(|w|²-e²)-nT
c2 = q(w)-n²a²b²-ne²T
c3 = -n²e²a²b²
Δ = c1²c2²-4c0c2³-4c3c1³-27c0²c3²+18c0c3c1c2
```

必要条件はΔ=0。回転ノルムは1へ丸めない。
これは実装中に自前に展開した行列式であり、旧版solverやその係数を使用していない。
三次式の判別式は独立の5×5 Sylvester行列式とも照合した。

## 元オフセットの代入と根の保持

既存の有理チャートで元曲線の点をC₁+U/H、元接線をV/H、S=V·V>0とする。
Hは楕円で1+q²、双曲線で1−q²。元の向きを補正した距離dを使い、
P=C₁+U/H+d JV/√S、W=(C₁−O)H+U、D=H²Sと置く。
c1,c2はそれぞれ(E₁r+E₁s√S)/D、(E₂r+E₂s√S)/Dの形になる。
Eの有理部は次数8以下、根号部は次数6以下で、Dの次数は8。

```text
D⁴ Δ = E1² E2² - 4c0 E2³ D - 4c3 E1³ D
       -27c0²c3² D⁴ + 18c0c3 E1E2 D²
      = A + B√S
```

展開はQ[q,√S]で正確に行う。A,Bの共通因子のうち、実チャート内部で正と分かるH,Sだけを
余り零の除算で取り除き、何を何回除いたかを記録する。
一般の場合にもA,BはSを共通因子に持つため、整理後は次数28/26以下となる。
必要条件の射影多項式N=A²−B²Sは次数56以下。特殊な形状ではさらに次数が下がる。
定数倍は整数の原始多項式へ正規化するが、可能な実元点を含む因子を捨てない。
恒等零は有限根へ変換せず未確認として返す。

すべての異なる実根を[-1,1]で分離し、各根で元のA+B√S=0を厳密な代数符号で確認する。
反対の元法線へ対応する共役根をここで除く。楕円の二つのチャートの重複端を一度だけ数え、
双曲線のq=±1は無限遠として除く。既存の認証付き区間で元の有限弧へ所属を照合する。
元オフセットの速度係数1−dκも代数符号で確認し、零ならsource_regularity=CUSPとする。
相手との接触種別をこの元曲線だけの正則性から決めない。

projection_completeは上記の元候補列挙だけの完了フラグ。
target_incidence_certifiedはこの段階では常にfalseで、中心数や元点対数を返さない。
相手の距離符号、双曲線の実枝、有限相手弧、同一中心へ来る別の相手元点は次段階に残す。

## 整数係数の根分離

次数56の最初の整数幾何例で、既存の有理数Sturm法は171.83秒経過しても根分離を完了しなかった。
専用ログ・PID・コマンドを確認して意図的に停止した。完了時間や失敗した数学的判定とは扱わない。
一般二進回転の次の例にはまだ進んでいなかった。

新しいprimitive_polynomial_rootsでは、各疑似除算で
R←|lc(B)|R−sign(lc(B))lc(R) qᵏBとし、正の整数contentで割る。
元の有理余りの正定数倍を保持するため、Sturm列の符号変化数は変わらない。
有理端点a/bでの評価はb^degree p(a/b)を整数Horner法で計算し、分母の繰返し正規化を避ける。
重複因子除去に使ったSturm列と、根分離/根精密化の列も再利用する。
既存のpolynomial_rootsとRootSystemは保持し、新経路のみに適用した。

同じ最初の例、同じ[-1,1]、要求幅1/4096、最大10000箱の最終整数版は0.330499秒で
異なる8実根を91箱で分離した。初期整数試作では0.420686秒、二進回転.3/.7の例では51.849796秒だった。
その後に列の重複計算を除いた。初期試作の値を最終版の実測とは扱わない。
最終の二進一般回転で両チャート・元所属・独立参照まで含む実測は113.287427秒。
全入力への高速性や、箱予算による係数演算時間の上限を主張しない。
