# S01: 有限外部境界とメッシュ細分の分離検証

2026-09-13 JST。平面/軸対称静電の既存Case・実FEM・native/CLIに対し、計画の境界遠方化と細分を分けて検証する。検証スクリプトと実行可能な合成例を追加する限定課題。実装中・未受入。

- 平面は片側の一様帯状電荷、軸対称は内面の固定電束を持つ同軸領域とする。電荷/誘電率/内側形状を固定し、外部の接地位置だけを2/4/8倍へ移す。
- 各外部境界でP1/P2の3段階細分を別に行い、元Phi/E/D、エネルギー、元Dの電極電荷を解析解と別々に比較する。
- 共通内部の場は境界位置に依存しない一方、絶対電位は帯状電荷で距離に比例、同軸電荷で距離の対数に比例する。固定電位掃引を固定電荷問題と混同しない。
- 電荷の符号とepsilon倍率を検査し、反力/Gauss則だけで元場精度を受け入れない。単位は平面C/m・J/m、軸対称C・Jで分ける。
- 外部境界差と各固定境界の離散化誤差を別に記録し、無限遠0電位の有限解や開放境界誤差上界を主張しない。
- 主ツリーへ単独実行可能な軸/平面の静電Case例を追加し、専用native/CLIで再生する。
- 既存ソルバー・保存・CLIの数値ソースを変更しない。既存標準回帰のsource hashを照合し、新規2unitと独立境界/細分系列を実行する。

新規依存・外部資料・旧版実行なし。親S01の残項目は受入条件との対応で改めて判定し、全計画の完了とは扱わない。
