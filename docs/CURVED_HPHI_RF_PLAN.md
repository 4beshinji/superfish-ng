# 明示曲線Hφの固有解・場・RF

[穴付き二次幾何](CURVED_MERIDIONAL_GEOMETRY_PLAN.md)と[変分形式](CURVED_HPHI_FORMS_PLAN.md)に続くP03の工程。未実装・未受入。
正本は明示した二次多項式メッシュ。真空・閉PEC・m=0 Hφを専用Caseで指定し、軸あり/なしを幾何から区別する。

受入条件：

- strictな専用Caseと最低正スペクトルを実装する。正半径qだけで定数静的循環を検証して除き、軸接続uでは零モードを捨てない。
- SI・peak exp(+iωt)・Hφ real・Er/Ez quadratureを保持する。U規格化、直交性、元K/M残差、最低帯域を再検証する。
- 二次写像の物理微分から全場成分を評価する。物理座標プローブは写像を逆に解き、穴・領域外・未解決の逆写像を拒否する。境界では一つの元要素の片側微分を返す。
- 元場から全体積の電磁エネルギーと全PEC成分/区間の壁損失を積分する。実曲線の弧長を使い、穴の損失を差し引かない。二つの積分次数の比較をf/場/離散化誤差とは別に記録する。
- 明示した真空軸区間・beta・位相原点だけに複素Vaccと二つのR/Qを返す。経路なしではN/Aを保持する。
- 直線極限の既存f・元場・全RFと一致する。曲線の軸あり/なし・0/1/2穴・P1/P2で独立行列の最低固有値と独立な場/積分を照合し、尺度・U・導電率・軸位相原点の則を確認する。
- 標準回帰と旧seedのf/RFを維持し、未対応のモデル・経路・値・保存入力を拒否する。

この工程は専用API。native・CLI・Project・Job・GUI・Study・追跡と、解析曲線からの自動生成は後続の受入工程。
有限FEMの一致を連続問題の誤差上界や曲線表面ピーク精度へ読み替えない。合成形状を実測構造と呼ばない。
既存の自作固有値処理、二次逆写像、軸電圧積分を再利用する。新規外部資料・依存・旧版参照は予定しない。
