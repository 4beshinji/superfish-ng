# 同じ真空領域のHφ電場・磁場内積

共通積分幾何の後続。固定候補で検証中、未受入。P03/D01/N03の場の対応・収束診断に使う物理積分だけを扱う。

対象は既存の専用CoaxialSolution、HphiMeshSolution、AxisHphiSolution。各Case・元メッシュ・元係数・最小正スペクトルを再構築検証し、同一真空領域の元要素上で比較する。正半径q形式と正則軸u形式の区別を保つ。
二つの場は同じ物理(r,z)座標・peak exp(+iωt)、Hφ実部・Er/Ez quadratureで評価する。省略成分は対象物理で恒等的にゼロ。
体積測度2πr dr dzで、EとHの自己・交差内積を別々に返す。単位はV² mとA² m。全3Dエネルギーの規格化や符号を勝手に変更しない。

受入条件：

- E自己内積×ε0/4とH自己内積×μ0/4が独立のFEM行列エネルギーに一致し、各固有モードの電気/磁気エネルギーがそれぞれ全U/2となる。
- 元の係数符号反転・エネルギー変更・節点/要素番号・境界分割変更を正しく反映する。混次数/独立メッシュの交差積分は交換時の転置と一致し、正規化した合同Gram行列は半正定値。
- 軸あり/なし、0/1/2PEC穴と閉同軸の両P1/P2、同じ実形状での閉同軸/明示mesh表現を扱う。実解析場の独立投影と細分で、周波数とE/Hの対応を分けて確認する。
- u形式は多項式積分、q形式は1/rを含む積分の二次数比較を行い、未解像なら明示拒否する。積分安定性を離散化誤差の上界としない。
- Case/係数/元meshの改変、異なる真空/穴/軸区間、予算超過や非有限値を拒否する。mode rankを追跡IDとして返さない。
- 標準、既存f/RF、固定候補と主source照合。既存native/Caseの意味・閾値・benchmarksは変更しない。

この工程では順位対応の一意性・縮退の部分空間・guard・細分誤差判定・保存/CLI/GUIを追加しない。後続の要求形式でそれぞれ宣言し検証する。
外部資料・依存・旧版参照の追加はない。物理式は本プロジェクトのPHYSICS.mdと各専用FEMの規約を用いる。

候補612source。4unit・48FEM/native/48比較と二尺度、解析8FEMがPASS。独立検証器は共通領域APIの交差点・重心座標・場評価を使わず、物理座標で元係数の多項式を再構成/微分し、別の矩形小区画とGauss積分へ照合した。標準は継続中。
