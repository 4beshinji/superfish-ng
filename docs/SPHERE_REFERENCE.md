# 球形PEC空洞の独立電磁場参照

## 対象と導出

半径R、中心(r,z)=(0,R)、真空の閉球、m=0 TMの正則なl=1・最初の径方向根を扱う。
native FEMの結果を係数・固有値・補正式に使わない。
球ベッセル関数の定義・微分恒等式は
[NIST DLMF §10.47](https://dlmf.nist.gov/10.47)、
[§10.51](https://dlmf.nist.gov/10.51)（REFERENCES.md R28）。
以下の縮約、PEC条件とRF積分は本プロジェクトのSI・peak-phasor規約から導出した。

t=z-R、s=√(r²+t²)、x=ks、F(s)=j₁(ks)/(ks)とおく。
u=A F(s)、Hφ=r uは、既存の強形式
u_rr+3u_r/r+u_zz+k²u=0を満たす。
すなわちF''+4F'/s+k²F=0に帰着し、球ベッセルの微分方程式で確認できる。
中心はF(0)=1/3で正則。小さいxの評価にはTaylor展開を使う。

Er=−A r t F'(s)/(s ωε₀)、Ez=A[2F(s)+r²F'(s)/s]/(ωε₀)。
これらは既存サンプラーと同じ電場のquadrature成分であり、RMSではない。
球面の子午線接線に射影した電場は
−A(r/R)[2F(R)+R F'(R)]/(ωε₀)。
したがってPEC条件はj₁(χ)+χj₁'(χ)=0、χ=kR。
最初の正根を区間(2,3)で解き、f=cχ/(2πR)とする。
一般形状のmode indexをこのラベルへ自動変換しない。

## 正規化とRF積分

振幅Aは総エネルギーU=μ₀/2 ∫H²dVから求める。
角度積分を先に行うと

- ∫H²dV=(8π/3)A²∫₀ᴿ s⁴F(s)² ds
- ∫wall H²dS=(8π/3)A²R⁴F(R)²
- Pwall=Rs/2 ∫wall H²dS、Rs=√(ωμ₀/(2σ))
- G=ωU Rs/Pwall、Q₀=ωU/Pwall

電圧は全軸z∈[0,2R]の∫Ez exp(iωz/(βc)) dz。
中心を基準にした偶関数の余弦積分を数値積分し、exp(iωR/(βc))を掛けて
既定のphase origin=0へ戻す。これはRF FEMの区分多項式積分とは別の計算。
R/Q accelerator=|V|²/(ωU)、circuitはその1/2。
APIは全軸・active length=2Rの参照に限定し、区間/位相原点を任意設定するAPIではない。

実装はanalytic_sphere.SphereTM。FEMソルバーから参照しない。
参照関数の試験は、PEC接線場、中心の有限性、別の2次元Gauss積分による
電気/磁気エネルギー各U/2、寸法・正規化変更、電圧位相と二つのR/Qを検査する。

## FEMとの比較手順

実行コマンド:
OPENBLAS_NUM_THREADS=1 python scripts/validate_sphere.py --out out/sphere-new

R=0.08 m、P2、1 J、β=1、σ=5.8e7 S/m。
元曲線は円の半周と軸で、弦誤差0.8/0.2/0.05 mm、FEM最大辺長10 mm固定。
各段階は実際に行列を組み立てsolveし、save_runで保存する。
基準値との相対誤差を周波数0.1%、各RF量・磁場・電場・軸電場1%で別々に判定する。
磁場の符号合わせのみを行い、振幅の最小二乗合わせは行わない。
体積場は球中心から0.95R以内の体積重み付き256点、
軸場は全軸の64点Gauss積分で比較する。
これは有限サンプリングによる場誤差指標であり、全領域の厳密な誤差上界ではない。
壁損失の積分は照合するが、境界ピークの精度は認定しない。
曲線FEM、楕円/双曲線の独立電磁場照合、旧形式の仕様確認とは別の受入である。
