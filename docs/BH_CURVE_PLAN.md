# S04: 単調な等方B-H表の構成則

2026-09-13 JST。後続の限定課題。未実装・未受入。

最初に非線形磁静場の材料契約を独立APIで確定する。B[T]とH[A/m]のノルム表は原点(0,0)を含む有限の非負実数列とし、両列の厳密増加を要求する。補間はH(B)の区分線形と明示し、表の上限を超える入力は拒否する。測定範囲外の飽和曲線、残留磁化、ヒステリシス、異方性、温度依存、RFへの転用は推定しない。来歴は必須の非空文字列で保持し、検証例には合成表と明記する。

区間傾きdH/dB[1/(H/m)]と割線H/Bを区別する。元ベクトル場はH=h(|B|)B/|B|、接線はT=(h/b)I+(h'−h/b)nnᵀ、n=B/b。零場は第一区間の傾きからTを定める。節点では右区間、最終節点では左区間の接線を返し、微分の不連続を隠さない。これは以後の減衰Newton法で使う局所線形化であり、節点に通常の二階微分が存在するという宣言ではない。

w(B)=∫₀ᵇh(t)dt[J/m³]とw*(H)=∫₀ʰb(t)dt[J/m³]を同じ表から区間ごとに積分する。独立に計算した両者でw+w*=B·Hを確認する。反跳材料のW0/Wsと同じ名前や基準を流用しない。逆関数B(H)、零場極限、半径方向/接線方向の接線固有値、符号反転と座標回転、線形極限を検証する。入力の丸めで正の傾きや有限積分を解像できない場合も拒否する。

追加5unit、独立した区間積分・構成則微分・逆関数・回転/反転を受入条件とする。微分は節点から離れた点と節点での明示片側を分ける。独立比較の許容値は値/積分/線形極限1e-11、有限差分の勾配1e-6、接線2e-6から開始する。標準検証と既存周波数/RFも照合する。材料評価の成功を、非線形FEMやメッシュ精度の受入と扱わない。

後続で平面/軸対称の残差と接線組立、線形極限、減衰反復、範囲外試行の棄却、失敗履歴・再構築を接続する。原S04の独立ソルバー比較と対象版モデル確認は残る。非線形誘電体の追加はC00で必要性を確認した後の別課題とする。

公開根拠は[COMSOL公式のB-H構成則](https://doc.comsol.com/6.3/doc/com.comsol.help.acdc/acdc_ug_magnetic_fields.08.032.html)の静的なH(|B|)と同方向の場、および[公式の微分透磁率の説明](https://www.comsol.com/blogs/how-the-b-h-curve-affects-a-magnetic-analysis-and-how-to-improve-it)の単調性と局所線形化である。区分線形・外挿拒否・節点接線の選択、ベクトル微分と区間積分は本実装の独立した設計判断。資料のコード・材料表・補間実装は再利用せず、新規依存や旧版資産を追加しない。
