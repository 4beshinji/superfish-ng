# 正半径Hφの独立Study接続計画

[Project/Job](HPHI_JOBS.md)と[表示/GUI](HPHI_GUI_PLAN.md)の後続。
下記の独立掃引・保存/worker・GUIを[実装契約と検証](HPHI_STUDY.md)で限定受入した。収束・追跡は含めない。

## 入力と物理の契約

専用HphiProjectを含むstrictな独立掃引を用意する。各点で保存した入力から実FEMを行い、
全正周波数順位・場・RFを保存する。順位を追跡IDとせず、mode_tracking=not_performedを明示する。
点の実行完了を収束・離散化精度の合格と判定しない。

候補パラメータは一様な正尺度、閉同軸円筒の内半径/外半径/長さ、全3D蓄積エネルギー[J]、壁導電率[S/m]。
一般メッシュの寸法変更を円筒パラメータへ暗黙変換しない。一様尺度では元外周・全穴・全節点を同じ尺度で変換し、
元の番号・接続とP1/P2次数を保持する。変換後もstrict幾何を再検査し、binary64で境界の共線性や正Jacobianを
保てない指定は実行前に拒否する。境界を許容差で吸着させたり、穴を省いたりしない。

全派生Projectを出力確保より前に検査する。実workerの排他claim、入力/実装変更拒否、各点nativeと
summaryの完全再生、保存再起動と新しい出力先への再実行、中止/失敗を既存Job契約へ接続する。
summaryは各点の元保存係数によるRFと完全一致させ、N/A二規約、U[J]/P[W]、位相を保持する。

## 先行する独立不変量と受入条件

1. 尺度sに対するf∝1/s、G不変、Q∝sqrt(s)。U固定ならE/H∝s^(-3/2)、P∝s^(-3/2)。
2. 形状固定のU倍率aに対しf/G/Q不変、E/H∝sqrt(a)、P∝a。
3. 導電率倍率bに対しf/場/G不変、Q∝sqrt(b)、P∝1/sqrt(b)。
4. 両幾何・両次数・各パラメータで実FEM/CLI/workerと保存再生を比較し、既存解析場の受入を保持する。
5. 非整数/未知版・未対応パラメータ・幾何崩壊を拒否する。source途中変更、再hash後の点入力/summary改変、
   点欠落・取込点への置換、中止・重複worker・未完了状態からの再起動を検査する。
6. GUIを接続する場合は、定義往復、実worker、中止、各点の元場表示、再起動、CLI/nativeとの一致を
   実ブラウザーで確認する。既存画面と標準f/RF回帰も確認する。

単純な独立掃引をHφ追跡・細分収束・調整・最適化の受入としない。親P03/O02と全計画の残項目を維持する。
新しい外部資料・依存・旧版参照は不要。既存自作PlanarStudyの操作契約を参考にする。
