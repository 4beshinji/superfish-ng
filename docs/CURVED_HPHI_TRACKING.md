# 曲線HφのE/H部分空間追跡（H13-b、受入済み）

`CurvedHphiTrackingRequest`と`track_curved_hphi_modes`は、元の曲線q/u固有場、全二次比較領域、各側の明示比較空間を受け取る。元E/Hの体積Gramと、各元物理領域内の有限スペクトル診断を組み合わせて対応を判定する。

独立した順位交換/縮退を含むH13-bの条件別受入は末尾に記録する。曲線調整/所有履歴/CLI-worker/GUIの受入は後続H13-c〜eに残る。

## 要求の所有と検証

要求版1は全二次domain、前後のnative chart、前後の比較native幾何とchart、追跡する正固有値prefix長、以前の個別IDまたはID集合、P1/P2比較次数、数値controls、求積点予算を保存する。transportは固定円筒成分のunitary L2だけ。幾何・chart・ID群をコピーして外部入力の変更から切り離す。保存は排他的生成で、既存要求を上書きしない。

未知フィールド・bool数値・不正ID・不正有理数chartを拒否する。構築時のchart検査は形式と参照セル/座標の範囲までで、実native幾何との全係数一致・被覆・丸め検査は追跡時にH11比較領域で行う。省略chartは恒等対応の場合に限り比較器が受け入れる。異なるnative分割では明示chartが必要。

実行時に両solutionを元caseから再検証する。各追跡prefixには少なくとも一つの計算済み上側guardモードを要求する。E/H Gramは全二次領域と両側の実回転体積で積分する。有限比較スペクトルは、各側の元domainを`same_vacuum`にした別々の診断として求め、形状変換から周波数則を推測しない。

## ID判定

元周波数の近接または有限比較区間の重なりで周波数群を構成する。既存のID集合と重なる群は統合する。元E/H Gramから別々に部分空間対応を求め、対応した前後rank集合と以前のID集合が両者で一致することを要求する。一次元対応はE/Hで必要な係数符号も一致しなければならない。

guardをまたぐ群、追跡帯/最初のguardの有限スペクトル未確認、E/Hの不完全/曖昧な対応、両者の割当や位相の不一致は`UNVERIFIED`となり、現在の個別IDを全てnullにする。多次元対応はID集合だけを保持し、分離後に自動で個別名へ戻さない。係数・周波数・RFを変更せず、連続経路の一意なモードIDや連続問題の誤差上界は主張しない。
