# S01: 軸対称静電の境界条件・Poisson解・元E/D

2026-09-13 JST。静電弱形式に続く限定課題。未受入。
正値実数の等方誘電体・直線適合P1/P2に、領域一定rhoと明示境界を接続する。
すべての境界辺を電極電位[V]、計算領域外向きDn[C/m²]、対称軸のいずれか一つへ割り当てる。
軸辺の電極化や、外形への暗黙0電位・暗黙外部境界は拒否する。
少なくとも一つの電極を必要とし、純Neumannとgaugeは後続課題にする。
共有DOFで接する異なる電極は拒否し、同一導体は同じ電極IDへまとめるよう案内する。

受入条件：

- D=-epsilon grad(Phi)、div(D)=rhoの符号を保持する。Neumann荷重は-∫Dn Ni dS。
- 全軸DOFを残してDirichlet消去後の疎な実FEMを解く。未対応モデルと厳密入力を維持する。
- 元セルPhi/E/Dと領域エネルギー∫epsilon E²/2を評価する。RFのphasor係数は使わない。
- 電極反力KPhi-fによる電荷と、元Dの負の外向き表面積分による電荷を別々に報告する。
  離散反力の総電荷保存・エネルギー恒等式は検査するが、これだけで元Dの精度を合格にしない。
- 電荷0、境界Dn=0、電極2つ・電位差非0の場合にだけ、反力とエネルギーによる二端子容量を定義する。
- 二層円柱の平行板でPhi、接線E/法線D、容量・領域エネルギー・両電極電荷を解析照合する。
- 同軸コンデンサでは対数Phiと1/r電場、容量、表面電荷をP1/P2で別々に細分照合する。
- 軸対称Phi=r²とPhi=z²の独立した製造解で負のrho、非0 Neumann、元E/D、電荷とエネルギーを独立検証する。
- 電位の定数シフト、印加電位/電荷の反転、誘電率・形状尺度則を確認する。
- 周波数/RFの既存標準回帰を保つ。純Neumann、浮遊電極、曲線、平面、非線形、保存/CLI/GUIは別の受入工程。

解析式は検証にのみ使い、FEM解を置き換えない。外側Dirichletや側面Neumannは有限問題の明示契約で、開放境界の厳密解とは呼ばない。
