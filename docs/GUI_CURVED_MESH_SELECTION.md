# 曲線メッシュからの図上要素選択

2026-09-09。現在のCaseの初期メッシュを作り、全細分履歴を適用した二次曲線空間を表示する。
表示する0始まりの要素番号と6節点は実計算用空間そのもの。
各辺は端点・中点から復元した二次Bezier曲線で描き、表示用に粗くした別メッシュを使わない。
固有値計算は行わない。鏡映設定がある場合も、履歴で番号を指定する元領域を表示する。

「現在のメッシュから図上選択」で図を作り、要素をクリックすると選択/解除できる。
キーボードのEnter/Spaceも選択操作に割り当て、選択番号と個数を表示する。
「履歴末尾へ追加」でmarked段階を追加する。一様段数方式の場合は、同じ回数のuniform段階へ
変換してから追加する。既存の局所履歴を落とさない。
要素品質・予算は既存の細分/計算経路で検査し、選択しただけで細分成功を保証しない。

メッシュ要求時の入力全体を保持し、要求中または表示後にCase/履歴が変わった場合、
その古い要素番号を履歴へ追加できない。入力が同じ状態へ戻った場合は元メッシュと同じ意味になる。
別Projectを開くと選択図を消去する。新しい細分段階を追加した後も図を消去し、次の選択前に再構築する。

図上表示はnative contour_mesh・二次曲線要素・5000要素以下に限定する。
メッシュ生成/履歴の要素上限を表示上限以下へ制限するが、超過時は拒否し、粗くして代用しない。
数値計算用Caseの元の上限は変更しない。大規模メッシュの図上選択、既存段階の途中への図上挿入、
形状変更後の番号の自動対応付けは未対応。番号入力による履歴編集は従来どおり使える。
