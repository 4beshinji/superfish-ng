# 同じ真空領域のHφモード部分空間対応

元E/H内積と明示比較空間のスペクトル診断を接続するAPI工程。[実装記録](HPHI_SAME_DOMAIN_TRACKING.md)の範囲で限定受入。
正半径qまたは軸接続uの、同じ外周/全PEC穴を持つ独立P1/P2メッシュ間を対象にする。
元のFEM解と、各元解に対して明示した比較メッシュ/次数を要求する。形状変形の写像はこの版に含めない。

受入条件：

- 前後の追跡帯域を最低正スペクトルのprefixとして宣言し、少なくとも一つの計算済み上端guardを要求する。前のIDまたはID集合の完全な分割と全controlsをstrictに保存/読込する。
- 元FEMの完全再検証、全E/H体積内積、各元解の有限比較区間を計算する。周波数近傍と区間の重なりを群にし、帯域の群がguardへ及ぶ場合や射影未達はUNVERIFIED。
- E/Hをそれぞれ規格化した物理Gramから、全方向の最小主内積と割当余裕で部分空間を対応する。両場の対応と、個別モードの係数位相が一致することを要求する。
- 縮退・未分離の多次元群はID集合として保持し、分裂後も元の個別IDを捏造しない。独立した周波数順位をIDへ置き換えず、群の次元変更や曖昧な対応は未検証とする。
- 0/1/2穴・軸あり/なし・P1/P2・符号/規格化/二尺度、独立メッシュの実FEM、円筒の解析場による対応と縮退、guard不足/帯域退出/弱い対応、元native不変、標準と旧f/RFを確認する。

PASSは指定された二つの有限FEM部分空間の数値対応で、連続した形状変更の同一性証明・連続問題の誤差上界・表面ピーク保証ではない。
専用の所有保存・再生・CLI/worker/GUI、履歴連鎖、形状写像は後続工程。新規外部資料・依存・旧版参照なし。

標準1068件・独立36比較と縮退/順位逆転12正逆比較・主4unitがPASS。主635sourceへ統合済み。詳細は実装記録を参照。
