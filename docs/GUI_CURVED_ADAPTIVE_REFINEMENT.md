# 曲線適応計算版4のGUI

2026-09-09、直前基準3671707。[版4の計算契約](CURVED_ADAPTIVE_REFINEMENT.md)を
既存の適応GUIへ接続した。計算・追跡・停止条件と保存形式は変更していない。

「入力を開く」で二次曲線Caseを読み、適応計算の確認方式で版4を選ぶ。
examples/adaptive_refinement/curved_sphere_confirmed.json の case が入力例になる。
ピーク比2量とRF3量の許容値に加え、比較する高次積分次数とその相対差の許容値を指定する。
高次次数はCaseの次数より大きく32以下。サーバーが厳密に検証する。
現在の形状から入力を作成すると、nested_curved、uniform_two_steps、
minimum_corner_angle_deg、quadrature_check_order、quadrature_relative_tolerance を含む。
滑らかな閉PEC/axis境界という版4の前提は変更しない。

版4の角度は写像後の頂点接線間の角度であり、内部の条件数の保証ではない。
初期弦メッシュの最小角はCase側の別設定である。版1〜3では直線三角形の最小角を表示し、
要求の minimum_angle_deg を維持する。版3を既定値に保ち、版4への変更を明示する。

各水準の五量と連続離散ピーク比の区間を表示する。
別表で積分次数・残差三成分・Rayleigh周波数・質量形式の差、許容値、判定を表示する。
残差成分は差のL1和を高次積分の全指標二乗で規格化する。
積分が未達なら QUADRATURE_UNVERIFIED と理由を表示し、再開できない。
個別IDを確認できず比較が存在しない水準は未評価と表示する。
物理誤差上界と幾何近似誤差の保証は与えない。

一時停止後の再開には保存要求を使い、編集したフォームの値を混入させない。
ダウンロードするJSONはサーバーが再検証した文字列そのもの。
再読込時に版・角度・積分設定と結果を復元する。改変を拒否すると前の確認済み結果を保つ。
版1〜3を開いた場合は曲線積分の表と行を消去し、版4専用の入力を無効にする。
直線表面評価ボタンは版4の結果では無効にする。対象場は最終水準の追跡済み順位で開く。

操作検証: scripts/verify_gui_curved_adaptive.mjs。
--url、--out（新規）、--request（版4要求）、--old-checkpoint（版3保存結果）を指定する。
実ChromeでCaseファイル読込・フォーム入力作成から実FEMを実行し、4水準と再開1水準、
五量/積分表、保存/改変拒否/再読込/対象場、積分未達、版3への切替を確認する。
旧版の一連の操作は scripts/verify_gui_adaptive_surface.mjs でも検査する。
外部HTTP要求を禁止し、実行前後の実装hashを比較する。

任意の局所細分履歴の直接編集、一般形状の精度/効率、幾何近似誤差の受入は残る。
N03/N04親課題全体を完了とはしない。

検証結果: 着手前647件中645合格・2 skip（624.058秒）。最終標準検証も同件数でPASS（632.244秒）。
版4の実Chrome11操作は初回PASS。out/browser-curved-adaptive-initial-20260909/report.json に記録。
4+1水準の実行/再開、五量/積分/品質設定の復元、保存JSON完全一致・改変拒否・再読込・対象場、
QUADRATURE_UNVERIFIED停止、版3切替を確認した。旧版15操作と合わせて外部HTTP要求なし。
7適応ジョブと2場取込ジョブは全て終了し、今回の検証用GUIサーバーも停止済み。
標準検証・今回の解析照合・両ブラウザーの記録hashは最終実装と一致する。
検証スクリプトの使用法表示と必須引数検査を実行中に補正したが、実装ファイルは全検証中変更なし。

今回の球形GUI計算は独立解析五量の区間両端照合もPASS。最大相対差はEpk/Eaccの2.706184e-4。
標準seedの周波数差ゼロ、RF/エネルギー差最大8.882e-16。ベンチマーク・許容値は変更していない。
