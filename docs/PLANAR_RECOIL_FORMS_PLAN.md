# S03: 平面の線形反跳透磁率・残留磁束・向き付き弱形式

2026-09-13 JST。次の限定課題の仕様。未実装・未受入。

対象は直線単純多角形の平面Az、静的実数の線形構成則B=mu0*mu_rec*H+B_rem。既存等方APIへ追加フィールドを黙認せず、専用材料/領域/分割/弱形式を設ける。mu_recは材料の直交主軸で正値2成分、B_rem[T]は同じ主軸の符号付き2成分を明示する。各領域に向きtheta[rad]を明示し、Q(theta)でテンソルと残留ベクトルを一緒に回転する。全セル所有と材料使用を検証する。

Kij=∫curl(Ni ez)ᵀ nu curl(Nj ez) dxdy[m/H]、fJ=∫Jz Ni dxdy[A]、frem=∫curl(Ni ez)ᵀ nu B_rem dxdy[A]、nu=(mu0*mu_rec)^−1。領域不連続の源はこの弱形式で扱う。fJとfremを分け、定数Az核とsum(frem)=0を保持する。

エネルギー規約は導出として明示する。構成ポテンシャルw0(B)=Bᵀnu B/2−Bᵀnu B_remはB=0を零点とし、負にもなり得る。ws(B)=(B−B_rem)ᵀnu(B−B_rem)/2はB=B_remを零点とする正値二次形。両者の差はB_remᵀnu B_rem/2で、どちらもd w/d B=H。これは固定された線形モデルのポテンシャルであり、永久磁石の絶対的な内部エネルギーや不可逆減磁を定義しない。従来のB·H/2をそのまま流用しない。力・トルクの物理契約はS05で別に扱う。

独立検証は72例（凸/凹2、P1/P2、材料3パターン、尺度2、回転/移動3）、216多項式、一様B=BremのH=0を24条件。K/fJ/frem・尺度/回転・多項式の相対または明示ノルム差1e-11以内、定数核/残留荷重総和は1e-12以内。追加5unitと標準1213件を検証する。

受入条件は、厳密JSON/未対応物性拒否、有限かつ正値の実テンソルと逆行列、回転/反転、一様残留BのH=0でKc=frem、独立高次数積分と多項式の二次形・源仕事、mu倍率でK/fremが逆比例、幾何尺度sでK不変/fJ∝s²/frem∝s、既存標準と周波数/RF回帰。参照値は合成であり材料表を同梱しない。境界付き解・元H=(B−Brem)での場/界面・保存は後続工程。軸対称や非線形/BH/ヒステリシス・温度・機械変形はこのAPIでは未対応。
