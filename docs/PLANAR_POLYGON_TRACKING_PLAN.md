## 幾何契約

`PolygonScaleMapping` は原点を中心とした `x_next = scale * x_previous` を宣言する。
scaleは正の有限値で、平行移動・回転・縦横別尺度・形状合わせは扱わない。
`previous_refinements` / `current_refinements` は、どちらの入力が他方より
四分割されているかを明示する。両方を非ゼロにはしない。最大8段、
共通三角形数は既定250000以下。予算と三角形数を生成前に確認する。

境界頂点・メッシュ頂点・三角形の順序まで照合し、番号が違うメッシュを
暗黙に対応させない。座標には尺度と中点生成の演算順による丸めだけを許し、
各成分の絶対値とその頂点に接する最短辺長の小さい方に対して16機械イプシロン以内とする。ゼロ成分には絶対許容差を置かない。
また、尺度変換と四分割の順序が異なる場合は、もう一方の順序から生成した
境界・頂点・接続が完全一致することでも検証する。局所許容差を拡大して合わせることはしない。
この数値規約は幾何フィットでも厳密な浮動小数点証明でもない。
同じ接続でも縦横比を1%変えた形状、平行移動、セル番号変更は拒否する。

`polygon_scale_overlay` は細かい側の各三角形について、両側の元要素番号と
頂点重心座標を構成する。元P1/P2多項式を直接評価できるようにし、表示補間を使わない。
共通積分の面積は前の物理xy領域に取る。矩形の単位正方形面積とは定義が異なるため、
結果の写像メタデータに明記する必要がある。規格化された対応内積では定数面積因子が消える。
逆向き比較のGramは尺度の二乗で変わるが、規格化された対応は変わらない。

## 実装済みの基盤と確認

基準a297692の523sourceは直前の標準899件合格時と完全一致していた。
`planar_tracking_polygon.py` と3unitを追加。18条件の尺度・細分方向・段数で
面積・元二次多項式・両側座標を確認し、厳密入力と異領域拒否が合格した。
この段階では基盤のみだった。その後、下記の接続候補を主ツリーへ取り込んだ。

`out/polygon-tracking-geometry-independent-normalized-20260910` は、三角形/凹形状、
TE/TM、P1/P2、尺度0.37/2、細分0/1の32比較と、参照8を含む40FEM。
元電場の自己Gramから電気エネルギーを独立に検査し、Gauss次数3/5、
一様尺度での周波数と対応、逆向き積分を照合する。
三角形の解析周波数誤差は別に記録し、粗い離散精度を追跡精度と読み替えない。

初稿 `out/polygon-tracking-geometry-independent-20260910` は、約5e12のGramの
直交成分を生の絶対許容差0.001で比べたため、丸め差約0.002で失敗した。
元logは保持する。修正版は物理的な `ε0/2` によるエネルギー規格化後に
1e-11で比較し、元の自己エネルギー条件も別に要求する。製品式や許容差は変更していない。

`out/polygon-tracking-resolution-candidate-20260910` は既存のシフト逆残差計算に
実多角形メッシュを与える隔離候補。追加8FEMの細分スペクトルとの近傍包含、
二尺度と規格化による不変量を確認してから製品へ組み込む。
有限細分空間の近傍診断に限り、連続スペクトル、固有値順位の隔離、真の誤差上界を主張しない。

標準検査 `out/validation-polygon-tracking-geometry-20260910` は遠方小形状の反例により中止（終了130）。
続く `out/validation-polygon-tracking-main-final-20260910` も、正当な尺度/細分の演算順差を拒否する反例で中止（終了130）。
どちらも受入の標準合格には数えない。

1. 矩形の既存要求版1と保存結果の完全再生を維持し、多角形の宣言写像を新しい版として導入する。
2. 両側のPlanarPolygonCase/native全体を検証してから幾何写像を構成する。異偏波・異Case種別・未対応写像は明示拒否する。

4. 専用保存の両nativeコピー、全結果再計算、改変・途中変更・再投入・中止・再起動を多角形でも確認する。
5. CLIと平面GUIの写像選択・完全条件保存・結果・コピー取込を接続する。矩形版1のGUI roundtripも回帰する。
6. 三角形の解析周波数と電場、凹形状、縮退、P1/P2、二尺度、異なる次数、細分の両方向を独立に照合する。
7. 旧Study・細分・矩形追跡・平面/軸対称native、TM seed、標準全体を確認してから限定受入する。

追跡履歴の連鎖全体はさらに別の課題。二スナップショットの対応PASSで代用しない。
新規外部資料・依存・legacy参照はない。

## 受入前に成立した二つの幾何反例

`out/polygon-tracking-offset-preflight-20260910`：原点から1e6 mの位置にある
0.01 m三角形の端を8 ulp動かすと、面積は相対9.3132e-8変わる。
座標の絶対値だけに比例する許容差ではこれを同じ形状と誤認した。
元の失敗を保持し、頂点に接する局所辺長で許容差を制限して拒否する5unitの一つを追加した。
同じ遠方メッシュ自身の写像は保持する。

その修正だけでは、凹形状の尺度0.37と細分の順序による正当な丸め差も拒否した。
`out/polygon-tracking-order-fix-20260910` で、別の演算順で生成したメッシュとの完全一致を
代替の検証方法にした。32組を正逆両方向で検証し、遠方小形状の反例も拒否した。
逆向きには、四分割が保持する元頂点と接続から粗メッシュを検証する。
許容差を緩めた幾何フィットではない。主ツリーの関連28unitは30.324秒で合格した。

`out/polygon-tracking-main-{correspondence,workflow}-20260910` に保持する。
修正後は `out/polygon-tracking-final-{correspondence,workflow,subspaces,analytic}-20260910` で再検証し合格。
