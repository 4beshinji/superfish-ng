# 固定材料界面を保つHφ比較・追跡契約

2026-09-22。H14仕様。H15の数値実装とH16の調整/所有保存/GUIを規定する。現在の材料固有解/nativeに比較対応を追加済みとは扱わない。

## 対象と既存の根拠

対象は`MaterialHphiCase`の真空を含む実数正値・等方・線形・非分散・無損失の区分一定epsilon_r/mu_r。正半径q=rHφと軸接続u=Hφ/r、直線三角形P1/P2、閉PEC、明示された全穴に限る。幾何だけを変形し、対応する材料係数は固定する。材料値変更は別の将来要求であり、本比較への暗黙入力を認めない。

根拠は[材料弱形式](MATERIAL_HPHI_FORMS.md)、[元場/RF](MATERIAL_HPHI_RF.md)、[native](MATERIAL_HPHI_NATIVE.md)、[明示直線写像](HPHI_GEOMETRY_MAPPING.md)。実装参照は`rf_materials.py`、`material_hphi.py`、`material_hphi_fem.py`、`hphi_geometry_mapping.py`。既存材料native版1、元場のSI/peak phasor、規格化U、非磁性壁金属、二つのR/Q定義を変更しない。

曲線セル/界面、複素係数、分散、異方性、非線形、体積損失、界面表面電流/電荷の新しいモデルは拒否する。H17の損失仕様を先取りしない。既存真空Caseに材料を受理させず、真空比較・曲線真空比較を材料比較の代用にしない。

## 宣言と完全被覆

H15で追加する専用比較宣言の版1は、専用format/schema_version、完全な`previous_partition`/`current_partition`、`mapping`、`material_pairs`、`region_pairs`を持つ。未知キー・boolの版番号・欠落・暗黙真空補完を拒否する。型名/公開関数名の確定はH15で行い、この構造に曖昧な省略を追加しない。

- partitionは既存`RFMaterialPartition`版1。各元FEMセルを領域で一度だけ覆い、全材料を使用する。比較空間にも専用partitionを与える。
- mappingは明示`same_domain`または完全な`HphiGeometryMapping`版1。後者は対応する制御三角形による正Jacobianの区分アフィン写像で、元FEMメッシュと制御メッシュは区別する。両側の軸型、PEC境界・全穴の役割を保持する。`same_domain`でも材料分割の一致は別に検証する。
- material_pairs/region_pairsは`previous_id`と`current_id`の組の配列。各側の全IDへの全単射を要求する。列挙順/配列indexを物理的対応と見なさない。ID改名は明示対応でのみ許可し、係数が同じだけでは領域を併合しない。
- 対応材料のepsilon_r/mu_rは正規化済み入力値として等しいこと。数値許容差で材料値変更を吸収しない。各region_pairが参照するmaterial_pairも一致すること。

共通分割は、両元nativeのセル、制御写像の区分境界、全材料界面を解像する。各共通小三角形に、両側の元セル番号・領域ID・材料ID・係数と写像所有を保持し、正面積の全領域でregion_pairが一致することを確認する。異材料領域の小さな不一致を捨てず、既存の厳密な直線被覆契約に従い拒否する。全体体積だけの一致で界面一致としない。

界面辺は隣接領域の組と両側の元セルを保持する。写像された界面の全区間と接続、端点、軸/外壁との接合を覆うことを検証する。辺番号・分割数の一致は要求せず、独立再メッシュを許す。材料係数が同一でも領域IDの境界を来歴から消さない。全nativeの被覆/界面が確認できない、型変更、穴消失、fold、未解像な写像は拒否する。

## 片側場とエネルギー内積

比較対象は再検証済みの元固有場E/Hである。元セルを指定して評価し、そのセルのepsilon_r/mu_rを使う。界面の点位置探索が返す片側を両側の平均値と扱わない。界面積分や対照検査では元セルを両側それぞれ指定する。界面上の測度ゼロを理由に、界面を横切る求積セルの材料平均化を認めない。

固定円筒成分について、自己Gramは

\[
G_E(i,j)=\int_\Omega \epsilon_0\epsilon_r\,\overline{E_i}\cdot E_j\,2\pi r\,dr\,dz,
\qquad
G_H(i,j)=\int_\Omega \mu_0\mu_r\,\overline{H_i}\cdot H_j\,2\pi r\,dr\,dz.
\]

既存の総エネルギーUで規格化した無損失固有場では各対角は2Uであり、電気・磁気エネルギーは各U/2。BをHの代わりに無重みで比較しない。真空の無重みGramに材料名だけを添える実装は不可。

共通参照座標で各側の3D体積密度を`w_a=2π r_a |det(Dx_a)|`、`w_b=2π r_b |det(Dx_b)|`とし、cross Gramには電気なら`epsilon0 sqrt(epsilon_a epsilon_b w_a w_b)`、磁気なら`mu0 sqrt(mu_a mu_b w_a w_b)`を掛ける。両自己Gramも各側の元密度で独立に積分する。これは固定円筒成分のエネルギーL2単位的移送であり、Maxwell方程式を保存するベクトル変換や実際の変形後固有場の生成ではない。実周波数・元場は各側のFEM結果を用い、写像から周波数補正を推測しない。

判定はEとHを別々に行い、部分空間の対応集合と単一モードの位相が整合する場合だけ個別IDを与える。縮退/近接はID集合を保持する。強い材料コントラストによるE/Hの相違を平均化してPASSにしない。Cauchy–Schwarz/Gram正定性、二つの積分次数、元の領域別エネルギー総和を独立診断する。

## scalar射影と有限比較スペクトル

scalar質量は正半径で`∫ mu_r q v/r dr dz`、軸接続で`∫ mu_r r³ u v dr dz`。係数移送/射影にも両側密度の平方根積を使い、全領域の材料重み付き質量に対応させる。Kは既存の`1/epsilon_r`の片側curl弱形式、Mは`mu_r`の元質量行列から組み立てる。真空のK/M/射影結果を後から一つの平均材料係数で補正しない。

各元側の比較partitionは同じ物理領域・同じ材料領域/係数・全界面を保つ。少なくとも元と同次数で、より多いセルと小さい最大辺を持ち、比較DOF/求積/共通分割予算内にあること。元qの定数静的核は比較演算子から消さず、正固有モードの順位と区別する。軸接続uは既存の全軸DOF規約を保持する。

既存Hφのshifted-inverse有限空間診断を専用K/Mと射影へ適用する。固有値はomega²/c0²、正shiftは明示し、射影損失・線形方程式残差・周波数区間/群・guardを保存する。元低順位正スペクトル全体を再検証し、要求帯域の上に計算済みguardを要求する。未計算guard、guardに接する群、未確認の射影/求積/対応はUNVERIFIEDで、個別IDを確定しない。入力不正は拒否、予算超過は明示した理由付き停止とし、無言で点/セル/モードを削減しない。

有限比較空間の近傍スペクトル診断は、連続問題の誤差上界・厳密固有値包含・連続経路の一意なID証明ではない。小さい元行列残差だけで細分/材料界面誤差が小さいとは扱わない。

## 独立受入条件（H15で実行する）

| 対照 | 必須の確認 |
|---|---|
| 一様材料 | 同一形状/Uでf比=`1/sqrt(epsilon_r mu_r)`、E比=`1/sqrt(epsilon_r)`、H比=`1/sqrt(mu_r)`、B比=`sqrt(mu_r)`を真空との独立solveで照合。既存テストのepsilon=4, mu=9ならf/6、E/2、H/3、B×3。これは個別物理対照であり、係数変更を本追跡要求へ許可しない |
| 固定材料の全空間尺度s | f比1/s、同じUでE/H/Bの振幅比s^(-3/2)、体積比s³、正逆のエネルギーGram/対応を検査。元波形・RF・norm metadataを保持 |
| 二層界面 | `scripts/material_hphi_reference.py`の独立分離解（epsilon=1/4、mu=1、長さ比2:1、k0=3nπ/(4L)）を使用。元片側のHφ、接線E、法線Dの連続条件と、非連続が許される成分/片側微分を区別。f・領域エネルギー・E/H体積L2・全PEC壁RFを別判定し、解析TEM帯域のradial guard下界も保持 |
| 独立材料積分 | 別Gauss/Vandermondeのセル/領域別積分で自己/cross Gramとmu重み付きscalar質量を照合。製造多項式は積分/界面評価用であり共振器のFEM解の代用品にしない |
| 真空極限 | 全係数1の材料専用Caseで、既存真空正半径/軸P1/P2とのf・元E/H・射影/Gram・追跡ID・RFを照合。真空経路へ入力を付け替える実装は不可 |
| 独立再メッシュと番号 | 同じ界面を持つ別FEM分割、正逆写像、セル/節点・材料/領域列挙順・明示ID改名で対応を確認。配列順位をIDとして使用しない |
| 拒否対照 | 同じ全体体積でも界面位置が違う、誤ったmaterial_pair/region_pair、係数変更、未割当/二重領域、失われた穴、曲線/損失、未計算guard、予算不足をそれぞれ拒否/未確認に保持 |
| 元native不変 | 比較前後のcase/mesh/fields/results/manifest byte、元RF全量・規格化・位相規約が不変。壁金属のmu0と媒質mu_rを混同しない。加速経路は既存の真空軸区間だけで、材料が接する場合の拒否/N/Aを維持 |

対象unitは`test_material_hphi_fem`、`test_material_hphi`、`test_material_hphi_saved`とH15の新専用テスト。独立積分/二層対照は既存`material_hphi_reference.py`と材料専用validatorを参照し、製品コードから解析値を返さない。既存物理許容差を変えず、fが合格でも場/界面/RFの不合格を残す。
