# S01: 平面静電Poisson解・元E/D・電荷/容量

2026-09-13 JST。平面の単位長さ弱形式へ全境界条件と実FEMを接続する限定課題。実装中。関連18unitはPASS、独立88例を検証中。未受入。
単純多角形の直線P1/P2、正値実数等方epsilon_r、領域一定rhoを対象とする。

受入条件：

- 軸/平面の静電プローブで、Pythonの数値とboolが混在した座標・重心座標・セル番号を変換前に拒否する。型付き数値配列と既存軸native/プローブの数値を維持する。
- 全辺を固定電極電位[V]または外向きDn[C/m²]へ明示割当する。平面でaxis_symmetryは拒否する。
- 基準電極からの電位差を解き、全DOFの元Phi/Ex/Ey/Dx/Dyを保持する。少なくとも一つの固定電極を要求する。
- Neumann荷重は-∫Dn Ni ds [C/m]、静電エネルギーは∫epsilon E²/2 dxdy [J/m]。
- 電極電荷[C/m]は離散反力と元Dの表面積分を別々に評価する。全電荷と離散エネルギーの恒等式を検査する。
- 二端子容量[F/m]は電極2つ・電荷0・他の境界Dn=0・電位差非0に限定し、反力・エネルギー・元場で区別する。
- 二層平行板で界面法線D連続性、Phi/E/D、領域エネルギー、電極電荷、容量を解析照合する。
- Phi=A x²とPhi=A y²の製造解で、凹形、符号付きrho、非0外向きDnを独立検証する。
- 全境界0電位・一様電荷の矩形Poisson問題を分離変数のFourier級数で照合する。級数の有限打切りとFEM細分誤差を分け、Phi/E/D/エネルギー/表面電荷を個別検査する。
- 平行移動/回転、電位定数シフト、電位/電荷反転、epsilon倍率を確認する。固定電位で容量/エネルギーは幾何尺度に不変、固定rhoでPhi∝s²・E∝s・エネルギー∝s⁴を検査する。
- 標準回帰と旧周波数/RFを保つ。曲線/穴、純Neumann/gauge、浮遊電極、非線形、保存/CLI/GUIは別工程。

解析式は検証専用。境界は有限領域の宣言で、開放境界の厳密解としない。
新規依存・外部資料・旧版実行なし。S01と全計画は未完。

正式な矩形細分基準はP1の32/64/128、P2の16/32/64。最細Phi/E/D/U/元場電荷の相対誤差上限はP1 [5e-4, 1.5e-2, 1.5e-2, 5e-4, 1.8e-2]、P2 [1e-5, 5e-4, 5e-4, 5e-6, 2e-3]で、各量の単調改善も要求する。独立4×4三角形求積で場誤差を評価する。初回Fourier 512/1024項のE/D差が1e-7を超えたため、2048/4096項へ増やした。打切り差上限1e-7とFEM許容差は不変。標本打切り差は厳密誤差上界ではない。
