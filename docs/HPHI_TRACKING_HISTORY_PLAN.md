# Hφ追跡の所有履歴

同領域追跡の保存とGUIに続く限定課題。[実装記録](HPHI_TRACKING_HISTORY.md)の範囲で限定受入。
各段階の保存場とID集合が連続する履歴を所有保存し、追加・再生・worker・GUIへ接続する。

先行する不変量は、隣接する段階の「現在」と次の「前」が同じ保存スペクトルであること。
同じ周波数でも、規格化や係数の異なる場を同じ履歴へつなげない。
前段で失った個別IDは周波数分裂だけで復元できず、次段にもID集合の完全分割を渡す必要がある。

受入条件：

- strictな段階数/上限要求と完全な追跡ジョブ列を受け取り、全段階を元FEM・E/H対応から再生する。前段currentと次段previousのnative5ファイル、帯域数、個別IDまたはID集合を照合する。
- 各Projectを保持する。表示単位だけの違いは保存場の連続性を変えない。再計算した別の保存スペクトルを周波数一致だけで接続しない。
- PASSの多次元群はID集合のまま継続できる。最終UNVERIFIEDは証拠として保持し、その後への延長を拒否する。段階上限でも停止する。
- 新しい保存先へ全祖先を所有コピーして延長し、元履歴を変更しない。元パス移動後も全再生でき、再hashしたID/祖先/kind改変・リンク・途中の入力変化を拒否する。
- CLI実行/追加/再生、実worker/取消/再起動、GUIの段階・ID集合・停止理由表示、各段階の追跡結果と元場取込を接続する。
- 軸あり/なし・穴・縮退/順位逆転の正逆チェーン、規格化違い/ID飛躍/未検証後の拒否、所有Project/native不変と標準/旧f/RFを検証する。

履歴は離散的な保存場とID集合の連鎖で、標本間の連続した物理変形や連続問題の誤差上界を証明しない。
新しい外部資料・依存・旧版参照なし。形状写像は別工程。
