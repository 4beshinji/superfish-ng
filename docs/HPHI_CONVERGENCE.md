# 明示したHφメッシュ列の細分差診断

[計画](HPHI_CONVERGENCE_PLAN.md)のAPI・専用保存・CLI工程。固定候補617sourceを主ツリーへ統合し、以下の範囲で限定受入。

`HphiConvergence(projects, ...)` は3水準以上の完全定義のHphiProjectを受け取る。
閉同軸・正半径の明示断面・軸接続の直線PEC穴付き断面が対象。全水準で宣言外周/全穴の区間順序、
P1/P2と積分の次数、計算するモード数、全3Dエネルギー、導電率、加速区間・beta・位相原点を固定する。
各水準は三角形数が増え、最大要素辺長が減る必要がある。同じmeshを繰り返した要求は拒否する。
独立に作った明示メッシュの列を扱い、入れ子空間やRitzの単調性は仮定しない。自動細分・形状生成はこの版に含めない。

`mode_ranks` は1始まりの周波数順位で、永続的なモードIDではない。
各隣接水準を全E/Hの体積内積で比較し、同順位の内積が行/列の他候補より一意に大きいことを両場で要求する。
上下の周波数間隔と、その近傍の細分による移動も確認する。上端guardが未計算、近接/縮退、順位入替、
EとHで必要な係数符号が異なる場合はUNVERIFIED。縮退を個別IDとして確定しない。
近傍間隔には、宣言した最小間隔と近傍周波数移動の2倍のうち大きい値を要求する。有限列の分離診断であり、連続問題のスペクトル分離証明ではない。

位相合わせに使う係数の符号を、E/Hと複素Vaccへ共通に適用する。
E/Hの差は共通領域上の元要素で直接積分し、近いGram行列の差引きでは求めない。測度は2πr dr dz、分母は細かい水準の場のL2ノルム。
積分次数の追加比較はL2相対差で1e-10以内を要求する。元の場/規格化・SI・phasorは変更しない。

最後の2組についてf・E・H、各RF量、全PEC線分の壁損失、宣言済み複素Vaccと両R/Qを個別に判定する。
スカラー/複素数の相対差は `abs(a-b)/max(abs(a),abs(b))`、両方ゼロならゼロ。
軸はゼロ面積/ゼロ損失を保ち、加速経路が未宣言なら加速量を判定へ追加しない。
各差が要求したしきい値以内で、最後の差bが一つ前の差aに対して `b <= a + max(1e-12, a*1e-8)` を満たす必要がある。
この判定規則を用い、前後の差・各しきい値・減少判定を結果に残す。RF合計の改善で個別の壁線分の増加を隠さない。

既定しきい値はf=1e-4、E/H L2=.01、各RF/壁線分/複素Vacc=.005、最小周波数間隔=.001、最小内積=.9、他候補との差=.1。
未知キー・boolの順位/予算・非有限値・不一致Caseや改変係数、予算超過を拒否する。

    python -m superfish_ng execute-hphi-convergence request.json --out NEW_DIRECTORY
    python -m superfish_ng replay-hphi-convergence NEW_DIRECTORY

全水準のProjectと元nativeを所有保存し、最後に完了manifestを公開する。既存出力は上書きしない。
再生では各水準の最小正スペクトル・元係数/RFと診断の全計算をやり直す。結果を改変してhashを作り直しても、その判定は受け入れない。
未完やリンクした水準、要求・実装の実行中変更を拒否する。worker・GUIは[後続工程](HPHI_CONVERGENCE_WORKSPACE_PLAN.md)。

PASSは最後の3水準の差が条件を満たしたことを示す。連続問題の誤差上界、一般の精度、表面ピーク証明、永続IDの意味は持たない。

## 検証

5unitは24.543秒、独立24系列/72実FEM・全native再生/4CLIは202.061秒でPASS。
0/1/2穴・軸あり/なし・P1/P2・二尺度を確認し、粗さ未達、guard不足、厳しいしきい値、符号反転を含めた。
尺度による診断値の最大差は3.120e-13。独立の同一入力を使う実行/再生4CLIは15.609秒、結果全文書が一致した。
この「検証PASS」は、すべてのメッシュ列の診断がPASSという意味ではない。穴付きの粗い例はUNVERIFIEDを保持する。

長い円筒の初回n=2/4/8では、外壁の一線分の差が1.262e-6から3.031e-6へ増えた。
全系列がPASSになるという検証器の予想が誤っており、製品は仕様どおりUNVERIFIEDを返した。初回出力を保持する。
しきい値を変えず、n=4/8/16のTEM/軸TM010・二尺度の4系列/12FEMを別に計算すると、348.806秒で全診断がPASS。
独立解析のf/E/H/全壁/複素Vacc/両R/Qの誤差減少と固定ゲートを確認し、直接L2差も独立の物理多項式再構成へ照合した。

正確にTM011/TM020が縮退する合成円筒3FEMは15.584秒で確認した。
最終周波数の解析誤差は2.735e-7/3.370e-7だが、両順位の個別対応はUNVERIFIEDを保つ。
小さい周波数誤差から個別モードの同一性を宣言しない。
