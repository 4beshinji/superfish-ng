# 二次境界を固定した内部メッシュの自動再生成

2026-09-14 JST、N04残件4の初期メッシュ生成。
元Projectの内部節点・三角形・要素番号を使わず、境界から内部を作り直す。
生成結果は既存の [置換計画版1](CURVED_PROJECT_REMESH.md) で、
[Study版4](CURVED_REMESH_STUDY.md) の区間計画へそのまま渡せる。
元の二次境界を保持する再生成であり、境界分割を変更する一般の幾何再近似とは区別する。

## 生成条件

[携帯可能な設定例](../examples/curved_remesh_generation/settings.json) と
[元Project](../examples/curved_project_remesh/source-project.json) は合成した二つの半楕円で、測定構造ではない。
APIは `curved_remesh_generation.generate_curved_remesh_plan(project, settings)`。
直接native曲線P2・未組立/未反射・閉PEC/軸・m=0 TMを受理する。

| 必須項目 | 意味 |
|---|---|
| `schema_version` | 整数1 |
| `max_chord_edge_m` | 初期の弦三角形の全辺長上限 [m] |
| `max_chord_triangle_area_m2` | 初期の弦三角形の面積上限 [m²] |
| `minimum_corner_angle_deg` | 新しいnative二次メッシュの全細分段階の角度下限。0より大きく60未満 |
| `max_triangles` | 再生成した初期メッシュと新履歴の各段階の要素数上限。元Caseの上限以下 |
| `max_rounds` | 内部挿入/細分の反復予算。正整数 |
| `curved_refinement_levels` または `curved_refinement_steps` | 新しい履歴を片方だけ明示。履歴なしはlevels=0 |

長さ/面積/角度は有限数で、boolや非数値・無限大を拒否する。
未知キー、欠落、重複JSONキー、両方の履歴、古い接続に拘束されたpatternも拒否する。
元Caseの辺長・境界/角の局所サイズ条件を併用し、弦三角形の角度下限は元Caseと生成指定の厳しい方を使う。
面積上限は弦三角形への指定であり、曲線要素の実面積・物理誤差上界ではない。

細分履歴の番号は**生成後の各段階**に対する番号。
新marked選択は元形状上で固定し、生成した計画へsplit_patternも保存する。
元marked番号を暗黙に流用しない。番号を選ぶ前にlevels=0の計画を生成して確認できる。
生成条件は準備の入力で、携帯用の計画は生成済みの全配列と新履歴を含む。
Studyの保存再生は生成済みメッシュを再構築し、生成器の再実行を要求しない。

## 方法と拒否条件

検査済み元メッシュから境界の一周とタグだけを取り出し、原点/向きを正規化する。
元の内部座標と接続は破棄して、既存のear clippingで境界多角形を三角形へ分ける。
長い内部辺を適合分割し、面積超過要素へ重心を挿入する。
既存の角度改善flipと内部平滑化を使い、大きさ・角度を測り直す。
境界節点/辺/タグの移動・追加・削除は行わない。

生成段階では正の弦三角形、被覆、辺長・面積・角度を検査する。
新履歴には元Caseより厳しい生成予算を適用し、大きい旧メッシュからの粗化も許す。
最後に既存の置換APIで元の全二次境界との一致、正Jacobian・全辺・各履歴段階の角度を検査する。
成功した完全な計画だけを返し、品質未達の最終反復を結果として保存しない。
この有界の生成手法に、任意形状での終了や指定角度の実現可能性の定理は付与しない。

固定境界を持つため、全てのサイズ・角度の組合せが実現可能とは限らない。
例えば長さLの境界辺を底辺とし、両底角がα以上の三角形は、
高さが `L / (cot β + cot γ) >= L tan α / 2` なので、面積に
`A >= L² tan α / 4` という必要条件がある。
境界辺25 mm・下限10度では面積は少なくとも2.7551e-5 m²必要で、
2.5e-5 m²の面積上限とは両立しない。
辺長自体の矛盾は事前に拒否し、残るサイズ/品質未達は予算内に解消できなければ拒否する。
面積の必要条件だけを十分条件として扱わない。

より細かい境界が必要なら元Projectの境界近似を明示して作り直す。
これは別の二次幾何であり、同一領域の置換とは扱わない。
また、2倍の相似検証では生成の長さ/面積指定を2/4倍にするだけでなく、
元Caseが保持する長さ上限も2倍にした入力を使う。

## CLIとGUI

```sh
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m superfish_ng generate-curved-remesh-plan \
  examples/curved_project_remesh/source-project.json \
  --settings examples/curved_remesh_generation/settings.json \
  --out out/new-generated-remesh-plan.json

OPENBLAS_NUM_THREADS=1 .venv/bin/python -m superfish_ng remesh-curved-project \
  examples/curved_project_remesh/source-project.json \
  --plan out/new-generated-remesh-plan.json --out out/new-generated-project.json
```

CLIは全検査後に排他的保存し、元入力・既存出力を上書きしない。
GUIは「曲線形状と初期メッシュの掃引」の区間欄で、
「元の二次境界を保って内部メッシュを自動生成」を開く。
SIの生成条件と切替値を指定して生成すると、その値以降に使う完全計画を区間定義へ入れる。
元Projectを変更しない。生成条件の重複キーや実行中の入力変更を拒否し、既存の計画を保つ。
元Caseの境界分割と整合しない既定値は自動的に緩和しない。
生成後の保存/実FEM/比較/逐次・適応要求は既存Studyの経路を使う。
