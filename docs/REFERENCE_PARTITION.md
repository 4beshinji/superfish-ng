2026-09-15 JST、開始HEAD `95da156`。D01一般比較写像の残件のうち、
異なる三角形接続を共通参照座標で交差分割する計算基盤を追加した。
**曲線追跡の入力版や製品操作へは未接続であり、D01全体の受入ではない。**

`reference_partition.intersect_reference_triangulations` は旧・新それぞれの
正向き参照三角形の座標列と、`max_pair_tests` / `max_triangles` を受け取る。
参照座標は無次元の明示入力で、物理対応や近傍点を推定しない。
整数・有限float・Fractionを扱い、floatはその二進値を厳密な有理数へ変換する。
boolean・非有限数・文字列・空分割・退化・負向きの三角形は拒否する。

既存 `planar_tracking_overlap` の有理数クリッピングを再利用する。
自己重複を検査した後、旧・新の全組の正面積交差を三角形化し、各側の
**全親要素**が面積で厳密に覆われることを要求する。欠落領域は拒否する。
辺・点だけの接触は積分要素を生成しない。組数予算は自己重複検査も含む。
交差多角形の共線点を除き、辞書順最小頂点から分割して結果を座標順に並べる。

結果は全交差三角形の有理数座標・行列式・旧新それぞれの親番号と
親内重心座標を保存する。親ごとの面積と被覆面積、総面積も保存する。
親番号の一致や同じ初期接続は要求しない。旧新交換・要素番号変更・
正向きを保つ局所頂点巡回でも、共通積分分割の座標が変わらない。

受入した基盤検査は `test_reference_partition` の5件。

入力不変、旧新交換、重複/欠落/反転/不正数/予算拒否を確認した。

体積Jacobianを評価し、固定細分履歴・元の全二次境界・可逆性を保持する。
