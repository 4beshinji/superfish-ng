# 曲線要素の加算順序を保持する組立

2026-09-09、直前基準465e09f。N04非球形対照の高次積分検査を実行する費用を削減する。
曲線P2の基底評価と要素行列の積分点ごとの演算を配列化した。
同じP2写像・Gauss点・TM弱形式を使用し、固有値解法・停止条件・許容誤差は変更しない。

基底は頂点3個・辺中点3個の順序と、従来のスカラー演算順序を保持する。
行列は各積分点の6×6寄与を作り、先頭ゼロを含む順序付き加算で縮約する。
行列積や総和への置換で加算を再結合すると、微小な積分差・追跡スコアの
保存文書完全照合を変え得るため、np.add.accumulate を用いる。
半径の三乗も従来のNumPyスカラー演算を保つ。
戻り値をコピーして、全積分点の累積配列を大域組立中に保持しない。
一時記憶は一要素の積分点数に比例し、戻り値は各6×6行列だけである。

受入条件は、曲線写像・要素行列の旧演算とのバイト一致、独立解析積分、
Maxwell行列相似則、従来の入力拒否、旧版1〜4の保存文書再検証、
球形の解析五量・停止系列と標準数値回帰の維持。
本実装自身の変更前スカラー演算をテストの比較器として残す。
一致は検証環境・対象入力での観測であり、異なるNumPy/BLAS/CPU間の
保存文書のビット互換を新たに保証するものではない。

独立解析検査は単位三角形の r=x, z=y(1+a*x) を使う。
定数場で 1ᵀK1=4(1/6+a/12)、1ᵀM1=1/20+a/30、
u=r で rᵀKr=9(1/20+a/30)。長さ2倍でKは8倍、Mは32倍になる。
従来の曲線FEM物理検査も全体回帰で実行する。

試作では合成回転楕円体の初期80要素、積分次数2/3/4/5/8/12/24/32で
全行列がバイト一致した。次数24の要素組立は約0.996秒から0.134秒だった。
これは単発の局所観測で、全体計算や一般形状の加速率ではない。
追加unittest 3件は0.332秒で合格。標準全体回帰も完了した。

新規外部資料・依存・legacy参照はない。計画N04の一般精度・効率は未受入のまま。
