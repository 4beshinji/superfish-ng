# 一般多角形の平面RF接続計画

基準は矩形製品7bac43aと、[明示xyメッシュ基盤](PLANAR_POLYGON_MESH.md)。以下は隔離試作と受入条件で、主ツリーの製品対応を宣言するものではない。

## 入力・保存・操作

専用 `PlanarPolygonCase` を用意する。Cartesian平面Caseの版2に、単一PEC多角形の全角点と明示xy節点・三角形・P1/P2を保存する。モデルは真空、遮断、TE/TMのみ。矩形Case版1のパーサーを緩めず、版ごとにstrictに振り分ける。材料・曲線・穴・TEM・伝搬を黙って受け入れない。

nativeの五ファイル構成を維持し、manifest/result版2とCase版2の一致を要求する。Caseに元の宣言形状と三角形を保持し、mesh.npzの全配列を再組立して一致させる。保存係数の正スペクトル、境界条件、規格化、場/RFを再検証する。矩形版1の配列・文書・再生は保持する。CLIのsolve/replay/probeは明示した版を扱い、probe出力はnative外の新規ファイルに限る。

## 点検索と場

最初の一般点検索は三角形AABBで候補を絞り、入力binary64座標の厳密な方向判定で内外を決める。細長い三角形でも固定のbarycentric許容差で外点を入れない。共有辺・頂点は最小の元要素番号を選ぶ片側評価とする。barycentric計算は拡張精度を使い、未解像なら拒否する。有限xy入力を要求し、実際のメッシュ外は拒否する。宣言した直線上のつもりで丸めた点が、実際のbinary64メッシュでは外側になる場合があることを説明する。現試作の候補探索は一標本当たり全要素に比例し、大規模な描画/probeの性能受入とはしない。

## 独立物理受入

矩形の回転・平行移動・二尺度についてP1/P2、TE/TM、非縮退4モードのf、U′、G、E/Hベクトルの変換則と保存/CLIを確認する。位相は同一のスカラー係数の符号を全派生成分へ適用する。幾何の変換則だけで一般断面の精度を受け入れない。

第二の解析対象は合成の直角二等辺三角形 `0 <= y <= x <= a`。TMのEzは `sin(mπx/a) sin(nπy/a) - sin(nπx/a) sin(mπy/a)`（m>n>0）、TEのHzはcos積の和（m>=n>=0、00を除く）。三つの壁に対するDirichlet/Neumann条件を直接代入で確認できる。周波数は `c sqrt(m²+n²)/(2a)`。矩形の分離解から対称/反対称の実関数を構成する独立解析であり、FEMの置換や補正には使わない。

解析の面積規格化、同じ位相のスカラー/派生電磁場、三辺の解析接線磁場積分によるGを別々に比較する。P1/P2の実細分でf相対1e-4、場L2 1%、G相対0.5%の既存平面ゲートを維持する。高次モードの粗分割失敗は保持して細分する。代数残差を離散化精度とはしない。凹多角形の幾何・線形パッチは別基盤で確認し、角特異性を持つ固有場の絶対誤差を少数の細分差だけから保証しない。

## 現在の隔離試作

`/tmp/planar-polygon-candidate-20260909` に主ツリーと分離した候補がある。`out/planar-polygon-product-candidate-20260909` は変換16FEM＋矩形参照4FEM、全16保存再読込と4CLI計算がPASS。`out/planar-polygon-candidate-rejections-20260909` は未対応入力、v1/v2誤読、再hashしたgeometry/modes/manifest版変更、細長い三角形の内外・共有辺選択を確認した。候補の採用は三角形解析・strict回帰・旧矩形nativeの再検証・標準回帰後に判断する。

新規外部資料・依存・legacy実行はない。Project/Job/GUI、曲線、多重連結、材料、伝搬、一般モード追跡は後続工程として残る。


三角形の解析壁積分 `∮H_t² ds` はU′=1 J/mに規格化すると、TMでは `8(1+1/√2)/(a μ0)`。TEではn=0で `4(3+2√2)/(a μ0)`、m=n>0で `4(4+3√2/2)/(a μ0)`、m>n>0で `8(2+√2)/(a μ0)`。各辺のsin/cos直交性と対角辺のds=√2 dxから導く。`out/planar-triangle-wall-identity-20260909` の両尺度・60モード条件・40/80/160点独立積分で閉形式を確認した。これらは検証専用で、製品の壁積分を置き換えない。

初回三角形候補 `out/planar-triangle-physics-candidate-20260909` は12FEM、112.543秒で終了1。P2 n64は三ゲートに合格、P1 n192は最大f2.081e-4・場勾配2.041%で未達。P1 n448へ追加細分し、派生場は解析/数値の角周波数比を含む実E/Hとして比較する（元driverの勾配比較も履歴として保持）。追加実行はout/planar-triangle-fine-candidate-20260909、ハンドル59036。これが合格しても製品主ツリーの受入ではない。

大きな明示メッシュでの候補探索費用も隔離評価した。`out/planar-edge-candidates-20260909` のBVH候補は、24種のランダム/細長い/同一AABB集合について総当たりと候補集合が完全一致し、共有端点・幅0のAABBも確認。元の厳密線分述語へ接続した11unitと、3規模の全PlanarMesh配列/面積一致がPASS。小規模では遅くなるため、測定から万能な高速化とはしない。主ツリーと実行中の三角形候補には未適用。
