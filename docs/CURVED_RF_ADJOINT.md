# 曲線RFの固定周波数・制約付き随伴

2026-09-09。N04のRFを意識した細分選択に向けて、
`curved_rf_adjoint.r_over_q_adjoint(solution, mode=0)`を追加した。
[係数感度](CURVED_RF_SENSITIVITY.md)の加速器規約勾配gについて、
同次拘束自由度を除き、次の疎な拡大連立方程式を解く。

```
(K - λ M) z + M u η = g
u.T M z = 0
```

λは元のFEM固有値、uは元のSI・ピークphasor・エネルギー正規化を保持する。
第二式が振幅方向の不定性を除く。回路規約の随伴は加速器規約の1/2。
`accelerator_lagrange_multiplier`は加速器規約のη。
質量対角の逆平方根で合同変換し、第一式をλで割り、拘束列を規格化して疎LUで解く。
密な全固有モード展開は検査専用で、実装では固有値を再計算しない。
返す随伴配列は元の全自由度順・拘束成分0・読み取り専用。

元固有対の残差、固有値と周波数の整合、同次拘束を確認し、
供給済みの他固有値との相対距離が1e-7未満なら拒否する。
未計算の固有値との分離を証明するAPIではなく、重複固有空間の目的関数は未対応。
特異な拡大系、随伴残差1e-8超、規格化質量直交誤差1e-10超も拒否する。
小さい代数残差を物理的な離散化誤差の証明として使わない。

## 感度の範囲

周波数・RF積分規約・幾何・電磁エネルギー行列を固定した目的関数の場方向感度を扱う。
許容される変化duが `u.T M du = 0` を満たすとき、
`z.T (K - λ M) du = g.T du` という相反関係を持つ。
固有値問題のKに摂動Bを与えた場の一次変化については、
周波数を固定して評価するRF関数の変化は `-z.T B u` となる。
後者でもRF関数のエネルギー行列そのものは元のまま評価する。

周波数変化による位相・電場係数・RF分母の寄与、形状/行列のRF関数への直接寄与は含まない。
形状最適化の全微分、細分誤差上界、RF向け細分選択器を実装したとはしない。
既存のFEM/RF出力・選択・停止条件は変更していない。
次は周波数方向の目的関数微分と、親子空間での随伴重み付き残差・選択の検証が必要。
