# S05: B-H・反跳材料解からの平面Maxwell応力

2026-09-13 JST。後続限定課題。[実装記録](PLANAR_MAGNETIC_FORCE_MATERIALS.md)の専用API範囲で限定受入。

受入済みの線形スカラー力APIを、実際のPlanarBHSolution（P1）とPlanarRecoilSolution（P1/P2）へ拡張する。元Caseを実FEM再求解し、絶対/相対Azと基準値の一致を確認する。対象内部には単調非線形B-H、異方性と残留磁化を許すが、重みが変化する全セルは宣言された真空・Jz=0に限る。B-H真空は入力floatの有理数比で全表点が厳密H=B/MU0、反跳真空は宣言主値(1,1)かつ残留B=(0,0)である。局所接線や近似的な材料一致では代用しない。対象以外の非真空材料/電流は重み0に限る。

元の平面力APIの真空Maxwellテンソル、重み付きトルクと節点回転応力トルクを同じ積分経路で評価する。材料内部の重み一定を確認し、そこから非真空の応力公式を推測しない。拡張結果はschema_version=2と元physics/材料判定を保持し、既存の線形結果version 1と保存報告を完全に維持する。今回の仮想仕事/保存CLIは線形スカラー限定を明示して維持する。

独立解析対照は、線形極限B-H/反跳の有限電流のLorentz力と偶力、および真空透磁率・一様残留磁化の中心正方形永久磁石と外部一様場。後者の自己力/自己トルクは対称性で0、外部トルクは磁気モーメントm/L=面積*Brem/MU0に対する(m×B)z/Lである。合成構造と明示し、実FEMを解析係数で置き換えない。厳密に表現できる線形極限は1e-9、非厳密の永久磁石応力はP1/P2の8/16/32細分ごとに改善・最細0.02を実装前の条件とする。トルク二定義、原点移動則1e-9、回転/磁化反転/尺度、複数重み、求積比較1e-12を別々に記録する。異方性/非線形内部については対称性の零力を独立不変量とし、非零トルクの精度を偽って解析受入しない。

全表では非線形な空気、ほぼ真空・残留磁化つき空気、電流つき遷移セル、不正重み、改変した元係数を拒否する。旧線形56例/仮想仕事40例と旧native24報告の再現・ファイル不変、標準検証、周波数とRFの回帰を確認後、応力APIのみ限定受入する。

材料の仮想仕事は次の限定課題。B-Hでは真の積分エネルギー、反跳では残留磁化項を含む構成ポテンシャルを使い、対象回転とともに材料主軸/残留Bを回す。非線形の変位先失敗を保存し、失敗側から差分値を作らないことを別に設計・検証する。GUI、軸対称、S05全体と全計画は未完。

数学の出典は[既存の平面力計画](PLANAR_MAGNETIC_FORCE_PLAN.md)と[PHYSICS.md](PHYSICS.md)の公開Maxwell応力・構成則を継承する。新規外部資料・旧版コード/データ・依存を導入しない。

最初の細分試験でP2永久磁石トルクの誤差2.1761e-14→3.3099e-14が厳密減少条件に失敗した。この対称mu_rec=1例ではP2重み付きトルクも磁気モーメント値と丸め精度で一致する。P2は全メッシュを既定の厳密対照1e-9で判定し、P1は減少と最細0.02を維持する。元場や積分コードは変更しない。最初のログ/試験と判断は開発証拠へ保存する。
