# N04: 大規模曲線メッシュの図上選択

2026-09-14 JST、開始HEAD `b6d624c`。
[N04の残件4](N04_ACCEPTANCE.md)と[従来の図上選択](GUI_CURVED_MESH_SELECTION.md)にある
5,000要素を超える表示・選択を実装した。初期形状・順序付き細分履歴を適用した
実計算用の二次曲線節点と0始まりの要素番号を、そのまま使用する。

受入条件は、大規模でも元の二次境界・番号を保つこと、拡大/移動/クリック/キーボード操作、
履歴末尾への正しい番号の追加、入力変更中/後の古い番号の拒否、費用の実測、
従来の小規模選択と保存Caseへの受渡しの維持である。
N04全体の一般的な適応効率や物理精度を、この表示機能で受入済みにしない。

## 表示と操作

`curved_mesh_document`の既定表示上限は250,000要素。
Case自身の生成/細分上限が小さければそちらを守り、超過時は従来どおり拒否する。
表示のための再番号付け・粗視化・曲線への点の置き直し・固有値計算は行わない。
明示元メッシュがある場合も同じ履歴を使う。

5,000要素以下は従来のSVGを保持する。それを超える場合はCanvasへ二次Bezier辺を描く。
端点p0/p1と中点pmから制御点`2pm−(p0+p1)/2`を復元する。
選択判定もこの二次曲線の閉領域を使い、直線三角形で代用しない。
ブラウザーの有限精度による描画・判定であり、幾何学的な厳密演算を提供するものではない。

制御点の凸包を含む矩形から空間索引を作り、クリック位置の候補だけを調べる。
共有辺で複数要素に一致する場合は、後に描く大きい番号を優先する。
拡大時は画面と重なる索引の要素を描き、選択表示だけの更新には既存の背景画像を使う。
各要素のDOMやイベントハンドラーは作らない。準備は2,000要素ごとに画面処理へ制御を返す。

大規模表示では、クリックで選択/解除、ドラッグと矢印キーで移動、ホイール・ボタン・＋/−で
拡大縮小、0キー・全体表示ボタンで初期表示へ戻る。
要素番号へ移動してEnter/Spaceで選択する操作もあり、現在の要素と選択状態を読み上げラベルへ反映する。
描画領域は配布CSSで指定し、既存のContent-Security-Policyを保持する。

入力全体の署名はメッシュ要求前・応答後・描画準備後・履歴追加時に確認する。
準備中の番号移動/拡大/追加を無効にし、入力変更なら選択を破棄する。
別Project読込・履歴追加・再表示時は古い描画、索引、イベント、ResizeObserverを破棄する。
新しい細分が実行予算や要素品質を満たすかは、元の細分/計算経路で検査する。

## 再現と検証

変更前、合成楕円の一様5段を表示すると、第4段が`max_triangles=5000`で拒否された。
`out/large-curved-mesh-selection-20260914/baseline-red.json`に再現を保存した。

`test_gui_curved_mesh_selection`の4テストが10.725秒で合格。
6,656要素の全節点/接続と実計算空間の一致、元Case/上限の保持、明示メッシュの同一結果、
不正上限/非対応幾何の拒否、表示がsolveを呼ばないことを確認した。
数値ソルバーは変更していないため、変更範囲に応じてこのモジュールと直接のGUI経路を選んだ。

実Chromeは最終製品コードで、大規模の17チェック（上限描画測定を含む）と、
競合状態・ドラッグ/ホイールを追加した21チェック、小規模の一様履歴/局所履歴各6チェックが合格した。
大規模で検査した番号は0/1999/2000/13312/26623。クリック位置は6節点から別に評価した
P2重心を使い、全要素にDOMを作らず正しい番号が選択されることを確認した。
大きく膨らんだ合成二次辺では、直線三角形の外・二次領域の内の点が正しく選択され、外側の点は選択されない。

準備中の入力変更検査は、確認済みの同じnative応答を再利用し、描画準備を意図的に保留するUI検査。
新たなメッシュ生成やFEM実行として数えない。非同期構築中の破棄も確認した。
小規模2例は既存の検証器で実worker/FEMを実行し、選択した履歴が保存結果へ渡ることを確認した。
全4ブラウザー実行の製品308ファイルは不変で、外部HTTP要求は0。

取得/履歴再構築の費用は描画器より大きく、この変更で短縮したとは主張しない。

`validate_large_curved_mesh_selection.py`は、ブラウザーの全表示配列をnative空間と照合し、
保存された選択履歴を実計算と同じ経路で再構築する。26,624→26,676要素、5つの番号と元履歴が一致した。
独立な閉境界積分`A=1/2∮(r dz−z dr)`、`V=π∮r² dz`を二次辺上で5点Gauss積分した。
元26要素・表示空間・選択後空間の同じ二次領域について、面積/体積は相対1e−12以内で一致した。
符号は辺の向きを保持し、絶対値は約0.00628287543341 m²、0.00134031388798 m³。
解析楕円の真の面積/体積との一致を要求した検査ではない。
