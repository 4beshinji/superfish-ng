# S05: 平面磁場の多極係数と座標規約

2026-09-13 JST。後続限定課題。未実装・未受入。

最初の限定範囲は多極展開の数学的表現と座標変換。原点c=(cx,cy)[m]、局所軸の反時計回り角θ[rad]、基準半径R[m]、次数n=1..Nを明示する。局所z'=exp(-iθ)((x+iy)-(cx+icy))、F'=By'+iBx'=ΣCn(z'/R)^(n-1)、Cn=Bn+iAn[T]とする。Bnはnormal、Anはskew、n=1は双極、n=2は四極。この規約は[CERN LHC-M-ES-0001 rev3.0 (2001), §§2.1–2.4, 5.1–5.2](https://lhc-div-mms.web.cern.ch/tests/MAG/FiDeL/Documentation/lhc-m-es-0001-30-00.pdf)を参照する。LHC固有の半径や主成分・10^-4規格化を既定値として取り込まない。

SIの絶対係数を保持し、主成分ゼロでも有効な零場を表現する。主成分への相対規格化や磁石長方向積分は、この段階で暗黙に補わない。入力は有限実数のnormal/skew配列、全来歴、厳密な座標規約とし、bool/複素JSON/未定義場/不正次数を拒否する。最大32次の有限多項式を対象にする。

物理ベクトルの評価は局所多項式と軸回転から行う。原点/角/基準半径の変更は有限多項式の二項展開による係数変換を用い、未知の高次項や領域内の無源性を推測しない。新旧の複素表現を結ぶ式を独立に導出し、場を同じ物理座標で比較する。これは入力された有限展開の評価・変換であり、FEM求解や任意の場が調和的であることの証明ではない。

受入は単一normal/skewの1..8次と混合場、明示した手計算の原点移動、座標回転、基準半径変更、変換合成/逆変換、零場と厳密入力、非常に大きい/小さいSI値での有限演算拒否を含む。場と係数の独立多項式/Decimal照合の許容は1e-11、有限差分によるdiv B/curl Bは適切な場/長さ尺度で2e-6。演算が解像できない尺度は許容差を緩めず拒否する。
