# 曲線境界の座標別丸め余裕

開始HEAD `01c8e5d`、2026-09-15 JST。D02の実曲線・対称Study検証で見つかった拒否を扱う。
円柱部＋円弧端部をz_minで鏡映すると、半径が変わらないのにr方向の丸め余裕が増大し、
join tolerance 1e-14 mを越えて入力が拒否された。受入条件は座標の独立性、全曲線の包含、
実際の領域逸脱・交差の拒否保持、元入力での鏡映Studyと共通幾何の全体検証である。

旧`curve_bounds`は全座標の最大絶対値から両方向に同じ128εの余裕を設定した。
新方式は各座標の演算項から余裕を求める。線分では元の両端座標を用い、
狭いパラメータ区間で端点項が相殺しても計算規模を失わない。
円錐曲線では回転行列の各行に寄与する絶対値の和を用い、双曲線のcosh/sinh増大も含める。
両半軸の最大値を下限として保持する。
中心座標は曲線評価後に一度加算されるので、その丸めは最終結果を外側へ送る`nextafter`で扱う。
中心を128ε倍して曲線評価誤差へ加える方式を除き、無関係な並進に依存させない。
これは従来同様の工学的な浮動小数点評価であり、超越関数の形式的区間演算証明ではない。
128の係数、入力接合許容差、幾何逸脱の判定閾値は変更しない。

最初の座標別修正では半径方向の余裕は改善したが、軸方向の中心加算を同様に過大評価して拒否が残った。
項の評価と中心加算を分けた修正で、同じ入力が通ることを確認した。失敗ログは保持する。
新規3unitの旧実装は1 failure/1 error（0.009秒）、修正後0.130秒PASS。
線分・回転楕円・回転双曲線の座標別並進不変性、電気/磁気対称の円弧6形状、
Decimalによる線分相殺と双曲線包含を検査する。
別の80桁Decimal検証は、通常中心、1e16の並進、座標値がほぼ相殺する中心で390座標を照合しPASS。

既存の候補入力のjoin toleranceを保持したまま、鏡映指定のStudy 3形状を生成した。
円弧形状を固定して円柱長だけを変える独立体積増分πR²ΔLが、Green境界積分の増分と1e-14 m³以内で一致する。
二次近似した円弧端部の絶対体積が解析円弧と厳密一致するという主張ではない。
今回の証拠は`out/curve-coordinate-bounds-20260915/`、候補入力は前段の`out/te-symmetry-harmonic-20260915/`にある。

共通曲線の分離・隣接・領域判定に影響するため、`scripts/validate.py`をfullで一度実行した。結果は下記に記録する。
実曲線3点のTE鏡映Studyは3半領域固有値計算で完了し、実Eφ追跡と保存再生がPASS。
