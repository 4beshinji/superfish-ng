# 境界実長と角近傍の局所細分化 — 2026-09-06

P1-04の限定した改善として、境界辺の最大実長と角近傍の内部辺サイズを明示指定できるようにした。
受入条件は実長上限、形状・境界タグ・領域積分の保存、独立PEC条件による電場診断の改善、既存数値回帰の維持。
これは高次要素、電場復元変更、全形状のEpk精度保証を実装したものではない。

## 原因に対応した変更

従来のprofileメッシュは軸長で区間を分割するため、斜面の壁辺は軸刻みより長い。
既存のメッシュを生成後、指定上限を超える境界辺を中点で分割する。
角周囲の円盤に交わる内部辺にも別の上限を指定できる。共有辺には同一中点を使い、
分割対象を持つ三角形の最長辺も分割する閉包処理を行う。
一辺・二辺・三辺分割の接続を構成し、正Jacobian、境界被覆、連結性、面積を検査する。
新しい外部メッシュ依存はない。形状もFEM弱形式もP1電場復元も変えない。

独立した失敗の根拠は前回診断のPEC接線成分（厳密値ゼロ）と、従来メッシュの実長上限超過。
回帰テストは旧生成経路が実長上限を超えることも明示検査する。
段差と傾斜壁で `∫r³ dr dz = ∫R(z)^4 dz/4` の解析積分、閉じた領域、境界タグを検査する。
Pillboxの周波数・R/Q・Gは独立解析解でも検証する。

## 制約と次の判断

固定点の改善は確認できたが、角の近くはまだ1%未満の自己収束を満たさない。
既定のメッシュは変更せず、過去マイルストーンの再現設定を保つ。
今回の範囲ではWineは再実行していない。旧Wineのピークに合わせる調整は行わない。
円弧の形状誤差、局所分割後の鏡映対称性、高次要素・電場復元の改善は別の検証課題。
円弧の境界細分は元の直線近似を細分するだけなので、弦誤差の収束は別途必要。
