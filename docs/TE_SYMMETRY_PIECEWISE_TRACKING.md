# TE半領域の非アフィン曲線比較

2026-09-15 JST、開始HEAD `16a625c`。D02の非アフィン対称経路のうち、
直接計算した半領域のpiecewise_remesh比較版2/3/4/5を対象とする。
受入条件は同じ対称セクター、実Eφと変動する回転体積重み、保存再生・改変拒否、
独立積分とMaxwell尺度則、既存の閉PEC/直線比較の拒否条件保持である。

曲線比較用の元弦メッシュの構文検査に対称タグを許可する内部呼出しを追加した。
直線比較の既定検査は閉PEC/axisのまま。実場比較では既存のTE case検査と
同一端条件・高々一対称端の検査を行い、元セクター内の順位をメタデータに記録する。
TE/TM混在、異なるセクター、TM半領域、鏡映済み場は拒否する。
版5の参照境界にもTE対称タグを通し、タグ一致・全境界被覆・参照分割検査を維持する。
既存の閉PEC出力には対称メタデータを追加しない。

本工程は半領域の保存比較基盤である。鏡映の全領域写像、非アフィンProject変形、
tune/Studyの対称経路は引き続き未接続。GUI専用受入も今回実施していない。

## 独立検証

`test_te_symmetry_piecewise_tracking`の直線プリミティブで構成したnative P2ケースは、
壁の中間点だけ半径を8%増やす。両端の半径は固定するため、単一アフィン変換では表せない。
z_min/z_maxと電気/磁気対称の4組を実FEMで解き、各比較版で実EφのIDを確認する。
検査用の正則場v=1（Eφ=r）は固有モードとして扱わず、比較の重み検査にのみ用いる。
各三角形の独立な一次写像・解析行列式を使い、SciPy dblquadで相互/自己積分を評価する。
回転体積は三角形の線形半径積分から求め、製品の重なり/体積と照合する。

実際に曲率を持つ追加例は二つの楕円弧と磁気対称端で構成する。
弧の中心と軸長を左右で異なる割合に変え、全体を単一アフィン写像で表せない形状を作る。
原寸/倍寸の周波数、全係数、全要素重心Eφ/Hr/Hz、U/G/Q0/壁損失の尺度を別々に検査する。
両R/Qを加速量として解釈せずN/Aを維持する。各比較版の重なりと体積8倍も照合する。
これらの例は独自合成形状であり、実測空洞ではない。

## 診断と結果

記録は`out/te-symmetry-piecewise-20260915/`。
最初のテスト起動はNumPyスカラーが厳密な曲線数値型検査に拒否され、FEM前に失敗した。
Python floatへ変換後、旧メッシュタグ拒否で新3件が17 errors/1 failureとなることを再現した。
実装後の新3件は3.548秒PASS。直線既定拒否とTM半領域拒否を補強した該当1件も0.138秒PASS。

楕円弧の追加起動は、線分端点と弧端点の丸め差が隣接分離条件で拒否された。
線分の宣言端点を弧の評価端点と同じ数値にして接続を一致させ、追加1件8.242秒PASS。
製品の接続検査・物理許容差は変更していない。新4テストは分割証拠で成功した。

関連は次の30件49.780秒PASS。full/seed validatorやhosted CIの証拠ではない。

```sh
OPENBLAS_NUM_THREADS=1 PYTHONPATH=tests:src .venv/bin/python -m unittest \
 test_piecewise_remesh_tracking test_curved_piecewise_remesh_tracking \
 test_curved_reference_partition test_curved_comparison_overlay test_te_curved_tracking
```

専用nativeは楕円弧2形状の原寸/倍寸4実FEM。版2〜5の計8保存比較がPASSし、全再生が一致した。
重なりは約0.990196〜0.990197、各版の尺度不変性も確認した。
版ごとに比較参照分割・数値積分が異なるため、異なる版の値の完全一致は要求していない。
サンプル次数に対する収束や連続した物理枝、離散化誤差上界をこの結果から主張しない。
周波数/係数/RFの尺度差は最大3.331e-15、元48ファイルのhashを保持した。
新規外部資料・旧コード・旧バイナリは利用せず、既存の独立TE定式化と現代の数学ライブラリを使う。

CLIの`replay-mode-tracking comparison-1-5.json`もREPLAYED PASS、追加FEM0。
