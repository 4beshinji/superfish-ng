# 実装済み能力表の整合

2026-09-13 JST。C01/O02の運用修正。未受入。
`capabilities`に専用Hφの4形式がなく、平面追跡版7も一覧から欠落していた。
実装済み機能と未対応範囲を、既存入力を受理する入口と対応させる。

受入条件：

- 閉同軸円筒、正半径メッシュ、軸接続メッシュ、明示曲線Hφの専用case/native形式・版・未知数・零空間・軸加速量を区別して出す。
- 実装済みCLI、Project/worker/GUI、独立掃引、直線形状だけの比較/細分差診断/追跡/履歴を記述する。曲線の未対応比較は利用可能としない。
- 平面追跡版1〜7の入力と各写像を列挙し、版7の独立境界分割を旧版の制約と混同しない。
- CLIの能力表がPython APIと同じJSONになり、列挙したコマンドが実CLIで存在する。例題のstrict読込と小規模なFEM/native/Project往復で宣言を照合する。
- canonical Modelの受理範囲、旧入力/保存、数値計算を変更しない。材料・静的場・一般曲線追跡等を宣言だけで利用可能にしない。
- 影響する能力表・実装状況・来歴を更新し、標準テストと既存周波数/RFの回帰を確認する。

親33課題の完了数を能力表の補完だけで増やさない。外部仕様・新規依存・旧版ソース参照は追加しない。
