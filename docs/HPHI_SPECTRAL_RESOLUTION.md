# Hφの有限比較空間スペクトル診断

[計画](HPHI_SPECTRAL_RESOLUTION_PLAN.md)の固定候補626sourceを検証中。本体統合・受入は未完。
`hphi_spectral_resolution(solution, comparison_mesh, ...)` は、元の専用Hφ解を完全再検証し、
同じ真空領域の明示P1/P2空間で近傍固有値の数値区間を求める。
比較先は元より三角形数が多く、最大辺長が小さく、次数が低くない必要がある。入れ子関係は仮定しない。

元のqまたはuを[L2射影](HPHI_MASS_PROJECTION.md)し、比較空間のK/Mを組み立てる。
s=1/真空断面積、T=(K+sM)^(-1)M、元lambdaからmu=1/(lambda+s)を用いる。
M自己共役性により、厳密算術では `dist(mu,spectrum(T)) <= ||Tv-mu*v||_M/||v||_M`。
この残差deltaへ1e-10*muの丸め余裕を足し、lambdaの区間へ戻してHzで報告する。
mu-delta以下の分母が正と判断できなければ上端はnull。正半径の定数q零モードは比較演算子に保持する。

元の最低正スペクトル・係数・規格化を検証し、元周波数/RFを変更しない。
比較空間の固有値計算によって元解を置き換える処理はない。
シフト逆行列の線形相対残差は1e-10以内、射影損失の既定上限は.01（明示変更可能で0より大きく1未満）。
射影損失未達、有限上端が得られない列、正半径の静的零モードへ及ぶ区間はUNVERIFIEDとなる。
各列の理由、射影の全診断、シフト、M残差、線形残差、丸め余裕、区間を結果へ保存する。

PASSは比較空間の数値診断が指定条件を満たすことを表す。
区間が捉える固有値の順位や一意性、縮退の分離、連続問題の包含・物理誤差上界を示さない。
浮動小数点残差と明示した余裕を用いた診断であり、保証された区間演算の証明書ではない。

## 検証

追加3unitは0.716秒でPASS。区間内の比較固有値、元係数/周波数不変、射影未達と不正な比較/改変解の拒否を確認した。
独立24FEM/nativeと48比較空間の全一般化固有分解は31.978秒でPASS。
軸あり/なし・0/1/2穴・P1/P2・二尺度・2段階の独立比較メッシュを含む。

独立検証は比較K/Mの密な全固有分解を使い、各区間に少なくとも一つの固有値があることを数えた。
全固有基底への展開からM残差を別に計算し、製品の疎なシフト逆行列と照合した。
muで規格化した残差の最大差は5.020e-13、尺度変換の最大差5.351e-14。
正半径の定数循環と軸接続の正スペクトル、元120nativeファイル不変も確認した。
製品の判定は34比較がPASS、14比較がUNVERIFIEDであり、粗さを無視して全比較を合格へ変えていない。
