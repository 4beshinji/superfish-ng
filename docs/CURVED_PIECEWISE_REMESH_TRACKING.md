# D01: 曲線比較メッシュによる非線形対応

2026-09-14 JST、開始HEAD `a26f3cc`。
[BACKLOGのD01区分変形比較](BACKLOG.md)に残っていた曲線領域への拡張を実装した。
既存の`paired_mesh`は実FEMの接続が一致する場合を扱う。本機能は、明示した旧・新の
比較用二次曲線メッシュを使い、接続や要素数が異なる実FEM場を比較する。
受入条件は、各領域の被覆・正ヤコビアン・二次境界全体の照合、非アフィン変形の可変体積重み、
独立積分/物理尺度則、厳密入力、保存再検証・逆方向履歴・CLI/GUI接続である。この範囲を限定受入とする。

## 入力と対応の定義

`mapping="piecewise_remesh"` の `comparison_meshes` に二つの版2オブジェクトを渡す。
各オブジェクトの必須項目は整数`schema_version: 2`と`source_mesh`。
`source_mesh`は完全な[版1の元弦メッシュ](MESH_INPUT.md)で、SI・rz座標、0始まりの番号、
全三角形・境界・タグを明示する。旧・新で頂点数、向き付き接続、境界辺・タグを共有する。

細分指定は省略、一様の`curved_refinement_levels`、順序付きの`curved_refinement_steps`のいずれか。
省略は0段。両キーの併記、負/boolean段数、空steps、未知キー・版・曲線/直線の混在は拒否する。
stepsは通常Caseと同じ非空のuniform/marked履歴で、元番号を別の分割へ推測移送しない。
比較空間の構築後にも6節点全体の向き付き接続と3節点境界・タグの一致を要求する。
同じmarked指定でも形状変化により遷移分割が変われば拒否する。

各側の曲線定義は対応するnative Caseから使う。比較宣言によるCase/物理/曲線の上書きは認めない。
比較用の履歴は実FEM側の履歴とは独立である。実FEMを比較用メッシュで解き直したり、
比較メッシュへ係数を補間して新しい解を作ったりしない。
既存の版1の直線比較入力と外側の追跡request/result版1/2は保持する。

各比較空間は元メッシュの被覆/向き/連結/タグ、二次写像の正ヤコビアン、全曲線辺の交差と
共有中点・トポロジーを既存native経路で検査する。各実FEM境界とは、共通の曲線fraction区間に
制限したBernstein係数を照合する。頂点だけの一致では受理しない。
照合の許容幅は既存の幾何スケール付き丸め幅で、数学的な厳密同一判定や幾何誤差上界ではない。
曲線空間の共通境界検査を場係数から分離し、従来の同一曲線領域/アフィン比較も同じ処理を使う。

対象は直接構築した閉PEC・軸接続のnative曲線TM解二つ。対称半領域と反射構築、TEや混在は
この版では受理しない。比較点数は`比較要素数 × sample_order² ≤ 262144`、次数は2〜32。
元比較メッシュの段階で標本予算を超えれば早期拒否する。生成設定を持つCaseでは細分上限も
標本予算以下へ制限する。設定を省略した明示元メッシュではnativeの既定細分上限を維持し、
完成後・標本作成前に標本予算を再検査する。

## 場と体積の積分

対応する参照三角形の二次写像を `F₀(ξ), F₁(ξ)` とする。
物理点の対応は `F₁ ○ F₀⁻¹` であり、一般には物理座標に関する二次多項式ではない。
それぞれの点で元FEMの `Hφ` を評価する。半径 `rₛ(ξ)` と正の行列式 `dₛ(ξ)` から
`vₛ = rₛ dₛ` を求め、比較特徴を `Hφ(Fₛ(ξ)) √vₛ` とする。
実装の `√(r/max(r)) √(detJ/max(detJ))` は正の側別定数を除くだけで、可変体積を保持する。

一つのモード対の正規化内積は、共通参照領域上の
`∫ H₀(F₀) H₁(F₁) √(v₀v₁)` を
`√(∫ H₀(F₀)²v₀ ∫ H₁(F₁)²v₁)` で割ったもの。
軸対称の共通因子2πはここでは相殺し、診断の物理体積では2πを含める。
既存の部分空間・割当て処理へこの特徴と正の求積重みを渡す。
周波数順位を物理IDと見なす処理や、Maxwell解そのものの座標変換は追加しない。

比較メッシュとFEMメッシュの交差分割は構築しないため、次数を変えて対応を確認する。
正のヤコビアンや小さな代数残差、追跡PASSは、求積誤差上界・連続枝の同一性・場/RFの
離散化誤差を保証しない。RF量は各元native解から計算したまま保持する。

## 保存と操作

完全な比較宣言をcontrolsへ保存する。結果には比較幾何次数、比較/実FEM要素数、標本数、
物理体積、標本点での行列式範囲、全辺検査、両側の全境界照合、宣言SHA-256を含める。
行列式の標本最小値を全要素上の厳密下界とは表示しない。
元native保存ファイルと宣言の再検証は既存のsaved tracking/history経路を使う。

GUIの「比較用メッシュによる局所変形」へ版2の二要素配列を入力し、通常の比較・履歴開始・
継続・保存・再読込を行える。逆方向へ進むときは結果の向きと比較宣言の順序を両方交換する。
交換し忘れた比較や改変済みの文書は、検証済み履歴を置き換えずに拒否する。

宣言hashはキー順等を正規化したJSONを対象とし、数値的に等しい`0.0`と`0`でも異なり得る。
ブラウザーのJSON再出力を元ファイルの数値表記・hash保存とは呼ばない。
各保存文書は自分自身の完全な宣言に対して再検証する。
