# S02: 固定電流での外部境界距離とメッシュ細分の分離

2026-09-13 JST。専用磁静API/CLIに対する独立検証と実行例の限定課題。未実装・未受入。製品ソルバーは変更しない。

平面と軸接続の二つの源問題を用い、電流の物理的な範囲と密度を固定して境界だけを移動する。有限境界での解析解とのFEM差、境界位置による物理場の変化、定数ポテンシャルの扱いを分ける。

- 平面：幅w、0≤y≤aに一定Jz、a<y≤bにJz=0。下端/側面Ht=0、上端Az=0。H_x=−Jz min(y,a)、B_x=mu H_x。Azは源内でmu Jz(ab−a²/2−y²/2)、外でmu Jz a(b−y)。U'=mu Jz²w(a²b−2a³/3)/2[J/m]。境界を遠ざけても共通領域のB/Hは不変だが、Azの基準と全エネルギーは変わる。非零の無限スラブ電流に有限なゼロ遠方ポテンシャルを仮定しない。
- 軸接続：0≤r≤aに一定Jphi、a<r≤bにJphi=0、軸は正則、端面Ht=0、外周Aphi/r=0。外側からの一様H補正C=−Jphi a³/(3b²)、源内Hz=Jphi(a−r)+C、源外Hz=C。a=Aphi/rは源内mu[C/2+Jphi(a/2−r/3)]、源外mu[C/2+Jphi a³/(6r²)]。この定数aの差はBを変えるためgaugeとは扱わない。
- 軸接続のb→∞参照は、同じ有限長L・端面Ht=0のまま径方向だけを無限大にし、C=0とする。U∞=πmu Jphi²L a⁴/12[J]、Ub=U∞−πmu Jphi²L a⁶/(18b²)。有限外周の閉じた磁束による一様戻り磁場がb^-2で減ることを、FEM差と別に照合する。専用の一般開放境界ソルバーを実装したとは主張しない。
- b/a=2,4,8、mu倍率1/7、源の±、P1/P2の各3細分、二座標の計144例。源境界は全メッシュで一致させる。元ポテンシャル/B/H、エネルギー、元H積分を独立に測る。
- P1 n8/16/32、P2 n4/8/16を初期系列とする。最細の元ポテンシャル/B/H/エネルギー/元H境界積分の相対差上限はP1 [3e-3,3e-2,3e-2,3e-3,3e-2]、P2 [2e-5,1e-3,1e-3,2e-5,2e-3]。各有限bで誤差が減ることを要求する。平面P2の二次式は丸め誤差域で判定する。
- 共通源内点で、平面B/Hの不変、軸Hz差のC差への一致を検査する。軸の∞参照との差と有限b FEM差を別に保存する。最細P1の正規化された境界変化差は5e-3、P2は1e-4以内。許容差を緩めず必要な細分を追加する。
