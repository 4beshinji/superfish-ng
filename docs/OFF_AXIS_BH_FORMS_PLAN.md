# S04: 軸非接続P1の非線形B-H弱形式

2026-09-13 JST。後続限定課題。[実装記録](OFF_AXIS_BH_FORMS.md)の軸非接続P1弱形式API範囲で限定受入。

厳密にr>0の直線メッシュと単調等方H(B)表/来歴に、psi=r*Aphi[Wb]を接続する。B=(-psi_z/r,psi_r/r)、H=h(|B|)B/|B|、Bphi=Hphi=0を明示する。全DOFと定数psiの零B核を保持し、psiの定数変更でAphiにC/rが加わることを元場の変化と区別する。領域外の軸を貫く絶対磁束は補わない。

dV=2pi*r dr dzでg_i=∫B_i·H dV[A]、K_ij=∫B_iᵀ(dH/dB)B_j dV[1/H]、fJ_i=2pi∫Jphi Ni dr dz[A]を組み立てる。U/U*[J]、元B·H、相対psi·gとgの総和0を別に検査し、源電流はsum(fJ)/(2pi)=∫Jphi dr dz[A]で確認する。gaugeと軸接続aの一様軸場を取り違えない。

P1でもBは1/rで変化する。固定正値求積でU→g→Kを保持し、q/q+4のK/g/電流/U/U*差を別の診断にする。求積差や小さな代数残差を場の誤差上界と扱わない。元P1の勾配はセル一定なので、最小rの頂点で最大|B|を確認して表範囲を守る。

受入は一定psiの厳密零B/H/エネルギー、非零Aphi=C/r、元1/r場と独立Vandermonde/Decimal積分、U/g/K変分、旧線形軸非接続P1極限、穴/材料所有/厳密入力、基準変更・z移動・材料/幾何尺度・符号反転を含む。同じBなら幾何s倍でpsiはs²、Kは1/s、gはs、固定JphiのfJはs²、U/U*はs³となる。表折点での求積差は形式の一致から分離する。境界付き解/保存は後続工程。標準と旧周波数/RF差を確認して限定受入する。
