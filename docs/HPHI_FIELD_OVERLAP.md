# 元Hφ電場・磁場の体積内積

[計画](HPHI_FIELD_OVERLAP_PLAN.md)の物理積分工程。固定候補612sourceを主ツリーへ統合し、以下の範囲で限定受入。

`hphi_field_grams(previous, current)` は専用の閉同軸、正半径一般断面、軸接続Hφの解を受け取る。
各Case・元メッシュ・元空間・係数・最小正スペクトルを再構築検証し、同一真空領域の元要素で積分する。
同じ真空なら閉同軸Caseと正半径明示mesh Caseも比較できる。形状変更は扱わない。

電場はEr/Ez quadrature、磁場はHφ実部を使い、対象のm=0 Hφ物理で省略成分は恒等的にゼロ。
共通の物理(r,z)座標とpeak exp(+iωt)、real+i·quadratureを保持する。
電場と磁場それぞれに、前の自己内積・前後の交差内積・後の自己内積の3行列を返す。
全3Dの測度は2πr dr dzで、単位は電場V² m、磁場A² m。規格化と元係数の符号は保持する。
加速経路や壁導電率の同一性はこの体積場APIの判定対象ではない。比較要求の呼出し側で必要な条件を宣言する。

軸の正則uはDuffy-Gauss次数5/7、正半径qは両Caseの大きい積分次数+4/+8を使う。
自己ノルムで正規化した全Gram成分の二次数差は1e-10以内を要求する。
元FEMのK/Mが与える自己エネルギー内積との差も1e-8以内で検査し、合同Gram行列の半正定値性を確認する。
積分の安定性は連続問題の誤差上界ではない。元のCase/保存検証の閾値は変更していない。

元要素被覆は[共通幾何](MERIDIONAL_OVERLAP.md)の厳密検査を用いる。
候補比較・共通分割の上限に加え、各側のモード数を `max_gram_modes`（既定256）で制限する。
結果はread-only配列と診断情報。順位対応、永続ID、縮退部分空間、細分精度は返さない。

追加4unitは2.057秒でPASS。両次数のエネルギー/符号/規格化、混次数・独立mesh・交換時の転置、閉同軸/明示mesh、改変・領域不一致・予算拒否を確認した。
独立48FEM/native・48比較は13.826秒でPASS。検証器は物理座標で元係数の多項式を別途再構成/微分し、
別の矩形小区画・Gauss積分と照合した。製品の共通分割・重心座標・場評価は使わない。
最大参照差1.797e-14、二尺度の最大相似差2.407e-13。

合成円筒のTEMおよび軸TM010の8FEM・4細分比較は2.901秒でPASS。
解析磁場投影と隣接候補の差で対象を確認し、周波数・E・Hの誤差減少を個別に検査した。
最終水準ではP1のf<.02、E<.2、H<.02、P2のf<.0005、E<.015、H<.002という事前の固定ゲートを満たす。
製品の共通場差は、独立解析場からの両誤差が与える三角不等式の範囲内にある。
ここでの小規模な円筒検査から、一般形状の精度や追跡を受け入れない。
