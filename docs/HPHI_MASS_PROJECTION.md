# Hφの質量内積とL2射影

[計画](HPHI_MASS_PROJECTION_PLAN.md)の固定候補623sourceを主ツリーへ統合し、以下の範囲で限定受入。
同じ真空領域の独立P1/P2メッシュについて、元のスカラー未知関数を別の有限空間へ射影する。

`hphi_mass_coupling(previous_mesh, current_mesh, ...)` は二つの宣言メッシュを再検証し、
元要素の厳密な共通分割から交差質量行列Cを疎行列として作る。Cの行はprevious、列はcurrentの基底。
軸接続はu=Hφ/rとr³ dr dz、正半径はq=rHφとdr dz/rを用い、異なる未知関数を混ぜない。
スカラー内積の2π倍が全3D磁場内積となる。軸の自由度と定数qを両方とも元空間へ保持する。
一般メッシュ同士を比較し、入れ子関係や節点一致を仮定しない。

前後の次数は独立にP1/P2を指定する。既定の積分次数は12で、指定範囲は4〜32。
軸接続の共通積分は5/7、正半径は指定次数+4/+8を比較し、自己質量を元FEMの行列へ照合する。
対角質量で規格化した各行列成分の差は積分1e-10・元質量再現1e-8以内を要求する。
予算は候補探索2,000,000・共通三角形250,000・各空間の自由度250,000が既定。
全穴・外周の不一致、予算超過、boolや未対応次数は拒否する。幾何を移動・補完しない。

`project_hphi_coefficients(previous_mesh, current_mesh, coefficients, ...)` は完全な元係数行列を受け取り、
M_current x = C.T aを実際に解く。元係数を変更せず、読み取り専用の射影係数と列ごとの診断を返す。
係数は有限実数の二次元配列で、ゼロ列を許す。非零列の質量ノルムが有限正数として表せない場合は、係数の再尺度化を要求する。
元固有モードを解き直すAPIではなく、出力へ周波数・RF量・mode IDを付けない。

差のノルムは共通領域の元多項式から直接積分する。近いノルムの差引きは誤差値に使わない。
線形方程式の相対残差1e-10、追加積分の相対L2差1e-10、ノルム非増加とPythagoras関係1e-8を検査する。
元ノルム・射影ノルム・直接二乗誤差・相対誤差・直交性の残差を報告する。
この誤差は指定した二つの離散空間の射影で失った場であり、連続問題のFEM誤差ではない。

## 検証

追加4unitは3.561秒でPASS。定数/線形/二次関数、任意の元係数とゼロ列、元係数不変、
未包含P1空間で二次関数を失う例と細分による減少、領域/次数/予算/非有限値の拒否を確認した。
独立48比較/144係数列は10.228秒でPASS。軸あり/なし・0/1/2穴・P1/P2全組合せ・二尺度を含む。

独立検証は各元要素の物理座標Vandermonde再構成と、矩形画素を両対角線で割る別の積分を使う。
製品の共通要素・重心座標・差の評価コードを参照解には用いない。
定数・線形/二次関数の質量は、矩形から穴を引く多項式/対数の解析積分にも照合した。
元質量・直接誤差・直交性・解析質量の最大差は5.630e-14、相似差最大1.824e-12。
qの質量は尺度s、uの質量はs⁵、同じ参照関数の射影係数と相対損失は不変となることを確認した。
