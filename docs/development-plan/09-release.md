# 統合受入と配布

[全体索引と実行規則](README.md)に従う。本章のIDは親課題IDではなく、作業カードID。

各カードは原則1コミット。既存ファイルは調査・変更候補であり、全てを書き換える指示ではない。新設ファイルは本文で指定する。

## V01

### 統合受入の対象と必要証拠を固定する

- **親課題**：V02。**種別**：仕様。初期状態：未着手。
- **先行条件**：[B03](01-baseline.md#b03)
- **コミット件名案**：`docs: 統合受入の対象と必要証拠を固定する`
- **既存の入口・影響先**：`docs/TESTING.md`、`docs/IMPLEMENTATION_STATUS.md`、`docs/COMPATIBILITY_MATRIX.md`
- **実施内容**：リリース対象のOS/Python/依存、全必須機能と除外、利用業務、旧保存の移行、配布物の境界を定める。環境未指定なら現在のLinux環境を候補とし、他OSを無断で受入済みにしない。
- **受入条件**：全必須F/I/O/N/Wの検証器/実行環境/再利用証拠が指定される。必要OS/実業務の未決は具体的な選択肢を示し、独断で要件を縮小しない。
- **確認方法**：文書/仕様/監査は差分と根拠・リンク・依存を確認。検証カードは本文指定の専用実行を行い、[共通検証規則](README.md#検証と完了報告)で報告する。文書更新だけでFEMを再実行しない。

- **納品物**：該当差分、カード受入条件ごとの結果と未確認理由、実施したコマンド/終了状態、次の着手ID。数値実行のrawは未使用の`out/`以下に保存し、短い結果と来歴を該当仕様書へ記録する。

## V02

### 配布と旧保存移行を検証する

- **親課題**：V02。**種別**：検証。初期状態：未着手。
- **先行条件**：[V01](09-release.md#v01)、[S07](07-static-and-integration.md#s07)、[C08](06-compatibility.md#c08)
- **コミット件名案**：`test: 配布と旧保存移行を検証する`
- **既存の入口・影響先**：`scripts/package.py`、`tests/test_package.py`、`docs/INPUT_OUTPUT.md`
- **実施内容**：現行パッケージを新規環境へ展開し、公開した入力/保存版のreader、CLI/GUIの代表計算/再開を確認する。依存ライセンスと参照バイナリ非同梱を検査する。
- **受入条件**：対象環境でインストール/元場再生/新規求解が成功し、ユーザー資産とoutを混入させない。実測したOSのみ合格を記録する。配布/移行の修正は原因ごとのコミットに分ける。
- **既存の検査候補**：`test_package`、`test_save_completion`。変更した契約に直接依存するケースを選ぶ。新機能の独立検査は別途追加する。
- **検査コマンドの出発点**：

```sh
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src:tests .venv/bin/python -m unittest -v test_package test_save_completion
```

- **納品物**：該当差分、カード受入条件ごとの結果と未確認理由、実施したコマンド/終了状態、次の着手ID。数値実行のrawは未使用の`out/`以下に保存し、短い結果と来歴を該当仕様書へ記録する。

- **親課題**：V02。**種別**：検証。初期状態：未着手。
- **先行条件**：[V02](09-release.md#v02)、[D04](04-design.md#d04)、[D11](04-design.md#d11)、[N04](05-accuracy.md#n04)、[N08](05-accuracy.md#n08)、[H18](02-hphi.md#h18)、[P10](03-planar.md#p10)

- **既存の入口・影響先**：`scripts/validate.py`、`docs/TESTING.md`、`docs/IMPLEMENTATION_STATUS.md`
- **実施内容**：変更を止めた候補で全unittestを含むvalidateを一度実行する。seedの周波数と全RFをbenchmarks/validationと比較し、追加物理の専用証拠の適用性を確認する。失敗修正時は影響範囲を再評価する。

- **確認方法**：文書/仕様/監査は差分と根拠・リンク・依存を確認。検証カードは本文指定の専用実行を行い、[共通検証規則](README.md#検証と完了報告)で報告する。文書更新だけでFEMを再実行しない。
