- **親課題**：L01。**種別**：調査。初期状態：未着手。
- **先行条件**：[B02](01-baseline.md#b02)

## 条件付き要件から追加カードを作る手順

L05は以下を実行する作業規則。既存90カードにない必須機能が判明した場合の成果物も、作業者がここから作れるようにする。

### 起票条件

B03/C01/C04/H17/S01〜S05/L01〜L03で、対象版の根拠とユーザー要件により追加が必要と確定した場合だけ起票する。
「対象版に存在する」だけでユーザーの必須範囲を変更しない。未確認の場合は調査結果に不足資料と次の照会を記録する。

カード名は`ADD-<親ID>-<機能名>-01`のように一意とし、親監査カードの依存に追加する。
下表の各行を一つのコミットへ展開する。複数ツール/物理/形式を一つの実装コミットにしない。

| 子カード | 実施内容 | コミットに入れる成果物 | 終了条件 |
|---|---|---|---|
| 01 仕様 | 原要件/対象版の根拠、方程式/構成則または変換規則、単位、正常/拒否例、旧経路との互換を決める | `docs/<FEATURE>.md`、必要な入力例、該当親/TSVへのリンク | 数式、未知数/境界/零空間または列/文法、数値ゲート、具体的な変更関数名が埋まる |
| 02 入力 | 専用strict schema/版/既定値/能力表示、元入力と来歴の保持 | `src/superfish_ng/<feature>_input.py`または既存readerへの追加、`tests/test_<feature>_input.py` | 重複/未知/不正型/単位/未対応を処理前に拒否し、旧入力が同じ意味で読める |
| 03 計算/変換 | 専用の実計算または変換を既存の確認済み核へ接続する | `src/superfish_ng/<feature>.py`、独立不変量の検査 | 仕様の解析/物理/変換参照と一致。失敗結果を成功値で代用しない |
| 04 保存/CLI | 入力/元係数/規約/全量/失敗履歴を保存し再検証する | 保存アダプタ、CLI、savedの検査 | 旧保存互換、成功/失敗/中断、改変拒否、元ファイル保持、CLIとAPI一致 |
| 05 利用先 | 要件に指定されたworker/GUI/後処理へ接続する | 利用先差分と該当操作検証 | 元FEM/単位/状態が一致し、実中止/再開/再起動または対象読み手との受渡しが成功 |
| 06 独立受入 | 独立解析/参照、必要な両側細分、対象版の入出力/操作を評価する | `scripts/validate_<feature>.py`、結果と親受入表 | 全必須条件にPASSまたは理由付き未確認。未確認があれば親を閉じない |

上のファイル名は新設候補。既存機能で満たせる行は「既存のファイル/関数/証拠」を指定して監査コミットに変える。
不要なモジュールや単体テストを表の形に合わせて増やさない。CLI/GUIが元要件にない場合は05の非適用理由を記録する。

### 機能別に最初に固定する内容

| 親/候補 | 仕様で決めること | 独立検証の出発点 |
|---|---|---|
| P04 体積損失 | 実場の摂動損失か複素固有解か、epsilon/muの符号とphasor、領域ごとの損失、適用限界 | 一様媒質の解析関係、無損失極限、独立エネルギー/損失積分。実固有解のまま複素モード対応と呼ばない |
| S01 純Neumann | 全電荷と境界流束の整合、定数核、基準電位、保存時のgauge | Gauss則、定数シフト不変、非整合荷重の拒否 |
| S01 浮遊電極/容量行列 | 電極毎の未知電位/指定電荷、基準電極、端子集合 | 電荷保存、容量行列の対称性、同軸/平行板極限、エネルギー |
| S02 境界拡張 | ポテンシャル/源の単位、gauge、有限境界と外部領域のモデル | Ampere則、場/エネルギー、境界距離とFEM細分の独立系列 |
| S03 材料モデル差 | B/H/磁化の変換、方向/異方性テンソル、物性の出典 | 方向回転/反転、界面条件、構成ポテンシャルと仕事の釣合い |
| S04 BH差分 | 補間/外挿と真の接線、表折点、収束/失敗契約 | 構成エネルギー微分、線形極限、独立BVP、減衰/停止不良 |
| S05 軸接続/材料の軸力 | 全周力の成分、真空応力領域、固定源の仕事と材料軸の移動 | Maxwell応力と別FEM仮想仕事、正味力の対称性、面/細分依存 |
| L01 各専用ツール | 近似物理と入力/出力、既存FEMで足りる部分、固有の計算が必要な部分 | ツールの定義に対応した解析/独立参照と実業務の完結 |
| L02 磁石探索 | 変数/固定源/材料、目的と制約、失敗の扱い、試行上限 | 初期/最終の元場を独立細分、制約達成と数値収束を別判定 |
| L02 熱 | 熱伝導率/熱源/境界/初期条件、定常/過渡、RF熱源移送の単位 | 解析熱伝導、熱収支、境界熱流束、メッシュ/時間刻みの別収束 |
