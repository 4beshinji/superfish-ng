# Hφの同一真空領域・独立メッシュ比較基盤

P03/O02に残る収束・追跡の前提として、元要素の共通積分領域を構成する。[幾何実装・検証](MERIDIONAL_OVERLAP.md)の範囲で限定受入。
独立Studyの同じ順位を同一モードとみなす機能は追加しない。
最初の工程は幾何だけで、FEMの再計算や場の対応判定・誤差推定は含めない。

## 入力と出力

同一の宣言真空領域を持つ二つの検査済みMeridionalMeshまたはAxisConnectedMeshを対象にする。
外周と全PEC穴をbinary64が表す厳密有理数として比較する。境界分割密度・内部メッシュ・節点番号は独立。
連続した同一直線上の分割点と輪郭の開始点を正規化し、穴の順序が違っても全形状の集合が一致することを確認する。
軸区間・穴の欠落、わずかな形状差を許容差で同一視しない。異なる物理Caseをこの幾何APIだけで同じ問題として承認しない。

既存自作の有理数三角形交差・BVH候補・元要素被覆検査を再利用する。
共通小三角形ごとに前後の元要素ID、両方の元局所順を保つ重心座標、r,z座標、正の面積ヤコビアンを返す。
全元要素の被覆面積を有理数で確認してから、浮動小数の積分用配列へ変換する。
この工程の測度はdr dz。回転体の2πr、正半径q形式の1/r、電磁場の位相/周波数/単位は後続の物理積分で明示する。
最大候補数・分割数を超えた場合や、正の分割が浮動小数で表せない場合は失敗する。

## 幾何工程の受入条件

- 軸あり/なし、0/1/2穴、境界密度と内部対角線の異なるメッシュで、全元要素被覆と穴を除いた独立面積・体積・多項式モーメントが一致する。
- 両方の元要素の重心座標から同じ物理点が得られ、元の多項式場の積分を保持する。番号変更・輪郭開始点・穴順変更に依存しない。
- 凹形・傾斜境界にも適用し、欠けた穴・軸区間や微小な形状差、予算超過を明示拒否する。
- 既存PlanarMesh/平面追跡の意味を変更しない。標準と既存f/RF、不変候補と統合sourceを照合する。

後続は、正則uまたは正半径qの元電場を2πr測度で比較する専用APIと、対応を確認した細分診断・保存・CLI/GUI。
幾何の一致・小さい固有値残差・小さい細分差を、連続問題の誤差上界へ読み替えない。
新しい外部資料・依存・旧版参照は使わない。

候補608sourceでは追加4unit（0.947秒）、独立48組の形状/メッシュ・元P1/P2の288積分（6.327秒、最大差9.992e-16）がPASS。標準1046件・主4unitも合格し、主ツリー614sourceへ統合済み。
