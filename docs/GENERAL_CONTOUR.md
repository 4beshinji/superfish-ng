# G01: 軸に接続する単一の一般輪郭

2026-09-08仕様。R(z)の単価関数を前提とせず、z折返しを許す直線多角形を扱う。
真空・軸対称m=0 TM、閉PEC（または明示した平坦端の対称面）の物理契約は維持する。

## 輪郭契約

Contourは閉じた単一外周を、終点重複なしのvertices_zr_mと同数のedge_tagsで表す。
タグiは頂点iから次の頂点への辺。タグはpec/axis/electric_symmetry/magnetic_symmetry。
有限SI座標、r>=0、min(z)=0、max(z)=L>0。軸辺群はz=0からLまで連続する1本の鎖とし、
正半径の外周は軸へ再接触しない。軸以外に穴・内部境界を表すことはできない。
反時計/時計回り入力を受理し、反時計回り・(0,0)始点に正規化する。タグは辺と共に写す。
対称タグはz=0またはLの端面だけ。r=0の辺はaxis必須、他の辺にaxisを指定しない。

自己交差、非隣接接触、重複点、ゼロ長辺、隣接辺の折返し重複、負半径、微小退化を拒否する。
幾何判定は全体寸法で正規化し、浮動小数点で判別不能な接触を推測して受理しない。
許容差を形状の丸めや隙間の自動修復に使わない。エラーには該当辺/条件を示す。
面積と回転体積は多角形境界の解析モーメントから算出する。

## Caseと既存形状の移行

v3 geometry.type=contour、vertices_zr_m、edge_tagsを追加する予定。
旧profile/stepped_profileは端面と軸を補って厳密変換する。arc_profileは指定弦誤差で
近似した輪郭への変換と明記し、円弧の厳密面積を多角形値と混同しない。
既存のCase/profile/hashは維持する。入力モデルとしての受理と計算可能性を分離し、
G02の一般輪郭メッシュが完成するまで既存R(z)メッシュ生成に流し込まない。
新輪郭のプレビュー/外部mesh検証/鏡映/保存への移行をG01で記録する。

## 独立受入条件

矩形・凹形状の分割面積/回転体積、向き反転と開始点変更、寸法s倍でA→s²A/V→s³V、
鏡映で面積/体積2倍、既存R(z)変換の一致。z折返し合成例を明示し、実測形状と呼ばない。
不正交差/接触/重複/軸切断/不正タグの拒否を検証する。
Case往復と既存回帰を通してG01を受入し、G02のメッシュ品質/固有値受入とは分離する。

### 局所端面タグ — 2026-09-08

同じ平坦端面でPEC/電気/磁気タグを混在可能にした。Caseのz_min/z_maxは
導出要約mixedを持ち、JSONの物理入力は引き続き辺タグを正とする。mixedは旧profileへ
指定できない。外部meshは端面全体のタグ推測を行わず、輪郭辺ごとのタグ照合を使う。
局所magnetic_symmetryは指定辺のu=0境界として計算し、領域全体の鏡映対称性を意味しない。
混在端面の鏡映を明示拒否する。GUIは混在を無効化表示し、通常形状へ戻ると要約欄を除く。

検査。指定辺の端点/中点ゼロ、同端面の残り自由度、Case往復と鏡映拒否も合格。
