# 宣言したPEC多角形の明示xyメッシュ

P02の一般断面へ進むための幾何・面積FEM基盤。矩形以外のPlanarCase、固有モードの製品solve、native保存、CLI、場の点検索はまだ接続していない。矩形の既存経路は維持する。

`superfish_ng.planar_mesh.PlanarMesh.create(polygon_xy_m, points_xy_m, triangles)` は反時計回りの単純多角形、SI xy節点、正向き三角形の整数番号を受け取る。閉点を末尾へ重ねない。宣言した全角点は元メッシュに同じ座標で含める。曲線、穴、多重連結、非PEC境界は対象外。

`from_dict` / `to_dict` の専用書式は `format=superfish_ng_planar_mesh`、`schema_version=1`、`coordinates=cartesian`、`boundary=pec` と上記三配列だけを持つ。余分なキー、bool/string座標、浮動小数点番号、非有限値、未使用点、重複点/要素を拒否する。軸対称readerは利用しない。

検証は次を全て要求する。

- 入力binary64座標でも厳密に正の向きと、丸めによる相殺で未解像でない要素Jacobian、共有辺の反対向き、辺当たり高々二つの要素。
- 要素の辺連結、Euler標数1、単一境界周回、各節点のlinkが内部円周または境界区間。
- 全辺の交差・重なり・非共有T字接続がないこと。AABBによるx方向走査で候補を絞り、方向判定が丸め誤差に近ければ入力binary64値を有理数へ変換して符号を再計算する。曖昧な交差を許容差で消さない。
- 境界が宣言角点を順番に通り、各宣言辺を単調に分割して全て被覆すること。アフィン座標生成の丸めだけを許容するため、全座標幅で規格化した法線距離に64 machine epsilonを用いる。これはユーザー指定の形状近似許容差ではない。
- 宣言多角形と三角形和の面積一致。面積一致は上の接続・交差検査を代替しない。

面積演算は原点移動と幅で規格化する。有限SI面積や正Jacobianを浮動小数点で表現できない場合は拒否する。入力配列のコピーを保持する。`planar_mesh_matrices(mesh, element_order, polarization)` は元形状・接続を再検証してP1/P2の面積K/MとTE自由/TM PEC自由度を返す。既存矩形と共通の積分組立関数を使い、固有値への解析補正はない。
