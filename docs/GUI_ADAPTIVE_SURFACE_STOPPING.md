# 版3のピーク比を含む適応停止GUI

2026-09-08、直前基準9cee5a4。[版3の数値仕様](ADAPTIVE_SURFACE_STOPPING.md)を
既存のローカル適応GUIへ接続する。FEM・追跡・区間評価・停止基準は変更しない。

確認方式で版3を選び、Epk/EaccとBpk/Eaccの相対変化上界の許容値を別々に入力する。
現在の形状から入力を作ると `surface_relative_tolerances` が明示される。
版3は `nested_affine` と `uniform_two_steps` を使う。ピーク用入力は版1/版2では無効になる。
入力作成後のJSONを確認して開始する。正確な多角形の角/接続診断に通らない形状は
サーバーがジョブ作成前に拒否し、直前の検証済み結果を維持する。

結果にはRF3量とピーク比2量の直近2区間・閾値・判定を表示する。
ピーク比は上限値同士の差でなく、連続離散ピーク上下界から求めた最悪相対変化を表示する。
各水準のピーク比上下界と元多角形診断も別表で確認できる。
表面の複合状態は NOT_CONFIRMED（全条件の確認未完）、UNVERIFIED（量/ID未確認）、
TARGETS_MET（指定した区間変化を達成）を区別する。
RFが条件内でもピーク比が未達なら、全体の上限停止を達成へ置き換えない。
全域確認回数、対象ID・順位、物理誤差上界なしを保持する。

開始・取消し・部分実行・保存再開は共通JobManagerを使う。
再開は検証済みチェックポイントの要求を使い、フォーム編集を暗黙に反映しない。
保存JSONはサーバーが再検証して返した文字列そのもの。
ページ再読込後に開いても版・閾値・全水準・状態を復元する。
改変された区間や元場を拒否し、直前の確認済み結果を維持する。
対象場を開く操作は保存結果を再検証して最終水準の追跡対象順位を使う。

版1/版2の表面未評価（UNASSESSED）は維持する。
両版の結果を開くとピーク表を消去し、5量表を従来の3量へ戻すため、版3の値を残さない。
独立した直線表面評価画面は引き続き別ID・固定N03閾値で評価できる。
通常RF表示のピーク標本を連続離散上下界に置換する変更は含まない。

検証入口: `scripts/verify_gui_adaptive_surface.mjs`。
実Chromeで閾値入力/入力作成、4+1水準の実計算・保存再開、五量と上下界表示、対象順位2、
JSON完全一致、改変拒否、ページ再読込、対象場、再入角入力拒否、ピーク未達の上限停止、
版2結果への切替と版1入力作成を確認する。数値合格はサーバーの再検証結果だけを使う。

通常RF画面への統合、一般形状の精度/効率、曲線局所細分、物理誤差上界は残件。
N03/N04親課題全体の受入には数えない。
