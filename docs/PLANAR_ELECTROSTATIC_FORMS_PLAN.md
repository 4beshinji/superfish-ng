# S01: 平面静電の誘電体・電荷・弱形式

2026-09-13 JST。軸対称静電に続く独立した平面基盤。[実装記録](PLANAR_ELECTROSTATIC_FORMS.md)の行列/荷重範囲で限定受入。
Cartesian xyに垂直な方向に一様な場を対象とし、単純多角形の明示直線P1/P2メッシュを使う。
正値実数・線形等方epsilon_r、領域一定の符号付きrho[C/m³]を全セルへ明示する。

受入条件：

- 平面専用の誘電体分割・座標JSONを用いる。回転軸やRFのPEC境界条件を入力から推測しない。
- 幾何は既存の単純多角形検査を使い、自己交差・未割当/重複セル・曲線/穴・未知物理を拒否する。
- Kij=epsilon0∫epsilon_r grad(Ni)·grad(Nj) dxdy [F/m]、fi=∫rho Ni dxdy [C/m]。
  法線方向に長さ1 m当たりの量であり、2πrや暗黙の厚さを掛けない。
- 全DOFと定数電位核を保持する。x=0を軸条件として扱わず、負のx/yと原点を横切る領域を受理する。
- 電荷和=∑rho*領域面積、正負・0・相殺、epsilon倍率、charge反転を確認する。
- 一様形状尺度でK不変・荷重∝s²、平行移動/回転でK・荷重不変、材料/領域順序の不変を検証する。
- 独立Gauss/Vandermonde組立、P1/P2の多項式エネルギー形式/電荷仕事、矩形と凹多角形の解析面積積分を照合する。
- 標準回帰と旧周波数/RFを維持する。積分差・定数核・行列残差から解や容量の精度を宣言しない。

この工程では平面の境界/gauge、解法、元E/D、J/mのエネルギー、F/mの容量、保存/CLI/GUIをまだ適用しない。
軸対称の電極/Dn契約は後続で単位長さの表面測度へ明示的に接続する。
