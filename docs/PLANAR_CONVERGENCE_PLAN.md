# 同一平面形状の細分診断計画

[平面Study](PLANAR_STUDY.md)の独立掃引と分離し、元の物理・形状が同じ細分列のf、電場、磁場、単位長RFを診断する。単に分割数を変えた掃引を収束認証と呼ばない。平面追跡・一般形状変形は別の契約。

## 元形状と子メッシュ

矩形/明示単純多角形に対し、元xy三角形の各辺中点を共有する四分割を使う。元の節点番号を保持して新点を追加し、全宣言境界・領域・物理・偏波・規格化・導電率が不変であることを再確認する。全子メッシュを既存PlanarMeshの正Jacobian・連結・境界被覆・交差拒否で検証する。数値的に解像できない細分は拒否し、許容差を緩めて通さない。

子要素から元要素への番号と重心座標写像を記録し、P1/P2の同じ離散場を細分空間へ係数移送できるようにする。共有点で元の連続スカラー場のtraceが一致すること、定数/一次/P2二次多項式、PEC拘束、PᵀM_fP=M_cとPᵀK_fP=K_cを独立に確認する。移送は新しい固有値解を生成したことにしない。

## 診断と保存

各細分段で実FEMを解き、元/子の宣言メッシュ・履歴・nativeを保存する。元Caseと細分点の関係、全体/点manifest、途中変更、再起動後の完全再生を検証する。固定形状の細分要求を任意座標変更や別偏波で代用させない。

fと物理E/Hの面積内積・単位長RFを別判定し、少なくとも三水準の比較を行う。元/子の共通領域で、元要素の多項式と実固有周波数から場を評価する。表示の平坦色・線形補間を診断積分に使わない。単一モードの位相整合と縮退部分空間を区別し、曖昧な対応・スペクトル範囲不足ではUNVERIFIEDを返す。

細分差、代数残差、壁積分安定、真の離散化誤差を別に扱う。G/Qや体積場が安定したことだけで角の連続表面ピーク精度を保証しない。単位長U′/P′、TE零空間除外、両R/Q N/Aを保持し、閾値・未達理由・対象順位/部分空間を保存する。

API/CLI・実worker/中止/再起動・GUIへ接続し、矩形と三角形の独立解析f/全場/G、二尺度・P1/P2・TE/TM、縮退正方形、凹形状、旧Study/単体native/GUI、標準・既存TM/TE数値回帰を確認して受け入れる。一般追跡と親P02全体の完了は別途監査する。
