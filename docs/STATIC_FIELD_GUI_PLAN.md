# O02: 静的ProjectのGUI入力・実求解・元場表示

2026-09-13 JST。[実装記録](STATIC_FIELD_GUI.md)の専用静的GUI範囲を限定受入。[静的Project worker](STATIC_FIELD_JOBS_PLAN.md)に続く。

受入済み11形式のCase/Projectを専用画面へ読み込み、厳密JSON編集・検査・Project保存・表示長さ単位m/mmを扱う。求解は同じ静的Project workerを使用し、HTTP処理内やGUI内に新しいソルバーを作らない。成功、保存済み非線形失敗、中止/未完/IO失敗を区別し、全Caseと材料/境界/求積/初期値・停止履歴を表示する。

成功した場は保存元の専用FEMを再検証し、元の片側場評価を使って描画する。異材料や穴をまたぐ補間・表示平滑化を数値結果に混入させない。標本位置と表示近似、平面単位長量/全周量とSI単位を明示する。B-H失敗に有効な場の図やゼロ値を作らない。RF周波数・R/Q・モード番号など対象外量はN/Aとし、静的JobをRF追跡へ渡さない。

初回/再起動時の実FEM再検証は非同期とし、検証前や改変後の場を公開しない。Project、元native、全結果/失敗履歴を元バイトで取得できるようにする。GUI actionを認証/厳密フィールド検査へ接続し、元Caseと結果・表示・API/CLI・保存ファイルの一致を確認する。

受入は全11形式/対応次数、実worker、3座標系のB-H成功/失敗、全量/単位・元場/材料/境界と描画、Project編集/往復、初回/再起動、中止/強制終了/改変拒否。独立参照Caseの元場とAPI/CLI結果を実ブラウザーで照合し、既存RF・磁気報告の操作と回帰を保持する。目視/自動ブラウザー確認をユーザー業務評価と混同しない。

静的Studyはこの画面の後続。対象版確認・O02親/全計画は未完のまま。新規依存、外部サービス、旧版コードの利用は導入しない。
