## 操作

`superfish-ng gui --workspace out/<新しい作業領域>` を起動し、「制約を満たす形状を探索する」を開く。

1. 曲線P2の全PEC Projectを準備する。要求例 `examples/optimization/curved_rf.json` の読込でもProjectとフォームを復元できる。
2. 半径・軸方向倍率の下限、上限、初期値、初期幅、最小幅と探索順を指定する。目的関数、最大化/最小化、採用改善量を指定する。
3. 使用するRF制約を選び、上限/下限と同じ単位の違反量尺度を設定する。尺度は制約違反間の比較に用い、細分許容差を変更しない。両R/Qの定義と各量の単位を画面に表示する。
4. 初期・最終確認を含む試行上限、RF評価座標、初期IDと対象IDを設定し、現在のProjectから要求を作成する。JSON要求を保存できる。JSONの重複キーや未対応項目は拒否する。
5. 開始後はジョブ一覧から状態確認・中止を行う。停止ジョブのチェックポイント一覧は未検証候補で、開く際に所有関係・祖先・保存場・全判定を再検証する。
6. 検証済みの途中結果を保存/読込し、再開する。再開には保存要求を用いるので、別途編集したフォームや要求JSONへ置き換わらない。再開前の完全検証中は待機表示になる。
7. 試行と3水準のいずれかを選び、対象IDの場を開く。保存された個別追跡の実順位を用いてnative結果を取り込む。個別ID未確認の試行は順位を仮定して開かない。

## 判定と制限

ジョブの正常終了、探索の状態、制約判定、停止理由を別に示す。`SEARCH_COMPLETE` と `TRIAL_LIMIT` は併存し、最適性や物理誤差上界の証明ではない。細分未達・区間重なり等の試行に有利な目的関数値を表示しない。中止された別分岐の部分計算を、完了試行のFEM数に算入済みとはしない。

対応範囲はnative曲線P2の閉PEC形状に対する半径/軸方向の2変数。固定局所履歴は上記版2で対応する。反射、組立、一般変数・非アフィン変形は未対応。計画親D03は継続中。以下の全体集計は各検証時の履歴であり、現在の親集計はCOMPATIBILITY_PLANを参照する。

再開preflightは管理器のロック外で実行し、起動前にclosedを再確認する。検証中でも他ジョブのstatus/cancelとcloseを進められる。開始HTTP要求そのものの同期的な完全検証を高速化した変更ではない。
