# S04: 平面P1非線形磁場の保存・CLI

2026-09-13 JST。後続限定課題。[実装記録](PLANAR_BH_NATIVE.md)の専用API範囲で限定受入。

専用CaseのB-H表/来歴・固定Az/Ht・全Jz・Newton設定/明示初期値を保存し、成功解の相対/絶対Azと基準、元セルB/H/接線、内部g・電流/境界荷重、反復履歴とU/U*・周回/反力・磁束を同じ非線形FEMで再計算して照合する。元係数と決定的な履歴の一致を要求する。独立ソルバー比較や旧版互換保存とは呼ばない。

成功nativeはcase.json、mesh.npz、fields.npz、results.jsonと最後に発行するmanifest.json。収束失敗は別のcase.json、failure.json、manifest.jsonとし、成功用read/probeで受け取らない。失敗読込でも同じCaseを再試行し、失敗理由・設定・全履歴・最後の有効係数またはnullを照合する。無効Caseは解析前の入力エラーで、収束失敗保存と区別する。solve/replayの収束失敗はCLI終了1、入力/保存検証エラーは2、成功は0。

受入は解析検証済み例のAPI/CLI保存ファイルとprobe全JSONの一致、失敗3種類の保持/再試行、改変後のハッシュ再計算でも物理/履歴の不一致を拒否、部分出力/シンボリックリンク/読書き中の変更を拒否、既存出力と参照データの不変性を含む。probeは元P1場と材料来歴・表区間/割線/微分磁気抵抗率を明示する。GUI/Project/Study対応は追加しない。標準検証と旧周波数/RF比較を完了して限定受入する。
