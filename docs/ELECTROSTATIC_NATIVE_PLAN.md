# S01: 軸対称静電の保存・再構築・CLI

2026-09-13 JST。静電Poisson APIに続く限定課題。固定候補687sourceの実装を検証中。未受入。
専用Case、材料/領域、全境界辺の条件、基準電位、元FEM係数と静電量を保存する。

受入条件：

- 専用native版1にstrict Case、全幾何/材料/境界/DOF配列、基準電位からの係数を保存する。
- 全K・体積荷重・Neumann荷重・固定DOFを再構築し、保存係数を再生する。単にmanifest hashが合うことだけで受理しない。
- 再計算したPhi/E/D、領域エネルギー、反力/元場の電極電荷、容量定義と単位を全検証する。
- 原本スナップショットとmanifestを最後に公開する5ファイル形式を採用し、既存出力の上書きを拒否する。
- solve/replay/probeの静電専用CLIと能力表を追加し、RFのcanonical Modelへ静電入力を暗黙変換しない。
- API/CLIの保存物一致、材料/境界/係数/基準電位/静電量のhash再作成後の改変拒否を確認する。
- 独立物理検証済みのCaseで再生・probe・CLIを照合し、元出力の不変を確認する。
- 標準回帰の周波数/RFを保つ。Project/worker/GUI、平面静電は別工程。

新規依存・外部サービス・旧版配布なし。S01と全計画は未完。
