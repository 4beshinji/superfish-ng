## 局所化と選択

親の係数を子空間へ移送し、子モードとの符号を質量内積でそろえ、質量ノルムを合わせる。
子解の固定周波数随伴z0と角周波数偏微分qωから、

```
qλ = qω * ω/(2λ)
z = z0 - qλ * u/(u.T M u)
```

を作る。これにより `-u.T M z = qλ` となり、場方向と固有値方向の寄与を合わせる。
親節点を子空間の先頭に保持する既存制限写像の契約を使い、
zの親P2節点補間を子空間へ移送して差し引く。この細かい成分をzdとする。
親の固有値λHと移送した場uHについて、各子要素の符号付き寄与を

```
ηT = -zd_T.T (K_T - λH M_T) uH_T
```

で計算し、元の親要素ごとに加算する。全親寄与の和が、組立済み全体行列による
`-zd.T (K - λH M) uH` と相対差1e-10以下で一致することを検査する。
基準の分母は子寄与の絶対値和と全体作用の大きい方で、符号相殺で偽の不一致を作らない。
差し引いた親補間の全体作用も報告し、積分誤差等を隠さない。

親の符号付きR/Q寄与の絶対値[Ω]を優先度とする。
既存の非負配列のbulk選択を再利用し、総優先度のbulk_fractionを覆う最短の降順prefixを選ぶ。
同値は親要素番号順。ここで足す量はΩの絶対寄与であり、従来の二乗残差ではない。
加速器/回路規約の符号付き寄与と全体推定変化を両方返し、回路規約は1/2。
選択番号は確認メッシュではなく元の親空間の番号で、新しいmarked履歴へ渡せる。

これは固定された二次近似領域のRF優先度であり、物理誤差上界ではない。
実測値・解析境界誤差を含む認証も与えない。ゼロ優先度は収束証明ではない。
通常の五量停止・表面/積分検査は変更せず、既存の適応版4へ自動選択としてはまだ接続していない。
