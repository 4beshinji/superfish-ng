# 曲線Projectと元メッシュのアフィン変形

2026-09-14追補：[曲線アフィンStudy](CURVED_AFFINE_STUDY.md)はこの変形を元Projectから各条件へ独立に適用する。追跡/区間二分は実際の前後の条件から相対写像を導出する。

2026-09-14追補：[局所分割の固定](FROZEN_CURVED_REFINEMENT.md)を先に実行すると、元形状の分割辺/遷移対角線を保持して変形できる。未固定の履歴は従来どおり接続を検査して拒否する。

後続実装: [曲線アフィンtune](CURVED_TUNING.md)へ接続。以下は一括変形基盤を受け入れた時点の記録。

2026-09-09、D02の曲線調整接続に必要な一括変形を実装・限定受入。

`transform_curved_project(project, affine_map, rf_coordinates=...)` は
native曲線を同じfractionで変換し、元弦メッシュの番号・接続・タグを維持した
Project第2版を返す。元メッシュがない場合は元Caseから一度生成する。
元の自動弦分割も固定数として保持し、新形状から再生成しない。
写像は既存の `(r,z) → (a r, b r + c z)`、a/c正、b有限。
軸・閉輪郭・対称面等のCase物理契約は変形後にも適用する。

RF座標の方針は必須引数。対象は入力Caseであり、鏡映後の評価条件は既存の鏡映規約から導出する。`fixed` は元の実効active length・電圧区間・位相原点を
固定し、`axial` は3つをc倍する。未指定区間も元Caseで評価してから変換する。
ただし未指定の位相原点は未指定のまま保持する。既存の鏡映契約では未指定は完成した
全体空洞の0が既定であり、明示0に変えるとz_min鏡映後に原点が移動するためである。
したがってfixedで短縮した形状の外へ電圧区間が出る場合は拒否する。
正規化エネルギー、導電率、beta、最小間隙/曲率半径は固定し再検査する。
生成器設定と細分の角度/予算も維持する。入力済みメッシュを生成器の設定から
作り直す操作ではない。弦/接合の近似許容長は行列の最大特異値で伸縮し、
その明示された新予算で既存の弦誤差条件を再検査する。

二次幾何は固有値計算前に再構築し、元二次写像を変換した点・接続・境界fractionと
照合する。局所細分は最長辺と対角線の選択が変形で変わる可能性があるため、
各履歴prefixを検査する。異なる場合はUNVERIFIEDとして拒否し、以前のセル番号が
別のセルを指す履歴を保持しない。2026-09-14に追加した明示の[分割選択保存](FROZEN_CURVED_REFINEMENT.md)により、
固定した参照分割を移送できる。未固定入力に自動で固定を付け加えない。幾何点の比較は浮動小数点整合性であり物理誤差評価ではない。

`relative_affine_map(previous, current)` は同じ元形状からの2変換の
`current @ inverse(previous)` を返し、試行間追跡に使う写像を導出する。
追跡そのものは実FEM場の比較であり、この関数がmode identityを証明することはない。

受入条件: 実FEM/二次写像・一様履歴・元接続・保存再読込と実追跡、
RF方針と相似則、独立点での写像合成/逆変換、曲率条件と不正入力拒否、
局所細分対応の検査、標準周波数/RF回帰。

このAPIをtune試行/保存再開/CLI/GUIへ接続する工程は残る。
新規外部資料・依存・legacy参照はない。
