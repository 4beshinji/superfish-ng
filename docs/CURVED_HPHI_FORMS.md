# 穴付き二次幾何のHφ変分形式

[計画](CURVED_HPHI_FORMS_PLAN.md)の固定候補646sourceを主ツリーへ統合し、以下の範囲で限定受入。
`curved_hphi_matrices(geometry, element_order=2, quadrature_order=12)` は空間・K・M・積分診断を返す。
幾何を全再構築して、参照P1/P2の微分を二次写像のJacobianで物理座標へ変換する。

正半径の幾何ではq=rHφを用い、Kは勾配内積、Mは値の内積を1/rで重み付けする。
定数qは静的循環として行列に残す。このAPIでは正スペクトルの抽出を行わない。
軸接続の幾何ではu=Hφ/rを用い、Kはr重みのcurl内積、Mはr³重みの値の内積とする。
全軸DOFを保持し、定数uに正のcurlエネルギーがある。軸接続空間に静的零モードの除外を適用しない。
共通因子2πを含めない既存行列規約を保持する。

指定次数と+4の次数でK/Mを別に比較し、相対差5e-10を超えれば未解決として拒否する。
要素次数は1/2、積分次数は2〜32の整数だけを受け付ける。型/モデルを暗黙に変換しない。
有限次数の一致は積分診断であり、固有周波数・場・RFの離散化誤差上界ではない。

## 検証

追加4unitと幾何/既存曲線を合わせた22unitが3.306秒でPASS。
直線極限の両既存K/M、質量正値・行列対称性、正半径qの唯一の静的核、軸uの正値、全軸DOFを確認した。
定数uではKの二次形式が4∫r、Mが∫r³に一致する。qの定数/物理座標場では解析的な対数積分とエネルギーを照合した。
相似変換ではqのK/Mが尺度の−1/1乗、uのK/Mが3/5乗で変わる。

初回unitの直線照合だけがFAILした。旧正半径Caseの既定積分次数8と新行列の次数12を比べていたためで、旧参照にも明示12を指定した。
製品行列と許容差は変更せず、同じ次数で再検証した。初回ログを保持する。

独立検証は軸あり/なし・0/1/2穴・P1/P2・3変形・2尺度の72形式、12個の全固有分解による核検査。
