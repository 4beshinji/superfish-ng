# S05: 元の平面FEM磁場からの多極係数抽出

2026-09-13 JST。後続限定課題。未実装・未受入。

第一段階は専用PlanarMagnetostaticSolutionのP1/P2と一様な正スカラーmu_rに限定する。元Caseの実FEM再求解と係数一致を確認し、指定した多極frameの閉円板が領域内部にあり、交差する全セルのJzがゼロで、mu_rが同一であることを確認する。円周標本だけを調べて、円板内部の電流や材料界面を見逃さない。曲線/軸対称/非線形/反跳材料はこの第一段階で暗黙に受理しない。

元P1/P2係数から円周の片側Bを評価し、局所By+iBxの正方向Fourier係数をnormal/skew[T]として出力する。基準半径・原点・局所軸角を保持する。指定角度標本数Nと別の2N、内側半径0.75Rの比較、負次数成分と打切り残差を別診断にする。Nは少なくとも4×最大多極次数、最大次数は32、N上限は8192とする。小さな角度差/残差を無源性やメッシュ精度の証明へ置き換えない。

受入は一様双極場、三角形領域のA∝x²−y²による厳密P2四極場と明示境界、座標/基準/幾何尺度変更、元P1 8/16/32細分、元場の角度比較、隠れた内部電流/材料界面と円板の外部接触の拒否、元FEM係数改変の拒否を含む。解析P2係数/元場差は1e-10、座標則は1e-10、P1最細の係数/元場は0.02を開始条件とし、メッシュによる改善を確認する。求積標本数の改善とメッシュ改善は別系列にする。

検証用の四極場は、対角線x=yに固定Az=0、水平/鉛直辺に対応する一定Htを与え、実FEMで解く。解析係数を製品解へ代入しない。標準と旧周波数/RF差を確認して限定受入する。保存/CLI・GUI・材料拡張・力/トルクは後続工程。
