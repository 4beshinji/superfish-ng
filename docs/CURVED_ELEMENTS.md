# G03 二次幾何写像と曲線FEM

## 対象と現在の到達点

元の解析曲線、計算境界の二次近似、場のP2近似を区別する。
二次多項式の境界は一般の円/楕円を厳密には表さない。幾何誤差の評価を引き続き行う。
現在は局所写像/行列と、元曲線の区間を保持した共有二次幾何候補まで実装。
共有候補の全域Jacobianを全要素で検査するが、全体の境界交差/単射性検査は未実装。
Case/全体メッシュ/solve/保存/読込/サンプリング/GUIはまだ直線要素のまま。
新しい局所関数が存在することを、曲線FEMの製品受入とは扱わない。

## 幾何写像の契約

quadratic_geometry.QuadraticTriangleは6個の物理座標(r,z)を受け取る。
参照三角形はξ≥0、η≥0、ξ+η≤1。節点順は
(0,0),(1,0),(0,1),(1/2,0),(1/2,1/2),(0,1/2)。
既存P2基底Niを使い、X=ΣNi Xi、J_ab=∂X_a/∂ξ_bとする。
物理勾配は参照勾配の行ベクトルにJ⁻¹を右から掛ける。

det Jは参照座標の二次多項式。まず二次Bernstein係数の最小値を全域下界として使う。
その下界が丸め余裕より大きければ正値性を確認でき、微小Hessianの悪条件判定は不要。
下界が不十分な場合の最小値候補は頂点、
各辺に制限した二次式の内点極小、および正定値Hessianの内点停留点。
半正定値の平坦な極小集合は境界にも達し、不定値の内点停留点は最小ではない。
悪条件の正定値内点問題はUNVERIFIEDとして拒否する。
形状を平行移動・寸法で正規化して係数を求め、512ε×max(1,係数絶対値和)以下の
最小値は「非正またはUNVERIFIED」として拒否する。
determinant_lower_bound_m2は丸め余裕を差し引いた下界で、実測最小値とは区別する。これは倍精度での保守的な検査で、
厳密有理数演算や形式的な区間演算証明ではない。

各節点だけでJacobianを確認する方式は採用しない。
反例X=(ξ−1/4)²−η、Y=(ξ−1/4)η−0.01ξは
det J=2(ξ−1/4)²+η−0.01。
6節点では正だが、(ξ,η)=(1/4,0)で負になるため全域検査で拒否する。
正の局所Jacobianだけで、メッシュ全体の重なりや境界の自己交差がないとは主張しない。

## 局所積分の契約

curved_fem.mapped_element_matricesは検証済み写像の一要素について、

- Kij=∫ r[(2Ni+rNi,r)(2Nj+rNj,r)+r²Ni,zNj,z] dr dz
- Mij=∫ r³NiNj dr dz

を参照要素へ引き戻す。元のTM弱形式は変更しない。
半径が要素内で負になる写像は拒否する。数値積分点だけの半径検査ではない。
積分次数は明示整数2以上、既定8のDuffy積Gauss。
曲線写像で勾配は有理関数になるため、既定次数で厳密な剛性積分とは呼ばない。
固有値・RFの受入では積分次数を変え、幾何/FEM細分とは別に積分誤差を確認する。

独立検証は曲線領域r=ξ、z=η(1+aξ)、a=0.4を使う。
面積1/2+a/6、回転体体積2π(1/6+a/12)。
一定uのK二次形式は4(1/6+a/12)、Mは1/20+a/30。
物理場u=rはP2幾何と同じ節点値で正確に表され、K二次形式は9(1/20+a/30)。
直線写像では既存直線P2の基底/積分と一致することも別に検証する。

## 続く実装と受入

1. 元曲線のパラメータ区間をメッシュ境界の各辺へ保持し、共有の二次幾何節点を生成する。
   軸/対称面は直線に保ち、端点の共有とタグを保持する。
   曲線化による反転時は未検証の要素を返さず、細分・再生成または明示失敗へ進む。
2. 全体の共有辺適合性・曲線境界交差・重なり・物理領域を検査し、曲線幾何次数を
   場の次数から分離して入力/保存する。座標配列だけを変えた直線Meshとして扱わない。
3. 全体行列と解、エネルギー正規化、軸/壁RF積分、曲線法線/接線を同じ写像へ接続する。
   境界弧長の積分誤差も別に検証する。
4. 曲線写像の逆写像を含む場サンプリングと図示を実装する。
   直線三角形の重心座標をそのまま曲線要素の位置判定に使わない。
5. 保存/再読込で節点順・共有性・元曲線対応・全域Jacobian・積分設定を再検査する。
   鏡映、Study、GUIも同じ保存契約へ移行する。
6. 球形の独立参照と、楕円/双曲線の幾何/FEM細分を再実行する。
   周波数・体積場・軸場・RF・表面場を別判定し、積分次数と幾何次数を混同しない。

## 元曲線区間と共有二次節点 — 2026-09-08

ChordApproximation.segment_parameter_intervalsは、各弦の元曲線fraction区間を保持。
元曲線番号・タグとともにContourの始点正規化で回転し、保存geometry_approximationにも記録する。
曲線ごとの線形化はfractionの等分であり、弧長の等分とは呼ばない。

curved_mesh.curve_geometry_candidateは既存の弦メッシュを再検証し、各境界辺を
一意な元弦へ対応づける。弦上の位置をfraction区間へ線形補間し、境界の頂点と
共有辺中点を元曲線上へ移す。内部点/内部辺中点は保持。
軸/直線と元曲線接続点は、既存の明示端点調整を保持した共通位置を使用する。
複数辺からの節点位置が矛盾する場合は拒否する。

結果はCurvedGeometryCandidate。節点/要素/境界辺の共有番号、
境界の曲線番号と有向fraction区間、節点移動量を読み取り専用配列に保持する。
全要素のJacobian下界、Bernstein半径非負条件または半径多項式の最小値を検査。
この型は全体境界の交差・単射性証明を持たないため、solve/保存済み解へ接続していない。

検証は原曲線列を回転した場合のタグ/fraction保存、区間の被覆、
共有節点、元メッシュ不変、軸固定、独立解析面積/体積との差の改善。
楕円・双曲線例で面積/体積誤差が弦近似の1/10未満となる。
双曲線の弦誤差4 mm・FEM辺長5 mmでは、曲線化で要素89が反転/未証明となり拒否。
単に内側メッシュを細かくすれば曲線化が成功するとは限らない。
弦誤差を減らすか内側メッシュを再生成する必要があり、直線要素へ黙って戻さない。
