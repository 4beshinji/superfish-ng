# G03 二次幾何写像と曲線FEM

## 対象と現在の到達点

元の解析曲線、計算境界の二次近似、場のP2近似を区別する。
二次多項式の境界は一般の円/楕円を厳密には表さない。幾何誤差の評価を引き続き行う。
現在は局所写像/行列と、元曲線の区間を保持した共有二次幾何候補まで実装。
共有候補の全要素Jacobianと二次境界の閉鎖/交差を検査。
全体空間/疎行列と明示的な実験solve・参照座標での場評価は実装済み。
壁/軸RF積分も実験APIへ接続済み。
物理座標プローブも実験APIへ接続済み。
通常のCase solve/保存・表面ピークへはまだ未接続。
Case/全体メッシュ/solve/保存/読込/サンプリング/GUIはまだ直線要素のまま。
新しい局所関数が存在することを、曲線FEMの製品受入とは扱わない。

## 幾何写像の契約

quadratic_geometry.QuadraticTriangleは6個の物理座標(r,z)を受け取る。
参照三角形はξ≥0、η≥0、ξ+η≤1。節点順は
(0,0),(1,0),(0,1),(1/2,0),(1/2,1/2),(0,1/2)。
既存P2基底Niを使い、X=ΣNi Xi、J_ab=∂X_a/∂ξ_bとする。
物理勾配は参照勾配の行ベクトルにJ⁻¹を右から掛ける。

det Jは参照座標の二次多項式。まず二次Bernstein係数の最小値を全域下界として使う。
その下界が丸め余裕より大きければ正値性を確認でき、微小Hessianの悪条件判定は不要。
下界が不十分な場合の最小値候補は頂点、
各辺に制限した二次式の内点極小、および正定値Hessianの内点停留点。
半正定値の平坦な極小集合は境界にも達し、不定値の内点停留点は最小ではない。
悪条件の正定値内点問題はUNVERIFIEDとして拒否する。
形状を平行移動・寸法で正規化して係数を求め、512ε×max(1,係数絶対値和)以下の
最小値は「非正またはUNVERIFIED」として拒否する。
determinant_lower_bound_m2は丸め余裕を差し引いた下界で、実測最小値とは区別する。これは倍精度での保守的な検査で、
厳密有理数演算や形式的な区間演算証明ではない。

各節点だけでJacobianを確認する方式は採用しない。
反例X=(ξ−1/4)²−η、Y=(ξ−1/4)η−0.01ξは
det J=2(ξ−1/4)²+η−0.01。
6節点では正だが、(ξ,η)=(1/4,0)で負になるため全域検査で拒否する。
正の局所Jacobianだけで、メッシュ全体の重なりや境界の自己交差がないとは主張しない。

## 局所積分の契約

curved_fem.mapped_element_matricesは検証済み写像の一要素について、

- Kij=∫ r[(2Ni+rNi,r)(2Nj+rNj,r)+r²Ni,zNj,z] dr dz
- Mij=∫ r³NiNj dr dz

を参照要素へ引き戻す。元のTM弱形式は変更しない。
半径が要素内で負になる写像は拒否する。数値積分点だけの半径検査ではない。
積分次数は明示整数2以上、既定8のDuffy積Gauss。
曲線写像で勾配は有理関数になるため、既定次数で厳密な剛性積分とは呼ばない。
固有値・RFの受入では積分次数を変え、幾何/FEM細分とは別に積分誤差を確認する。

独立検証は曲線領域r=ξ、z=η(1+aξ)、a=0.4を使う。
面積1/2+a/6、回転体体積2π(1/6+a/12)。
一定uのK二次形式は4(1/6+a/12)、Mは1/20+a/30。
物理場u=rはP2幾何と同じ節点値で正確に表され、K二次形式は9(1/20+a/30)。
直線写像では既存直線P2の基底/積分と一致することも別に検証する。

## 続く実装と受入

1. 元曲線のパラメータ区間をメッシュ境界の各辺へ保持し、共有の二次幾何節点を生成する。
   軸/対称面は直線に保ち、端点の共有とタグを保持する。
   曲線化による反転時は未検証の要素を返さず、細分・再生成または明示失敗へ進む。
2. 全体の共有辺適合性・曲線境界交差・重なり・物理領域を検査し、曲線幾何次数を
   場の次数から分離して入力/保存する。座標配列だけを変えた直線Meshとして扱わない。
3. 全体行列と解、エネルギー正規化、軸/壁RF積分、曲線法線/接線を同じ写像へ接続する。
   境界弧長の積分誤差も別に検証する。
4. 曲線写像の逆写像を含む場サンプリングと図示を実装する。
   直線三角形の重心座標をそのまま曲線要素の位置判定に使わない。
5. 保存/再読込で節点順・共有性・元曲線対応・全域Jacobian・積分設定を再検査する。
   鏡映、Study、GUIも同じ保存契約へ移行する。
6. 球形の独立参照と、楕円/双曲線の幾何/FEM細分を再実行する。
   周波数・体積場・軸場・RF・表面場を別判定し、積分次数と幾何次数を混同しない。

## 二次境界の閉鎖・交差検査 — 2026-09-08

quadratic_boundary.check_quadratic_boundaryは(start,end,midpoint)の辺列を受け取り、
端点次数2の単一閉サイクルと、端点/辺中点の別番号を検査する。
辺列順序や向きが混在していても、幾何を変えずに閉ループをたどる。

二次辺をBezierの3制御点へ変換し、導関数の線形補間からカスプ/折返しを拒否。
非隣接辺は凸包包絡箱の離隔で判定し、不十分な組をde Casteljau二分する。
共有端点を持つ隣接辺は、有向接線の和への投影が正になる接続近傍を確保し、
その外の区間対を同じ離隔検査へ回す。共有端点以外の交差を許さない。
分割上限は各辺対で既定10000箱。上限・丸め解像度で決着しない場合はUNVERIFIED。
境界寸法で正規化し512εの包絡余裕を使う。点を移動/スナップする許容差ではない。
近接接触はFAIL/UNVERIFIEDで拒否し、厳密交差と丸め未確定を混同して成功扱いしない。
これは倍精度の保守的検査であり、形式的な区間演算証明ではない。

候補生成の最後にこの検査を行い、boundary_checkへ読み取り専用結果を保持する。
楕円32辺・双曲線28辺はPASS。
単純な端点四角形の辺が膨らんで交差/接触する例、1辺の折返しを拒否。
さらに隣接2放物線が共有端点以外の(.1,.36)でも交差する例を拒否。
向き/順序を変えた辺列と寸法1e-5/1/1e5倍を検査し、分割予算1箱では成功を偽らない。

境界検査だけを全体メッシュの適合性証明として使わない。
次は元の円板位相/共有辺対応と全域正Jacobian・単純境界の条件を
全体曲線空間の検査として集約し、その空間から全体行列を組み立てる。

## 物理座標の逆写像とプローブ — 2026-09-08

curved_sampling.QuadraticLocatorは検証済みの二次写像を受け取り、
物理座標から参照三角形の座標を求める。
節点の直線三角形はNewton反復の初期推定にだけ使い、包含判定には使わない。
物理座標を要素寸法で正規化し、減衰Newton反復の残差と参照三角形内を確認する。
境界の丸め幅は正規化座標の512εで、参照座標を境界へ戻した後も物理残差を再確認する。

Newton反復が不十分な場合は、参照三角形を4分割し、各小三角形の
二次Bezier制御点による包絡で探索する。包絡が全て対象点を除外した場合だけ領域外とする。
分割予算・境界の丸め解像度で決着しなければUNVERIFIED。
既定はNewton30反復、要素ごと1024箱。未確定をNaNへ変換して隠さない。

CurvedFieldSampler.evaluateは物理点(r,z)の配列を受け取る。
曲線の膨らみを含む包絡で候補要素を絞り、逆写像後にfields_in_cellへ渡す。
領域外は既定で例外、outside='nan'ならinside=FalseとNaNを返す。
ただしどの候補でも内外を証明できなければ、outside='nan'でもUNVERIFIEDで停止。
共有辺上では最初に確認できた要素の片側微分を使い、場を平滑化しない。
対象領域は実際の二次メッシュであり、元の解析曲線との差の領域へ外挿しない。

## G03離散曲線場の連続極値上界 — 2026-09-08

rational_bounds.bound_rational_normは[0,1]上のsqrt(ΣN_i²)/D、D>0を上下から囲む。
係数は昇べき順。入力floatはその二進値を厳密なFractionへ変換し、以後の多項式演算、
Bernstein変換・次数上げ・中点de Casteljau分割と上界比較は有理数で行う。
ΣN_i²とD²を同じBernstein次数に揃え、D²の全係数が正なら係数比の最大が上界。
これは商を正の重み付き平均で表せることによる。D²の正値と端点D>0から符号を保持する。
正値を囲めない区間は分割し、評価点でD<=0なら拒否する。

端点/中点の厳密値を下界候補とし、最大上界の区間から分割する。
既定相対幅1e-6、生成区間予算10000。予算不足はUNVERIFIED。
戻り値の平方根floatは、二乗をFractionで比較して外向きに丸める。
二乗値がdouble範囲外でもノルムを出力できるよう2の冪で正規化する。
外向き丸めで幅を超えれば追加分割し、厳密最大値自体のfloat幅が不足ならUNVERIFIED。
下界を得たパラメータはfloatと厳密分数を保持する。
