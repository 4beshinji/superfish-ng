# 曲線辺の候補検索

2026-09-09、基準942860b。N04非球形対照の検証費用を改善する。
曲線辺の検査は、元メッシュの共有関係、全辺の正則性、隣接辺・非隣接辺の
交差/接触の拒否を含む。これらの幾何条件と細分検査は変更しない。

既存の候補検索は、各辺のパディング済みBezier制御点包囲箱を全ての後続辺と比較する。
候補が少ない場合も全組合せに対する座標比較を行うため、辺数の二乗に比例する。
新しい検索は、箱中心の広がりが最大の座標で中央値分割する木を構築する。
葉は最大16箱。内部節点は子孫全箱の包囲箱と最大辺番号を保持する。
辺iの照会では、厳密に離れた節点と最大番号がi以下の節点だけを除外する。
葉で既存と同じ閉区間の重なりを確認し、j>iの候補番号を昇順に返す。

接触する箱は候補から落とさない。新しい許容誤差・幾何近似は追加しない。
候補を従来の辞書順に戻すため、最初に検出する失敗、候補数、細分箱数も維持する。
候補段階は交差の安全性を判定するものではなく、従来の隣接/分離検査へ同じ辺対を渡す。
全箱が重なる入力では候補数自体が二乗に増えるので、全入力での計算量改善は保証しない。
外部空間検索ライブラリは追加しない。

受入条件は、独立全探索との候補・順序の完全一致、接触・退化・長い箱・順序反転、
完全な幾何検査報告の一致、交差時の最初の失敗と検査予算の維持、
旧保存版1〜4の完全再検証、球形解析五量・停止系列・DOF、標準周波数/RF回帰。
候補検索の時間と、辺検査全体・計算全体の時間は区別して測定する。
