# 角部表面電場の切り分け — 2026-09-06

対象は過去にEpk/EaccがWine=2.42008、NG=2.77785となった合成necked cell。
実機形状ではない。ユーザー依頼によりP1-04の診断部分を先行し、まずNGの19固有場を新規計算した。
その後Wine環境を新設し、鋭角・丸み各4段階のブラックボックス比較まで実行した。
結論は、過去条件の局所境界分割はNGが粗く、有限距離の場にもNGの離散化誤差が残る一方、
鋭角ピークは両コードで細分に伴い増加し、その値の大小を精度順位にはできない、というもの。
丸み対照でもWine最終細分のピーク変化が2.81%あり、ピーク精度の検証完了とはしない。

## 評価方法

- 真空・閉PEC・m=0 TM基本モード、ピークphasor、全蓄積エネルギー1 J、β=1。
- 鋭角の元形状はnr=24/48/96/192/384、nz=round(nr×0.18/0.105)。diagonal/crossedを別々に解く。
- 表面電場はPEC境界の所有要素から片側微分で評価。節点平均・平滑化をしない。
  同一座標に複数の片側値があれば最小・最大を保存し、平均で隠さない。
- 元の4角点の各両側で、壁に沿って0.5/1/2/4/8 mm離れた固定物理座標を評価。
  境界辺長と所有三角形の最大辺長も保存し、分割数を局所解像度と同一視しない。
- 対照形状は元形状の4角に半径3 mmの接線接続円弧を入れた別の合成形状。
  半径・接線・鏡映対称性・フィレット重複拒否を独立にテストする。
  円弧の最大弦誤差1/0.25 µmそれぞれでnr=48/96/192を計算。
  元の鋭角試験と同じ半径方向に形状適合したメッシュ生成を用いるため、円弧を明示的な折れ線へ変換する。
  円弧の厳密な入力と計算した折れ線入力の両方を保存する。
- 円筒TM010の独立Bessel解で、ピークと全PEC境界端点の電場を検査する。
  固有値残差・周波数・R/Qと、表面電場の誤差を分ける。

## 鋭角のピークは細分で上がり続ける

| nr | NG diagonal Epk/Eacc | NG crossed Epk/Eacc |
|---:|---:|---:|
| 24 | 2.036508 | 2.076020 |
| 48 | 2.352182 | 2.253188 |
| 96 | 2.777845 | 2.675930 |
| 192 | 3.301968 | 3.196629 |
| 384 | 3.915829 | 3.802331 |

nr=96で過去のNG値を再現した。nr≥48の最大位置は半径45 mm、z=25または155 mmの首元角点。
nr=96/192/384で最大値を持つ境界辺長は約1.087/0.5435/0.2717 mm。
diagonalの最後の細分では、絶対Epkが18.594%、Epk/Eaccが18.591%増加する一方、
周波数変化は0.0015785%、R/Q変化は0.0071283%。Eaccの正規化だけによる増加ではない。
crossedでもEpkは18.956%増加し、分割方向を変えても有限ピークの収束は見られない。

局所的な数学との整合も調べた。首元の真空側角度は
`ω = π + atan(1.5) = 約236.31°`。軸から離れた角ではTM方程式の主部は局所的にLaplace型で、
PECの磁場Robin条件の主部はNeumann条件になる。分離解の最初の非定数項は
`Hφ ∼ constant + A ρ^(π/ω) cos(πθ/ω)`、その微分から
`|E| ∼ ρ^(π/ω−1) = ρ^(-0.238288…)` が可能になる。
これは当該空洞の厳密解を置き換える式ではなく、非零特異項が励起された場合の局所漸近予測。
一般の角点べき則の背景は[NISTIR 7668 §2.2](https://math.nist.gov/~WMitchell/papers/nistir7668.pdf) [R24]。
同資料のDirichlet例をそのままRF解とせず、上記Neumann主部への対応は今回の導出として区別する。

予測では代表寸法を半分にすると約17.96%増加する。NGの最細3段階について
所有三角形の最大辺長とEpkの両対数傾きはdiagonal=-0.2477、crossed=-0.2536。
局所特異性と整合する増加であり、単純な丸め誤差や有限な厳密ピークへの過大評価とは解釈できない。
この傾きの一致だけで場の振幅精度や厳密な発散を証明したわけではない。

## 角から離れた固定点にもNGの離散化誤差が残る

首元2角点×両側の4点について、nr=192→384の電場最大片側値の最大相対変化を示す。
分母は前段の値。特異点そのもののピークとは別の測定である。

| 角からの距離 [mm] | diagonal [%] | crossed [%] |
|---:|---:|---:|
| 0.5 | 24.546 | 25.341 |
| 1 | 8.532 | 4.759 |
| 2 | 4.055 | 3.237 |
| 4 | 1.407 | 1.506 |
| 8 | 1.592 | 1.451 |

したがって「NGは細分したので角近傍まで正確」とは言えない。
固定点でのP1微分は所属要素の変化にも影響され、変化は単調とは限らない。
角から0.5 mmの点では、最細でも所有三角形の寸法が距離と同程度である。

独立した物理条件として、滑らかなPEC面では接線電場がゼロであることも利用できる。
保存した片側値ではnr=384、首元から1 mmの4点における最大`|Et|/|E|`が
diagonal=8.733%、crossed=1.724%。4 mmでは2.031%/0.385%である。
NGはPECを弱形式の自然条件として課すため、有限P1メッシュの復元電場が点ごとに
接線ゼロを満たす保証はない。この量は実在の接線電場ではなく、復元場の離散化誤差の診断。
角の特異性だけを理由に、有限距離のNG場の誤差まで無視しない。

## 接線接続の丸みを固定するとピークの変化は小さくなる

| nr | 弦誤差1 µmのEpk/Eacc | 弦誤差0.25 µmのEpk/Eacc |
|---:|---:|---:|
| 48 | 2.525359 | 2.519530 |
| 96 | 2.556105 | 2.551972 |
| 192 | 2.566193 | 2.563290 |

最後のメッシュ変化はEpk/Eaccで0.3947%/0.4435%。
nr=192固定で弦誤差を1→0.25 µmとした差は約0.1131%。
円弧近似を変えると軸格子も変わるため、純粋な形状誤差だけを測ったとは呼ばない。
また固定された折れ線近似は依然として微小な角を持つ。これらは今回の範囲で変化が小さくなった証拠で、
円弧厳密形状のピークに対する誤差上限ではない。

円筒対照ではnr=24/48/96の絶対Epk解析誤差が0.32170%→0.09715%→0.02837%。
全PEC境界端点の最大絶対電場誤差/E0も0.51169%→0.25345%→0.12600%へ減少した。
一般的な電場スケーリングの誤りだけで鋭角の増加を説明する証拠はない。

## Wine環境と境界判定の追加切り分け

ユーザーの環境新設許可を受け、Wine 9.0とローカルの7.20インストーラーを用いて
`/tmp/superfish-wine-runtime/prefix-ready` にSUPERFISHを導入した。
数値出力が示す内部版は過去と同じ7.17（2006-01-13）。
`wine-local.sh` は専用の32 bit Wine・DLL探索先・prefix・仮想画面`:97`を指定する。
環境は/tmp配下のため、一時領域の掃除後には再作成が必要。
再作成にはUbuntu公式のWine32/i386依存とXvfbをrootなしで展開し、
Wine依存の32 bit zlib1.dllをprefixのsystem32に配置したうえでインストーラーUIを実行する。
失敗した初期化先は保持し、既存のユーザーWine環境は変更しない。

最初の新規Wine計算 `out/surface-diagnostics-20260906/wine-input-sharp-dx0.1/` は
f=1271.757800 MHz、Epk/Eacc=2.420077078で過去の文書値を再現した。
その後の初回スイープ `out/surface-wine-20260906/` はローカルSF.INIの作業ドライブ指定不足
（Error 505）で失敗。`TAPE40=C`を設定した次の試行は
`out/surface-wine-ready-20260906/` に残した。

後者でSF7へ斜面上の線を指定すると、一部の行が全成分ゼロになった。
左右対称点でも不一致があり、これを真の電場ゼロとして比較しない。
境界への厳密な点指定での判定が原因と考えられるが、内部の補間アルゴリズムは調べていない。
両コードに同じ真空側法線オフセット0.1/1 µmを指定し、NGを6ケース新規に解き直した。
保存先は `out/surface-ng-inset-20260906/`、80点×6計算。後続検査用のFEM場も保存した。
首元の点でオフセット変更のNG場への影響は最大0.00202%。
この検査の値は厳密な表面トレースではなく、指定距離だけ真空側にある点の値である。

`SF.INI`では作業ファイルのディスク保存、使用ドライブC、SF7の出力桁数を明示する。
数値出力の印字座標は電場桁数を増やしても有効6桁のため、照合時はその丸め幅だけを許容し、
要求座標と印字座標の差も保存する。電場はSF7の符号付き成分からの大きさ、
蓄積エネルギーは同じ計算のSFOから取り、両者を1 Jへ揃える。

Automeshの数値出力から実境界座標列を読み、首元に接する境界辺の最大長を両コードで比較する。
過去のNG nr=96では1.94895 mm、Wine DX=0.1 cmでは1.00000 mm。
したがって過去の条件では、少なくともこの境界分割はNGの方が約2倍粗い。
Wineの内部三角形の形状・寸法までは取得していないため、全離散空間の精度順位とは区別する。

## 最終Wine比較結果

鋭角4段階は `out/surface-wine-inset-20260906/` で完了。
同試行の丸み折れ線入力はError 344（物理点に対応する論理格子点がない）で失敗した。
公式PO入力仕様 [R25]に従い、円弧を反時計回りNT=4・時計回りNT=5で指定した
`out/surface-wine-arcs-20260906/` で丸み対照の4段階も完了した。
NGの丸みは弦誤差0.25 µmの近似、Wineは半径3 mmの円弧指定であり、完全に同じ折れ線ではない。
NGの弦誤差変更試験と、Wine出力境界の円半径検査を合わせて形状差を監視する。
Wine最細では各円弧に14境界点があり、半径誤差は最大5.55e-10 mで、印字精度内。

ここから「全ての量でWineの方が正確」あるいは「NGの高いピークが正しい」とは結論しない。
