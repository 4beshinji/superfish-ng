## 幾何と場空間

軸を含む単一の連結真空断面、一本の連続した軸区間、外周と有限個の直線PEC穴を対象にする。
内導体は軸や外壁と接触させない。全セルは非負半径にあり、正面積・manifold・全境界被覆を満たす。
外周の軸辺とPEC辺、各穴のPEC辺を区別し、軸を金属壁や新しい穴として数えない。
現在の全r>0専用Caseを緩めず、軸を含む領域は別の明示入力・保存契約を設ける。

未知数は既存canonical TMと同じu=Hφ/r。軸上uは有限で、Hφ=ruは自動的にゼロになる。
軸上のu自由度を削除しない。正半径のq=rHφ空間をそのまま軸へ延長しない。
既存の非負エネルギー形式

    K(u,v) = ∫ r[(2u+r u_r)(2v+r v_r) + r² u_z v_z] dr dz
    M(u,v) = ∫ r³ u v dr dz

を使い、既存のP1/P2組立を再利用する。PECは自然境界条件。
部分積分した式の2r² n_r uv境界項を捨ててNeumann-u問題へ置換しない。
軸につながるこのHφ空間では、q一定の非ゼロ静的循環は正則でない。
正半径問題の零モード除外を流用せず、零モード不在と正スペクトルを別に確認する。
全Maxwell静電/静磁場の位相的分類をこの縮約だけで実装済みとは主張しない。

peak exp(+iωt)のHφ real、Er/Ez quadratureを明示する場合、
Er=r u_z/(ωε0)、Ez=-(2u+r u_r)/(ωε0)。軸上Er/Hφは0、Ezは有限。
既存TMのphasorを使う経路との共通位相変換を明示して検証する。

## 独立解析例

合成円筒0≤r≤R、0≤z≤Lから矩形の導体断面を除く。
κRをJ0の第三正零点とし、穴の半径端をJ0の第一・第二零点/κ、z端をL/3・2L/3に選ぶ。

    Hφ = A J1(κr) cos(3πz/L)
    ω = c sqrt(κ² + (3π/L)²)

は外周・穴の全PEC面と軸正則性を満たす。rHφの法線導関数を全PEC面で直接確認する。
Aは穴を除いた全3Dエネルギーから定める。半径/軸方向の分離積分、外矩形から穴を引く独立高次Gauss積分、
MaxwellのUE=UHを照合する。全壁損失は外壁・端板・穴の全辺を正に加える。
これは解析用の合成空洞で、LANL/KEKの実測構造ではない。

軸が真空につながるため、明示した軸上加速経路とbetaに対する複素Vaccを解析線積分と比較できる。
両R/Q定義を区別し、軸の存在だけで未宣言の加速経路を捏造しない。
二穴の検証はJ0零点の第一/第二、第三/第四を各穴とし、第五を外壁として独立に確認する。

## 実装前に固定する受入条件

- 不正な軸区間・軸接触穴・外部穴・輪郭交差・非連結・被覆欠落をstrictに拒否する。
- 穴なし矩形で既存canonical TMの同一メッシュK/M・全スペクトル・共通位相変換後の全場/RFが一致する。
- P1/P2・二尺度・二水準以上で、上記穴付き解析場のf、E、H、全壁RF、軸Vaccと両R/Qを個別確認する。
  上下guardで孤立した対象を選び、計算した順位を解析ラベルや追跡IDと混同しない。
- 軸上の場、穴内部拒否、全3D単位、規格化、位相を専用nativeとCLI/APIで完全保存再生する。
- Project/Job/GUI/Studyへの接続は、対応する元入力・保存・再起動・中止・実ブラウザーの検証後にだけ受入とする。
- 全標準と既存の周波数/RF回帰を確認し、既存ベンチマークや許容差を変更しない。

新しい外部資料・依存・旧版参照は不要。canonical弱形式と公開数学であるBessel方程式から独立に導く。
曲線内導体、複数材料、m>0や一般3D、旧版照合は別の残項目として維持する。
