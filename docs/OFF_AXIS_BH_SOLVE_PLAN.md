# S04: 軸非接続P1の境界付き非線形磁静場

2026-09-13 JST。後続限定課題。[実装記録](OFF_AXIS_BH_SOLVE.md)の専用API範囲で限定受入。

正半径のOffAxisBHPartitionに専用Caseを接続する。全Jphi、固定psi[Wb]/接線Ht[A/m]、P1、固定求積q、Newton設定と明示初期係数を厳密に保持し、少なくとも一つの固定psi境界を要求する。最初の固定値に対する相対psiを解き、絶対psiとAphi=psi/rを別に保持する。領域外の軸を貫く絶対磁束は補わない。

自然荷重は+2pi∫HtNi ds[A]。同じ固定求積のU/g/実接線で減衰Newtonを行い、頂点までの表範囲確認、採用/棄却/失敗の全履歴を保持する。版2失敗はcoefficient_field=psi_relative_to_reference_wbとlast_valid_coefficientsを明示し、既存平面版1と軸接続版2を維持する。q/q+4の接線/内部荷重/エネルギー差と同じ係数での高次数自由残差を、収束と元場の誤差から分離する。

元psi/Aphi/Br/Bz/Hr/Hzと片側材料/来歴、JのU/U*、AのH周回/固定反力、Wbの磁束を出す。仕事はU+U*で、非線形K@psiをgへ代用しない。固定反力は+2pi∫Ht dsとの比較、元H周回は断面源電流との比較をそれぞれ保持する。一定psiの零B/Hと非零Aphi=C/r、基準変更で場/エネルギーが不変であることを確認する。

独立検証はpsi=-Czの厳密1/r径方向場と径方向材料界面、Bz(r)の径方向電流・二材料問題、P1 8/16/32の元psi/Aphi/B/HとU/U*/周回/反力/磁束の改善、旧線形極限、穴/尺度/符号/基準変更、零場、期待収束失敗を含む。径方向参照はF=psi-reference、F_r=rB(H)、H_r=-Jphiの別BVPもCase境界から解く。解析/FEM係数をBVP初期値へ使わない。求積や反復残差の小ささでメッシュ検証を代用しない。

開始許容値は独立の表現可能場1e-10、線形極限1e-10、尺度/基準比較1e-10。P1最細のpsi/Aphi 1e-3、B/H 0.02、U/U* 1e-3、元周回/反力0.02、磁束2e-3。物理量ごとの解析尺度で正規化し、元場4量は細分で改善させる。BVPはODE残差1e-10・境界1e-11・257点の場差1e-8。標準と既存周波数/RFの回帰差を確認して限定受入する。保存/CLIは後続工程。
