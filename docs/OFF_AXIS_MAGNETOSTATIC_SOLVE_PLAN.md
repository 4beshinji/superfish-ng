# S02: 軸非接続の境界付き磁静FEM・元場と3D積分量

2026-09-13 JST。実装中・未受入。

- 全r>0直線領域に正値mu_r、全領域の符号付きJphi、全境界を明示する。固定psi[Wb]か接線Ht[A/m]を指定し、少なくとも一つの固定psi境界を要求する。同じ頂点で接続した固定辺は一つのIDにまとめる。
- 自前P1/P2の実FEMで解く。自然荷重は+2π∫Ht Ni ds[A]。最初の固定psiを基準とし、相対係数と元psiを保持する。定数psiによるB=0/Aphi=C/rの自由度を明示し、領域外の絶対磁束を補わない。
- 元psi/Aphi/Br/Bz/Hr/Hzを元セルから評価する。Jエネルギー・Wb磁束、源電流A、固定psi反力Aを個別に出す。固定反力は+2π∫Ht dsと比較し、実H周回+源電流と離散電流/仕事の恒等式を区別する。
- 一様BのP2二次psi（穴を含む）、定数psiの零場、H=C−Jphi*rの環状電流、二層の連続Hと積分したpsiを独立参照とする。解析解でFEMを補正しない。
- 追加6unit、独立88例（P2一様B32、環状電流24、二層24、定数psi零場8）を検査する。電流の2系列は各P1 8/16/32、P2 4/8/16で細分し、psi/Aphi/B/H/U/H周回/元H反力を別々に比較する。
- 最細の相対誤差上限はP1で[1e-3,1e-3,2e-2,2e-2,1e-3,2e-2,2e-2]、P2で[1e-5,1e-5,1e-3,1e-3,1e-5,2e-3,2e-3]。境界磁束はP1 2e-3、P2 2e-5以内。各量で誤差減少を要求する。元場は独立4×4 Gaussの体積重みで評価する。
- 一定Jで幾何s/透磁率mを変えるとpsi∝m*s³、B∝m*s、U∝m*s⁵、電流∝s²。符号とz移動を含め比較する。固定Bではpsi∝s²、U∝s³/m。基準変更によるB/H/U不変も検証する。
- 既存全標準と周波数/RF回帰を保持する。保存/CLIは次段階。純Ht、軸接続、曲線、非線形/異方性、永久磁石、厳密開放境界、巻線インダクタンスはこのAPIで対応しない。
