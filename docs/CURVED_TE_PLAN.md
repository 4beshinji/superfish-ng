## 実装と受入条件

- 通常の明示TE Caseから曲線P2の幾何・K/Mを構築し、PEC/電気対称の全境界節点を拘束する。軸と磁気対称をTMの拘束集合で代用しない。一様/局所細分後の実境界から集合を作る。
- 物理二次写像の勾配からEφ、Hr/Hz quadratureを復元する。点検索は元弦三角形で代用せず、既存の検証付き逆写像を利用する。軸の厳密値・領域外・未確認検索を区別する。
- 曲がったPEC壁の側要素の磁場を、写像Jacobianから求めた接線へ射影する。面積要素2πr dsを積分し、対称面を損失へ含めない。高次積分との差を別検査する。
- 直線極限で既存TE P2の周波数/場/エネルギー/壁損失と一致すること。定数vのEφ=r v、Hr=0、Hz=2v/(ωμ0)を曲線上で厳密に再現すること。
- 球形の独立解析で周波数相対1e-4、場成分1%、G相対0.5%、電磁エネルギー釣合い1e-9。実細分のRitz減少と、元の球面/二次近似幾何差を区別する。2尺度でMaxwell f/G/Q0と場振幅の尺度則を確認する。
- 専用TE保存を曲線版へ拡張し、再構築した実二次節点/接続と保存値を照合する。元メッシュのみを表示対象とせず、VTKにも実二次要素を保存する。従来直線TE結果を再読込可能に保つ。
- 通常CLI/API/native一致、Case/幾何/係数/規約改変拒否、磁気対称半領域と全領域の比較、一様/局所細分履歴を確認する。
- 最終ソースを固定して標準validateと独立検証を行い、既存TM seed9モード19量を比較する。Project/GUI/追跡等の未接続項目はP01/O02の残件として明記する。

## 独立球形参照

公開の大学講義資料 [PHY–387 K, Problem set 13 (2022), §1](https://web2.ph.utexas.edu/~vadim/Classes/2022s/hw13.pdf)
の式5a/6/8/10を周波数・壁損失・球Bessel積分の参照にする。
TEの正根jℓ(x)=0、ω=c x/R、G=Z0 x/2。ℓ=0をTE共振として加えない。
資料の式9直前のTE表記はTM式の誤記と読み、式9をTE評価には使わない。
時間phasorは製品のexp(+iωt)から独立に磁場を導く。文章・コードは転載しない。

ℓ=1,m=0の実電場はEφ=A j1(kρ) r/ρ、ρ²=r²+(z-zc)²。
v=A j1(kρ)/ρの勾配を解析微分してHr/Hzを求める。
全蓄積エネルギーUに対しA²=3U/[2πε0 R³ j1′(x)²]。
中心ではv=A k/3、勾配0の正則極限を使う。これらの式は検証用で、製品solverへ導入しない。

## 主ツリーへの接続

開始時の750件（748合格/2skip、1155.964秒）が終了してから主ツリーへ反映した。
統合後のTE12検査は2.028秒でPASS。製品はte.pyからte_curved.pyへ二次写像の場/壁積分/点検索を分岐し、
spaceのconstrained_dofsもTEのPEC/電気対称集合として保持する。
Caseに保存した一様/局所履歴から幾何を再構築し、最後にTE拘束集合を作る。
既存TM用のCurvedSpace追跡・適応APIを直接TE用に受入したわけではない。

曲線TE結果はschema_version=3。直線版2の書式は維持する。
geometry.npzには実二次節点・要素接続・境界接続・タグを保存し、読込時の再構築とdtype/配列を厳密照合する。
VTKは6節点二次三角形（type 22）と各写像中心の場。軸CSVは実曲線空間の軸節点を使う。
補助CSV/VTKの完全性とNPZからの数値再検証を区別し、場ピークの保証はしない。
製品例題は `examples/te/sphere.json`。合成球形で、3モード・一様4段の例である。

```sh
superfish-ng solve examples/te/sphere.json --out out/te-sphere-new
superfish-ng replay-te out/te-sphere-new
OPENBLAS_NUM_THREADS=1 python scripts/validate_curved_te.py --out out/curved-te-check-new
```

Project/JobManager/GUI、TEの追跡/Study/設計探索・場の鏡映構築は未接続。P01親全体と全計画の完了ではない。
