# Hφの同領域質量内積とL2射影

部分空間追跡で有限比較空間を使うための基盤。固定候補623sourceの実装を検証中、未受入。
軸あり/なしの明示した直線PEC穴付きメッシュを対象に、同じ真空領域の独立P1/P2空間を比較する。
軸接続では正則未知関数u=Hφ/rと重みr³、正半径ではq=rHφと重み1/rを使う。
異なる未知関数の空間を混ぜない。質量内積の2πは除き、全3D磁場内積との関係を明示する。

受入条件：

- 宣言メッシュを再検証し、全穴と外周が厳密に同じ領域を覆うことを既存の元要素共通分割で確認する。元メッシュを動かさず、候補/分割/自由度予算とstrictなP1/P2・積分次数を検査する。
- 元空間の自己質量と交差質量を疎行列で作り、高次積分差・元FEM質量再現を確認する。元係数を対角近似や点サンプル補間で置き換えない。
- M_current x = C.T a のL2射影を解き、線形方程式残差・誤差の質量直交性・ノルム非増加・Pythagoras関係を検査する。差は元要素上の多項式から直接積分し、近いノルムの差引きを誤差値に使わない。
- 同じ空間、独立同次数/混次数メッシュの定数・線形・二次関数、0/1/2穴、軸あり/なし、二尺度を独立多項式/解析積分で検査する。任意の元係数も射影し、未包含空間で失う場をゼロ誤差と表示しない。
- 不一致領域/空間、予算・bool・非有限係数を拒否し、元係数不変、標準と旧f/RF回帰を確認する。

射影は元固有モードの新しいFEM解ではない。周波数・RF量・mode IDを与えず、再計算した固有ベクトルへ代用しない。
比較空間でのスペクトル診断、縮退/順位交差の追跡、永続保存・CLI/GUIはそれぞれ後続工程。
既存自作の質量形式と直交射影の線形代数を使う。新規外部資料・依存・旧版参照は追加しない。

候補/tmp/superfish-hphi-mass-projection-20260912の追加4unitは3.561秒、独立48比較/144係数列は10.228秒でPASS。別の物理多項式再構成/積分との差最大5.630e-14、相似差最大1.824e-12。標準48376は継続中。
