# 楕円パラメーターの直交角評価

2026-09-09、曲線tuneの鏡映検証で発見した相似変形時の接続拒否。
別置き試作で原因を検証し、初回標準/独立検証の終了後に製品へ反映。最終回帰も合格。

中心z=.12 m、半軸(.12,.096) mの楕円で、θ=π/2のcosが約6.1e-17になる。
従来評価では中心zに加算した結果が.12 mより1 ulp外側となり、垂直な対称端面との
接続に負の分離投影が生じる。元の.1 mでは同じ誤差が中心座標の丸めに吸収されるため、
1.2倍という相似変形だけで接続証明がUNVERIFIEDへ変わる。
既存の「負の投影は拒否」を緩めることは、本当に重なる接続を受け入れる危険がある。

楕円の任意保存フィールド `parameter_evaluation` を導入する。
省略/`numpy` は従来のnp.cos/np.sin評価を完全維持し、既定のto_dictには追加キーを出さない。
`exact_cardinal` は表現されたθがk*(π/2)と厳密に等しい場合のみ、sin/cosを0/±1にする。
位置と接線の両方に同じ評価を使う。誤差許容幅を持つ角度スナップは行わない。
開始角正規化と1周未満のsweepからθは[-3π,3π]内であり、その整数倍だけを比較する。
未対応方式、null/bool/配列を拒否する。

非恒等の楕円アフィン変換はこの評価方式を明示したnative弧を生成する。
保存された方式は鏡映・弧分割のdataclass置換でも維持される。
恒等変換と過去の保存曲線は従来どおり。既存保存場の数値再構築を黙って変更しない。
この変更は三角関数の表現上の直交角規約であり、曲線の移動補正、交差許容やFEM許容差の
緩和ではない。回転角には既に同じ厳密直交角規約がある。

受入条件: 問題の相似変形のred→green、直交角の厳密位置/接線、隣接floatを丸めないこと、
旧文書のキー不変と新方式のstrict往復、左右/両対称の実FEM・保存再構築・tune追跡、
旧native保存場の再読込、既存曲線/標準周波数とRF回帰。
新規外部資料・依存・legacy参照はない。
