形状と条件

TEの磁場は+時間phasorのquadratureです。軸方向加速場はゼロで、R/Q・加速量はN/Aです。通常計算・保存・場表示・プローブに対応します。TEの保存場比較は同じ端条件の円筒のEφに対応し、一対称面の半領域とその鏡映結果を扱います。通常/鏡映の混在は拒否します。Studyは独立したパラメータ掃引と同一物理条件の細分比較に対応します。TE細分比較では電場・磁場・RFを別々に判定し、物理誤差上界や表面ピーク精度は保証しません。鏡映結果は対称性で選ばれた部分スペクトルで、元半領域から再検証します。鏡映結果の細分比較は同じ物理・同じ対称条件の元半領域に対応します。一般形状の追跡・適応・調整・最適化は未対応です。

モード対応と追跡履歴

          
完了した計算結果を選び、保存場を比較します。周波数順位とモードIDは別です。TEは同じ端条件の円筒のEφを比較し、TE/TMや通常/鏡映の混在は受理しません。対称面は一つまでで、鏡映の番号は部分スペクトル内の順序です。

          

            
            
          

          

          
          
          

            
旧・新の比較用メッシュを明示し、それぞれの物理領域を覆う必要があります。版1〜3は対応する三角形分割を使い、版4・5は共通の積分分割を生成します。実FEMメッシュの接続は一致しなくても比較できます。版1の直線・版2の二次曲線では番号も一致させます。

            
二次曲線の版3では、各側の元メッシュと細分履歴を再構築し、境界から節点・要素番号を自動対応させます。boundary_pairingにsame_curve_fractions（同じ曲線分率）かordered_curve_vertices（曲線上の節点順）を両側で明示してください。曲線番号・種類・タグと分割の隣接関係が対応し、それぞれの計算用の二次境界全体を保つ必要があります。曲線形状の変化による体積の重みも比較に含めます。

            
二次曲線の版4は、対応する初期分割から異なる局所細分を行った場合に共通の積分分割を生成します。両側に同じboundary_pairingとmax_pair_tests（初期要素内で調べる組数の上限）を明示します。各側の全要素を交差領域が厳密に覆うことを確認します。実FEMの係数を変更せず、元の場を比較します。

            
版5は異なる初期接続にも対応します。各source_meshの頂点と同じ順序で無次元のreference_verticesを指定し、境界対応にdeclared_reference_polylinesを選びます。対応する曲線の参照折線とタグが一致する必要があります。max_pair_testsは辺交差・自己重複・両分割の交差検査の総予算です。

            
            
            
逆方向へ継続する場合は、比較する結果も逆に選んでください。入力欄の旧・新だけを入れ替え、メッシュの妥当性は比較時に検証します。標本次数を上げた確認も必要です。

          

          

            
旧結果から新結果への変換: r′ = a r、z′ = b r + c z。正の倍率で軸と原点を保ち、境界全体が対応する必要があります。二次曲線では、同じ番号・パラメータの曲線を対応付け、変換後の近似境界全体を照合します。再近似で境界が変わった場合は比較できません。

            

              
              
              
            

            
            
逆方向へ継続する場合は、比較する結果も逆方向に選んでください。係数は 1/a、1/c、−b/(a c) に変換されます。

          

          
同じ曲線定義・パラメータ付けと、同じ二次近似境界が必要です。解析曲線が同じでも、再近似で境界が変わった場合は比較できません。標本次数を変えて対応を確認してください。

          
直線境界とPEC/axisタグが一致する領域に限ります。標本次数を上げて対応を確認してください。対応PASSはRF量の収束を保証しません。

profileの頂点座標、二次曲線形状のアフィン変形、または曲線寸法を調整します。上の形状と追跡の判定条件から入力を作成します。曲線変形の追跡写像は各試行から導出します。

          
          

            
            
            
            
各座標[m] = multiplier × 設計変数 + offset_m。multiplierは設計変数の1単位あたりの長さです。座標はすべて同時に更新します。

r′=a(x)r、z′=b(x)r+c(x)z。radial_scale、axial_scale、axial_shearの係数を定数項から順に指定します。係数cₖの単位は1/(設計変数の単位)ᵏです。元メッシュの対応を保持し、最終細分の倍率には2の累乗を指定します。不正形状や細分対応の変化では停止します。
