形状と条件

一般輪郭の頂点・解析曲線・辺タグは読込ファイルの値を保持します。形状の変更はファイルで行ってください。

zは左から右、rは軸から壁までの半径です。

頂点 z [mm] r [mm] 操作

元曲線を保持し、初期分割用の直線輪郭を生成します。二次曲線要素の選択は下の計算設定で行います。FEMの最大辺長は別に指定します。

円弧は直前の頂点から指定頂点まで。(z,r)面の短円弧です。

終点番号 半径 [mm] 方向 操作
円錐曲線の共通接線を構築

構築要求または保存した構築結果を開き、接点を確認して候補を選択してください。PEC弧同士・PEC線分と弧の接続、またはPEC線分同士・弧同士・線分と弧の指定半径フィレットを構築します。

構築要求を読み込んでください。

候補位置1 (z,r) [mm]位置2 (z,r) [mm]長さ [mm]接続可否・方向

端点や精度を確認できない候補は未確認です。逆向き・空の弧・ゼロ長では接続できません。構築要求を編集すると選択と検査結果を解除します。

構築診断

        

        

          繰り返しと端部の組立
          

            現在の輪郭を一部分として追加します。各部分のzは0から。半径の異なる接続は実際の段差になります。
          

          
          

          
        

        

          
        

        
        

          
        

        
        

          
          

            
            
          

          
段数を1増やすと要素数は4倍になります。初期の二次形状を保持し、解析曲線へ点を置き直しません。

        

        

          メッシュと正規化
          

            
一般輪郭は最大辺長を指定して自動生成します。品質または資源上限を満たさない場合は停止します。空欄は自動生成を指定しません。

            

              
              
              
              
            

          

          

            
          

          

            メッシュの細かさだけで精度は保証されません。電磁場はピークphasorです。
          

        

        

          加速量の積分・位相設定
          
空欄は入力全長・全区間・位相原点0を使用します。蓄積エネルギーと壁損失は入力領域全体の値です。

            細分領域半径は形状の丸め半径とは異なります。円弧形状への角近傍細分は未対応です。

モード対応と追跡履歴

          
完了した計算結果を選び、保存場を比較します。周波数順位とモードIDは別です。

          

            
            
          

          

          
          
          

            
旧・新の比較用メッシュを明示します。両者は同じ頂点番号・三角形接続を持ち、それぞれの物理領域を覆う必要があります。実FEMメッシュの接続は一致しなくても比較できます。

            
            
            
逆方向へ継続する場合は、比較する結果も逆に選んでください。入力欄の旧・新だけを入れ替え、メッシュの妥当性は比較時に検証します。標本次数を上げた確認も必要です。

          

          

            
旧結果から新結果への変換: r′ = a r、z′ = b r + c z。正の倍率で軸と原点を保ちます。直線境界の全体が対応する必要があります。

            

              
              
              
            

            
            
逆方向へ継続する場合は、比較する結果も逆方向に選んでください。係数は 1/a、1/c、−b/(a c) に変換されます。

          

          
同じ曲線定義・パラメータ付けと、同じ二次近似境界が必要です。解析曲線が同じでも、再近似で境界が変わった場合は比較できません。標本次数を変えて対応を確認してください。

          
直線境界とPEC/axisタグが一致する領域に限ります。標本次数を上げて対応を確認してください。対応PASSはRF量の収束を保証しません。
