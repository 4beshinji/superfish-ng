平面のモード追跡

元の電場を宣言した写像で比較します。各対象帯域の上に、少なくとも1モードを計算しておいてください。

同じ多角形の元要素どうしを比較します。節点番号や分割は異なって構いません。形状の変更は受け付けません。

次の座標 = 尺度 × 前の座標。平行移動・回転・形状変更は対応していません。三角形の番号と宣言した四分割関係が一致する保存場を選びます。

宣言変換 F(x) = 尺度 × R(角度) x + 平行移動。通常は次の座標 = F(前の座標)、逆向きでは前の座標 = F(次の座標)です。可逆アフィン変換は別の対応で指定します。

宣言変換 F(x) = A x + 平行移動（Aは厳密に可逆な2x2）。通常は次の座標 = F(前の座標)、逆向きでは前の座標 = F(次の座標)です。鏡映を含む向き反転やせん断を指定できます。せん断後の厳密な固有周波数や物理収束は保証しません。

同じ接続なら両方0。片方を細分した場合は、その側だけに回数を指定します。

部分空間と追跡条件

部分空間を引き継ぐ場合はモードIDをnullとし、以下に前の順位とID集合を指定します。縮退した個別IDは自動で復元しません。

PASSは宣言写像での数値的な場・部分空間の対応です。連続した変形経路のモード同一性や、真の物理誤差の保証ではありません。
